## 一、项目概述

**视频工具箱**（VideoToolbox）是一个 Windows 桌面视频工具集，基于 PyQt5 + PyQt-Fluent-Widgets 构建，主要能力：

- **视频下载**：调用 yt-dlp / ffmpeg 下载 YouTube、B 站等站点视频，自动检测画质、下载字幕、打包独立文件夹（视频 + 1280x720 封面 + 信息 txt + srt）；
- **视频库**：本地视频扫描，缩略图卡片浏览与播放；
- **音视频智能合并**：按文件名与时长自动配对 mp4 + m4a/weba + srt/ass 并合成；
- **字幕处理**：内嵌开源字幕引擎 VideoCaptioner v1.4.2（GPL-3.0）提供转录 / 优化 / 翻译 / 配音 / 合成；
- **字幕校准**：调用自研术语库脚本 `subtitle_calib_merged.py` 做名词级原位校准；
- **校准知识多用户同步**：启动拉取、退出推送，条目级三方合并到 GitHub 仓库 `09Th90/VideoToolbox`。

技术栈：Python 3.12（内嵌运行时）、PyQt5、qfluentwidgets、yt-dlp、ffmpeg、VideoCaptioner、mihomo（内置代理）、Qt Installer Framework / Inno Setup（打包）。

**覆盖范围说明**：本说明书逐文件覆盖项目根目录与 src / tools / installer_src / data / docs / build / logs / history 下的**全部自有文件**。`tools\python`（内嵌 CPython 运行时，约 2 万文件）、`tools\videocaptioner`、`tools\ms-playwright`、`tools\mihomo`、`tools\asr_model`、`.buildvenv` 等属于第三方组件 / 构建环境，内部文件不逐项展开，按目录整体说明其作用与用法。

## 三、运行方式

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 图形界面（推荐） | 双击 `视频工具箱.exe` | 打包产物，免 Python，顶层唯一可执行文件 |
| 脚本启动器 | 双击 `src\视频工具箱.bat` | 自动选用 `tools\python` 内嵌运行时；不存在时回退系统 Python |
| 直接运行源码 | `python src\video_toolbox_qt.py` | 需安装 PyQt5 / qfluentwidgets / video_toolbox 依赖 |

> 未签名提示：exe 未做代码签名，开启 Device Guard / 应用控制策略的电脑可能拦截，此时请改用脚本方式运行。

- **用途**：Git 忽略规则，声明哪些文件不入库。
- **使用说明**：直接随仓库维护，无需手动操作。新增敏感或大体积文件时按注释分组追加条目。
- **关键忽略项**：

  - 历史大体积留档：`history\build\`、`history\logs\`、`history\data\`。

### 4.2 `aqtinstall.log`

- **用途**：aqtinstall（Qt 工具安装器）的安装日志，记录 Qt IFW 4.7 工具链的下载与安装过程。
- **使用说明**：仅供排障查阅，无运行作用；已按 `.gitignore` 排除入库，可随时删除。

### 4.3 `deploy_installer_ghpages.py`

- **用途**：把 `installer_repository\`（在线安装器组件仓库）部署到 GitHub 仓库 `09Th90/VideoToolbox` 的 `gh-pages` 分支并启用 GitHub Pages，供在线安装器远程拉取组件。
- **使用说明**（命令）：
  ```bat
  gh auth login                 :: 前置：完成 GitHub 登录，脚本从 gh keyring 取 token
  python deploy_installer_ghpages.py
  ```
- **可选环境变量**：`VT_REPO_DIR` —— 仓库根目录覆盖（脚本被复制到其它位置运行时用）。
- **原理**：走 GitHub Git Data API（curl 直连 api.github.com），直连持续 401/5xx 时自动回退内置 mihomo 代理（仅代理 GitHub 域名）；`gh-pages` 分支只含安装器仓库内容，不污染 `main`。
- **备注**：需要 `09Th90/VideoToolbox` 仓库的写权限；完成后在线仓库地址为 `https://09th90.github.io/VideoToolbox/`。

### 4.4 `github_proxy.yaml`

- **用途**：本机 GitHub 专用代理配置（FlClash / ClashMeta / mihomo 格式）。规则已精简为**只代理 GitHub 相关域名**（github 关键字、ghcr.io、gh.io），其余流量全部直连。
- **使用说明**：导入 FlClash → 配置 → 导入本文件 → 在代理组 SELECT 中手动选择节点（或 AUTO 自动选优）。用于解决本机网络访问 api.github.com / GitHub Releases 不稳定问题。
- **⚠️ 安全提示**：本文件**含代理节点 UUID、密码、secret 等敏感凭据**，已在 `.gitignore` 中排除，严禁提交到任何仓库或随包分发。本文档不展示其具体凭据内容。

### 4.5 `subtitle_calib_merged.py`

- **用途**：字幕校准统一脚本（唯一入口）。对 SRT 做**名词级术语原位校准**：只替换中文行术语，严格保留序号、时间轴、空行、换行（CRLF/LF）与 BOM 一字不变。由「字幕校准」页面以 `tools\python` 子进程调用，也可命令行直接使用。
- **使用说明**：
  ```bat
  :: A. 术语校准（12 种片源模式）
  python subtitle_calib_merged.py <输入.srt> [--out 输出.srt] [--report 对照.md]
       [--bi|--ja|--jpe|--ko|--ak|--akko|--zho|--endo|--pgr|--pgren|--wwoc|--react]
       [--fix-en] [--kb 学习库.json]
  :: 不传 --out 只做术语命中统计，不改写文件；默认输出「原名.calib.srt」，绝不覆盖原字幕

  :: B. 流水线子命令
  python subtitle_calib_merged.py extract   <源.srt> <cues.tsv>          :: 抽 cue 表
  python subtitle_calib_merged.py split     <cues.tsv> <前缀> --n 6      :: 切分段并行校准
  python subtitle_calib_merged.py merge     <源.srt> <表|目录> --out 输出.srt
  python subtitle_calib_merged.py verify    <源.srt> <输出.srt>          :: 校验结构零改动
  python subtitle_calib_merged.py compare   <源.srt> <输出.srt> <对照.tsv>
  python subtitle_calib_merged.py scan      <cues.tsv> [--min 2]         :: 扫描高频英文词
  python subtitle_calib_merged.py subfix    <源.srt> <fix.tsv> --out 输出.srt
  python subtitle_calib_merged.py terms-check [表名...]                  :: 术语表二次命中自查

  :: C. 对象级知识库（ENTITIES + 学习系统）
  python subtitle_calib_merged.py kb-export [--json] [--out 路径]        :: 导出知识库
  python subtitle_calib_merged.py kb-lookup <词>                         :: 反查实体全部知识
  python subtitle_calib_merged.py kb-lint                                :: 对象级体检
  python subtitle_calib_merged.py learn <原始.srt> <人工校准.srt> [--mode bi]
  python subtitle_calib_merged.py learned-show / learned-promote / learned-reject
  ```
- **内部结构**：`BILINGUAL_TERMS`（中英双语专名表）、`CONTEXT_MAP`（上下文佐证规则）、`WORD_MAP`（机翻错词）、`KO_TERMS / JA_TERMS / ENDFIELD_TERMS / AK_TERMS / PGR_EN_TERMS` 等按模式分离的术语表，以及对象级 `ENTITIES` 知识层；新对照统一以 `Entity` 追加进第 6 节，勿另建平行脚本。
- **备注**：2026-09-01 起算法为「术语表预编译 + 单遍替换」，输出与原实现逐字节一致；学习库默认文件名为 `subtitle_learned_kb.json`（cwd 存在时自动加载）。本文件同时是「校准知识多用户同步」的同步对象，与 `data\calib_sync_base.py` 为同一内容的基线快照（SHA256 相同）。

### 4.6 `视频工具箱.iss`

- **用途**：Inno Setup 安装包脚本，生成离线安装器 `installer\视频工具箱_Setup_v1.10.8.exe`。
- **使用说明**（命令）：

### 4.7 `视频工具箱.spec`

- **用途**：PyInstaller 打包配置，将 `src\video_toolbox_qt.py` 打包为单文件 `dist\视频工具箱.exe`。

### 5.1 `video_toolbox.py` —— 核心引擎

- **关键函数族**：
  - 路径/环境：`_resolve_tools_dir()`、`_resolve_data_root()`、`prepare_runtime_env()`、`set_data_root()`；
  - 字幕引擎集成：`vc_importable()`、`vc_state()`、`vc_prepare_settings_file()`、`apply_global_llm_to_engine()`、`engine_ui_brand_patch()`；
  - v1.11.0 新增：`apply_asr_to_engine()`（ASR → 引擎「转录配置」）、`vc_asr_patch_apply()`（本地独立模型覆盖）、`vc_lazy_cache_patch()`（diskcache 延迟化）、`calib_ai_run()` / `calib_ai_chat()`（AI 校准入口）；

  - 合并：`scan_media()`、`smart_pair()`、`merge_pair()`、`merge_mode()`；
  - 通用：`ensure_ytdlp()`、`ensure_ffmpeg()`、`load_config()`、`save_config()`、`clean_path()` 等。
- **备注**：v1.10.8 起校准知识条目级合并核心抽到 `calib_merge_core.py` 纯函数模块，本文件只负责调用；v1.11.0 修复 `_pull_and_merge` 引用的 `_read_sync_text` / `_atomic_write` 两个函数此前**未定义**、导致启动同步长期以 NameError 静默失败的问题。

### 5.2 `video_toolbox_qt.py` —— GUI 界面

- **用途**：程序入口与 Fluent 风格图形界面（PyQt5 + qfluentwidgets）。页面：视频下载、视频库、音视频合并、字幕处理（内嵌引擎）、字幕校准、设置（导航底部唯一全局设置入口）。
- **使用说明**：
  ```bat
  python src\video_toolbox_qt.py            :: 源码运行
  :: 调试钩子（供打包验证 / 截图）
  set VT_GUI_SELFTEST=1 && python src\video_toolbox_qt.py   :: 自检自退
  set VT_SHOT_TAB=字幕校准 && set VT_SHOT_FILE=out.png && python src\video_toolbox_qt.py
  ```
- **线程模型**：后台线程只向 `app.q` 投消息，主线程用 QTimer 泵出后更新控件；退出时经 `aboutToQuit` 挂接 `engine.sync_calib_on_exit` 静默同步校准知识。
- **备注**：`VERSION = "1.11.0"`；DPI 取整 PassThrough，100%–200% 缩放一致；跨屏拖拽按相对位置移动；v1.11.0 起全局 AI 拆为接口 A/B 两条独立通道、设置页新增 ASR 与 AI 校准卡片、字幕校准页新增 AI 校准开关与「再次校准」、字幕处理页预热只导入 `home_interface` 且耗时留痕 `logs\startup.log`。

### 5.3 `calib_merge_core.py` —— 校准知识合并核心

- **用途**：校准知识**条目级三方合并**纯函数模块（v1.10.8 抽出）。供 GUI、退出同步子进程、CI / 脚本共同复用；只做合并，零副作用（不建目录、不联网、不写日志，日志走可注入钩子）。
- **使用说明**（作为库引用）：
  ```python
  import calib_merge_core as core
  merged, added, conflicts = core.merge_calib_script(local, remote, base)
  merged_kb, added, conflicts = core.merge_learned_kb(local_text, remote_text)
  ```
- **合并语义**：纯字面量表按「错形键」合并；CONTEXT_MAP 等按整元组并集；ENTITIES 按 canonical 并入；学习库按「模式|错形」候选合并（计数取大、证据取并集）。冲突保留本地；合并结果必须通过「语法编译 + 实体注册冲突」两道门，任一不过整体放弃。

### 5.4 `calib_ai_agent.py` —— AI 校准 Agent（v1.11.0 新增）

- **用途**：Agent 级字幕校准（无界面、无第三方依赖）。把「基于脚本 subtitle_calib_merged 校准字幕，不允许改变时间轴和格式，仅调整文字内容，一次读不完就自行拆分，最后合并」这套要求实现成可复用的流水线，供界面（`engine.calib_ai_run`）、命令行与自检脚本共用。
- **使用说明**（作为库引用）：
  ```python
  import calib_ai_agent as agent
  res = agent.calibrate(src, out="x.calib.srt", report="x.calib.md",
                        mode_flag="--ko", log=print, chat=my_chat, round_no=1)
  ```
  `chat(prompt, system=None, max_tokens=...) -> str` 由调用方注入（引擎按「校准通道」选用接口 A / B）。
- **八步流程**：① 术语脚本基线（机械部分兜底）→ ② `extract` 抽取 cue 表（剥离时间轴）→ ③ `kb-export --json` 载入知识库并展开成「错形 → 官方名」规则 → ④ 自行分块（条数 + 字符预算双约束）→ ⑤ 逐块 LLM 复校（返回截断/超时自动拆半重试）→ ⑥ 证据校验（改动必须能被知识库解释；行数变化、整句改写、无依据改动一律拒绝并写报告）→ ⑦ 按 cue 边界合并回填（只替换中文行，序号/时间轴/参考行/换行/BOM 一字不动）→ ⑧ 独立校验（调脚本 `verify` 断言结构全一致，不通过即判失败）。
- **再次校准**：`round_no > 1` 时以本轮输出为输入再跑一轮，提示词要求只挑残留错形；界面按 `原名.calib.rN.srt` 命名。
- **备注**：`hiddenimports` 需包含 `calib_ai_agent`（`engine.calib_ai_run` 内延迟导入，静态分析跟踪不到）。自检见 `_selftest_calib_ai.py`。

#### 5.4.1 `apply_vc_official.py` —— 官方新版实现一键套用（v1.11.0 新增）

- **用途**：把官方 VideoCaptioner 新版（`E:\VideoCaptioner`，`app\core\subtitle_processor\`）中两类与"翻译不可用"直接相关的实现套用到内置引擎，幂等、可重复执行：

### 6.1 `ai_client.py` —— 全局 AI 客户端

- **用途**：全局 AI 客户端（v1.11.0 起为**两条独立通道**）。接口 A：工具箱自身（Anthropic Messages 兼容文本 + GLM 视觉识别 + 标题/字幕语言识别）；接口 B：字幕引擎优化/翻译/拆分与 AI 校准（OpenAI 兼容 `/chat/completions`）。另提供 ASR 配置读取与连通性自检。仅依赖 Python 标准库（urllib），无第三方依赖。
- **使用说明**：被 `video_toolbox.py` 以 `ai_mod()` 导入调用；配置持久化在 `data\ai_config.json`。作为库使用：
  ```python
  import sys; sys.path.insert(0, r"tools")
  import ai_client
  print(ai_client.quick_test("a"))            # 接口 A 连通性自检 (ok, 回复信息)
  print(ai_client.quick_test("b"))            # 接口 B 连通性自检
  print(ai_client.asr_test_connection())      # ASR 配置自检
  print(ai_client.channel_config(None, "b"))  # 接口 B 归一化配置（地址/密钥/模型）
  ai_client.detect_language("Hello world")    # 语言识别 -> "en"
  ```
- **关键能力**：`chat_text()` 按通道协议自动分流（A→Anthropic、B→OpenAI 兼容）；`chat_vision()` 图片+文本（屏幕识别）；`detect_language()` 先用本地 Unicode 启发式（假名→ja、谚文→ko、汉字→zh），拉丁语种才调 AI 细分；`channel_config()` / `asr_config()` 提供两条通道与 ASR 的归一化配置（接口 B 密钥留空时回退 A）；`_chat_url()` / `_asr_url()` / `_models_url()` 做地址归一化（裸域名、`/v1`、`/chat/completions` 都能填）；智谱 1305 / overloaded / 429 / 5xx 自动退避重试；视觉模型拥堵自动降级到 `vision_fallback_model`。
- **备注**：`set_enabled(False)` 可强制关闭（对应 `--no-ai`）；`get_client(channel)` / `reset_clients()` 管理两条通道的客户端单例；ASR 配置项 `asr_mode`（service/local）、`asr_base_url/api_key/model/prompt`、`asr_local_model/model_dir`；AI 校准项 `calib_channel`、`calib_chunk_cues`、`calib_max_chars`、`calib_max_tokens`；语言→字幕参数映射（`bili_subtitle_lang` / `ytdlp_sub_langs`）供下载侧按标题语言拉取对应字幕。
