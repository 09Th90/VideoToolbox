## 本版包含

### 架构

- **核心拆分收官**：`src/video_toolbox.py` 由 5475 行降至 **223 行**，退化为纯 facade；
  ASR / 校准 / 下载 / 流水线 / 共享底座 / 翻译六个域全部迁入 `src/core/`
- **自研主题引擎 `vt_fluent` 完成**：QSS 主题引擎、图标引擎、合并 QSS（B0）→
  纯控件族（B1）→ 菜单/反馈/设置卡/窗口导航四族（B2/B3）→ 全量切换 import（B4），
  **qfluentwidgets 运行期残留归零**
- **新增自研并行引擎 `vt_engine`**：config / entities / 执行 / 编排 / threads 五层，
  与旧引擎 API 逐字段对齐，**不 import 任何第三方引擎符号**
- **新增校准实体层 `calib_entity`**：术语实体、lint、adopt、知识库注入与作用域、
  源文件守卫、wiki 客户端

### 缺陷修复

- **下载链路必崩（P0）**：`pipeline.py` 与 `agent_cli.py` 仍引用重构后已不存在的
  `YTDLP_DL_COMMON_ARGS`，导致**链接任务下载阶段与 CLI 下载必抛 AttributeError**。
  已改用 `ytdlp_dl_args()`，并新增引擎符号存在性静态扫描防回归
- **设置可能整体丢失**：配置文件原先直接覆写，进程被强杀 / 断电时留下截断 JSON，
  读取端解析失败即返回空配置（实测 302 个键 → 0）。改为**原子写 + `.bak` 回滚**
- **缩略图串味**：视频信息缩略图原先按文件名 stem 命名，不同目录的同名文件
  （如两部片的 `第01集.mp4`）共用同一缓存，会显示成另一部片的画面。
  改为按**完整路径哈希**派生
- **临时目录膨胀**：PyInstaller 的 `_MEI*` 残留从不清理（实测 29 个目录 648 MB），
  现于启动时清理 7 天前的残留
- **校准学习库写入放大**：原先每条候选都整库落盘一次，改为整批落盘并保留 5 份备份
