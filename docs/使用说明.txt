视频工具箱 v1.10.4 使用说明
==============================

零、全局 AI（字幕语言识别，v1.10.1 起仅保留这一用途）
------------------------------
工具箱接入全局 AI（智谱 GLM），目前只用于一件事：
  · 内容识别：自动识别视频标题的主要语言，下载字幕时按标题语言拉取
    （标题是英文就下英文字幕）。AI 不可用/未启用时回退到多语言全量列表，
    不影响下载本身。
配置位于 data\ai_config.json（已内置默认 Key，开箱即用）：
  · enabled —— true 启用 / false 关闭
  · model   —— 文本模型（默认 glm-4.7-flash）
客户端代码在 tools\ai_client.py（仅标准库依赖）。
v1.10.1 起「B站投稿」板块已整体移除，原先的分区/简介/话题 AI 能力一并下线。

一、运行方式
------------------------------
【图形界面】双击「视频工具箱.exe」（免 Python，推荐）
【脚本方式】双击「视频工具箱.bat」，或用 Python 运行 video_toolbox_qt.py

也可以把链接 / .url 快捷方式直接拖到 exe 上：
  拖链接   → 自动打开下载页并填入链接
  拖文件夹 → 自动打开合并页并填入文件夹

输入框编辑辅助（v1.3.1 新增）：
  所有输入框（视频链接 / 保存位置 / 合并输入输出 / 视频库目录）
  均支持 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。
  连续打字算一步，整段粘贴或选目录算一步，撤销时光标位置一并还原。

二、视频下载（支持并行任务）
------------------------------
1. 粘贴视频链接（支持 YouTube / B 站等 yt-dlp 支持的站点）
2. 选择保存位置：点「浏览…」选文件夹，或直接把文件夹拖进输入框
   · 默认首次为 downloads 文件夹
   · 选定后会长期记住：写入 config.json，下次启动自动填回，不用每次重选
   · 改过一次就一直沿用，直到你再次修改
   · 若该目录当前不存在（如外接硬盘没插），记忆也不会丢，插回后继续可用
3. 点「检测画质」：自动列出 ≥720p 的档位
   规则：同分辨率只保留最大文件；有 60fps 就只留 60fps
4. 点「加入并行下载」：任务会进入「并行下载任务」列表
   勾选「同时下载字幕」（默认开启）会一并下载该视频的字幕：
   包括博主上传的字幕和自动生成字幕，自动转换为 .srt 格式
   （支持中/英/日/韩/西/法/德等多语言）
   · 字幕在视频下载完成后单独拉取，即使字幕接口被风控或没有字幕，
     也只提示一句，不影响视频、封面和信息文件的正常下载
5. 下载期间可以继续粘贴下一个链接、检测画质并加入下载
   每个任务都有独立进度和状态；点击任务可查看对应进度
6. 遇到 B 站等站点的下载风控（HTTP 412）会自动等待重试，
   下载时直接复用「检测画质」的结果，不再重复请求站点，成功率大幅提高
7. 所有后台调用都会隐藏控制台窗口，不会再弹出黑色 yt-dlp / ffmpeg 窗口

三、每个视频自动打包成独立文件夹（v1.3 新增）
------------------------------
下载完成后，每个视频都会在保存位置下单独生成一个文件夹，
文件夹名取自视频标题，里面固定包含：

  某视频标题\
    ├─ 某视频标题.mp4      视频本体（音频始终取最高质量）
    ├─ 封面.jpg            封面图，统一转为 1280x720
    ├─ 视频信息.txt        标题 / 简介 / 视频链接 / 博主主页链接 / 画质 / 下载时间
    └─ *.srt               字幕（若勾选了下载字幕）

说明：
· 封面不论原图是竖版还是超宽，都等比缩放 + 黑边补齐到精确 1280x720，不会拉伸变形
· 多张封面候选时自动取分辨率最高的那张，原始封面图会被清理，只留 封面.jpg
· 视频没有封面时自动跳过，不影响视频下载结果
· 视频信息.txt 使用 UTF-8 with BOM 编码，Windows 记事本直接打开不乱码
· B 站视频若站点未提供博主主页链接，会自动用博主 UID 拼出 space.bilibili.com 链接
· 标题里的非法字符（\ / : * ? " < > | %）会被替换为空格，超长标题截断到 80 字
· 同名视频不会覆盖：已有同名且非空的文件夹时，自动改名为「标题 (2)」「标题 (3)」
· 下载完成后自动打开该视频的独立文件夹

四、视频库（缩略图卡片 + 手动刷新）
------------------------------
1. 默认指向下载页记住的保存位置，可点「浏览…」选择其他文件夹，
   或点「同步下载目录」跟随下载页的保存位置
2. 点「刷新」扫描视频并生成缩略图卡片（打开软件不会自动刷新，避免误扫大目录）
3. 会递归扫描子文件夹，因此每个视频独立文件夹里的视频都能直接看到；
   卡片名显示「文件夹名 \ 文件名」，便于区分不同视频
4. 视频以「缩略图卡片」展示，自动显示视频时长和文件大小
5. 缩略图自动生成并缓存在 data\thumb_cache 文件夹
   缓存名包含完整路径指纹，不同文件夹下的同名视频不会串图
6. 单击卡片直接播放视频；右键卡片打开所在文件夹
7. 视频库刷新只扫描本地文件并用 ffmpeg 抽帧，全程隐藏控制台窗口

五、音视频智能合并
------------------------------
1. 选择输入文件夹（里面放 mp4 + m4a/weba + 可选 srt/ass 字幕）
2. 点「扫描配对」：自动按文件名和时长配对
   m4a 直接封装不转码；weba 自动转 AAC
   SRT 作为软字幕；ASS 可选烧录 / 封装 MKV / 忽略
3. 点「开始合成」，结果输出到「合成结果」文件夹

六、字幕处理（引擎内嵌，v1.10.2 起）
------------------------------
1. 语音转录 / 字幕优化 / 翻译 / 配音 / 合成，由内嵌的字幕引擎承担，
   直接在「字幕处理」页内使用，不弹独立窗口、无需联网下载任何模型
2. 用法：切到「字幕处理」页，拖入视频或粘贴链接即可；生成的字幕文件
   可直接用于本工具箱的「字幕校准」
3. 语音转录引擎可选：必剪、剪映（免费，联网即用）等
4. 字幕翻译：必应、谷歌（免费）；大语言模型（需在设置内配置 API Key）
5. 字幕优化与配音依赖大语言模型，首次使用请到「设置 → 字幕引擎」
   （或点本页右下「打开设置」）填好 API Key；
   不配置只影响优化与配音，转录与翻译照常可用
6. 配置、日志与模型缓存位置：%LOCALAPPDATA%\VideoCaptioner
7. 页面右下「许可与来源…」查看内置第三方组件的许可与来源声明文件

七、设置（v1.10.4 新增，导航底部统一入口）
------------------------------
左侧导航底部的「设置」集中了全部设置项，分两段：
1. 工具设置
   · 下载目录：视频下载的默认保存位置（与下载页联动）
   · 主题 / 界面缩放 / 云母特效：适配不同屏幕与个人偏好
   · 关于：版本号，以及第三方组件许可全文与来源声明的打开入口
2. 字幕引擎
   · 即内嵌字幕引擎的完整设置界面（转录配置 / LLM 配置 / 翻译服务 /
     翻译与优化 / 字幕合成配置 / 保存配置 / 个性化）
   · 首次切到本分段时才加载，故打开设置页本身很快
3. 注：v1.10.2 及更早版本该入口是「字幕处理」页右下角的「引擎设置…」
   对话框，v1.10.4 起并入此处统一管理

八、字幕校准（v1.9.3 新增）
------------------------------
1. 调用统一校准脚本 subtitle_calib_merged.py（随安装包分发到程序目录顶层），
   做名词级术语原位校准：序号/时间轴/空行/换行/BOM 一字不动
2. 选 .srt 文件 → 选片源模式（中英双语/韩语/日语/明日方舟/终末地/
   中文行专属/战双帕弥什/综合OST）→ 点「开始校准」
3. 可选项：长句拆两行（≥14 字在标点处拆，不切官方专名）、
   修正英文/参考行（仅双语模式）、生成改动对照报告（同名 .md）、
   仅统计命中（不写输出文件，先看会改哪些词）
4. 输出默认为同目录「原名.calib.srt」，重名自动加序号，绝不覆盖原字幕

九、目录说明（v1.7 起按功能划分，程序文件夹顶层只有主程序）
------------------------------
视频工具箱.exe        主程序（顶层唯一可执行文件）
subtitle_calib_merged.py  字幕校准统一脚本（「字幕校准」页签调用）
tools\                运行时依赖（已内置，无需联网下载）
  ffmpeg/ffprobe/yt-dlp.exe   下载与剪辑工具
  python\             内嵌 Python 运行时（字幕校准子进程用）
  ai_client.py        全局 AI 客户端（字幕语言识别，仅标准库）
  （字幕引擎已内嵌进主程序 exe，docs\ 下保留其许可与来源声明）
src\                  源代码与脚本启动器
  video_toolbox.py        核心引擎源码
  video_toolbox_qt.py     界面源码（Fluent 风格）
  视频工具箱.bat          脚本版启动器（需要电脑装有 Python 3）
  _selftest_*.py          各项离线自检脚本（可选）
docs\                 使用说明、界面预览与第三方组件声明
  VideoCaptioner_GPL-3.0.txt     VideoCaptioner 的 GPL-3.0 许可全文
  VideoCaptioner_组件来源.txt    第三方组件来源与许可清单
data\                 用户数据（自动生成，不随安装包分发、卸载不删除）
  config.json         保存位置等设置
  downloads\          默认下载目录
  thumb_cache\        视频库缩略图缓存
logs\                 日志目录（gui_errors.log 界面异常记录）

自检方式（不联网、不下载视频，仅在临时目录验证，在 src 目录执行）：
  python _selftest_pack.py
  python _selftest_gui.py
  python _selftest_vc.py
  python _selftest_e2e.py

注意：exe 未做代码签名，部分开启了 Device Guard / 应用控制策略
的电脑会被拦截，此时请改用脚本方式运行。
