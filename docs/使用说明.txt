@version 1.15.0
视频工具箱 v1.15.0 使用说明
==============================

零、全局 AI（v1.12.0 起只有一套配置，全程序共用）
------------------------------
工具箱用到的 AI 收敛为**一套**配置（OpenAI 兼容），填一次、三处生效：
工具箱自身（视频标题 / 语言识别、视觉识别）、字幕引擎（优化 / 拆分 / 翻译）、
以及「字幕处理」页内「字幕校准」子板块的 AI 校准。保存后立即写入字幕引擎，
不再需要分别填写。
（v1.11.0 的「接口 A / 接口 B」双通道已在 v1.12.0 合并；旧配置在启动时自动
迁移，无需手动处理。）

「设置 → 全局 AI」里可填：
  · 启用 AI       —— 总开关；关闭后依赖大模型的优化 / 配音等能力不介入
  · 密钥          —— API Key
  · 接口地址      —— 如 https://open.bigmodel.cn/api/paas/v4
                     兼容 OpenAI / DeepSeek / Gemini 兼容层 / Ollama / Azure 等；
                     填到域名或版本段均可自动补全（Azure 填到 deployments/<部署名>）
  · 文本模型      —— 如 glm-4.7-flash
  · 视觉模型      —— 如 glm-4.6v-flash（截图识别类能力用）

两个按钮：「测试接口」验证连通性，「保存并应用」立即生效。

配置实体位于 data\ai_config.json（首次使用需在「设置 → 全局 AI」填入
自己的密钥；密钥只保存在本机该文件，不随程序分发、不上传）：
  · enabled / api_key / base_url / model / vision_model  —— 全局 AI（全程序共用）
  · asr_*         —— ASR 语音识别（见下）
  · calib_*       —— AI 校准参数（分块条数 / 字符预算 / 输出上限 / 校准风格）
客户端代码在 tools\ai_client.py（仅标准库依赖）。

零之二、ASR 语音识别（v1.11.0 新增：可接入独立的 ASR 模型）
------------------------------
「设置 → ASR 语音识别（转录配置）」里可选两种转录模型来源，保存后立即写入
字幕引擎的「转录配置」，不用再进引擎设置里手改：

  · 自有 ASR 服务（推荐）：填接口地址（填到 /v1 即可，自动补
    /audio/transcriptions）、密钥、模型名（如 FunAudioLLM/SenseVoiceSmall、
    whisper-1 等任 OpenAI 兼容 ASR 服务）与可选识别提示词。
    保存后转录模型自动切到「Whisper [API]」，语音识别交给这套服务完成。
  · 本地独立模型：填模型名（如 large-v3、large-v3-turbo，或自训练/微调后的
    模型目录名）与模型目录（留空用软件内 data\VideoCaptioner\models）。
    保存后转录模型切到「FasterWhisper」，并优先使用你指定的模型与目录。

「测试 ASR 配置」按钮会校验服务连通性（服务模式）或模型与目录是否就绪
（本地模式）。注意：本地模式需要机器上具备 faster-whisper 运行环境与对应
模型文件（可在引擎设置里下载），服务模式则完全免下载模型。

v1.10.1 起「B站投稿」板块已整体移除，原先的分区/简介/话题 AI 能力一并下线。

一、运行方式
------------------------------
【图形界面】双击「视频工具箱.exe」（免 Python，推荐）
【脚本方式】双击「视频工具箱.bat」，或用 Python 运行 video_toolbox_qt.py

也可以把链接 / .url 快捷方式直接拖到 exe 上：
  拖链接   → 自动打开下载页并填入链接
  拖文件夹 → 自动打开合并页并填入文件夹

输入框编辑辅助（v1.3.1 新增）：
  所有输入框（视频链接 / 保存位置 / 合并输入输出 / 视频库目录）
  均支持 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。
  连续打字算一步，整段粘贴或选目录算一步，撤销时光标位置一并还原。

在线安装太慢怎么办？（v1.12.0 新增）
------------------------------
安装向导已固定为简体中文（v1.14.1 起不再弹出语言选择框，全程中文界面）。
在线安装器要从 GitHub Pages（海外）下载几个组件包，共约 104MB。国内直连
常常只有几十 KB/s、甚至完全连不上——慢的是这条国际链路，不是程序本身的问题。
按下面三档挑一个，通常立刻见效：

1) 有源码仓库 / 内网分发 → 走内网源，秒级装完（推荐）
     · 本机装：在含 installer_src\ 的目录里执行
         python installer_src\install_local_repo.py
       脚本会自动起内网仓库服务并拉起安装器（104MB 走本机，实测约 1 秒）。
     · 给同事装：在放着在线仓库的那台机器上执行
         python installer_src\repo_server.py 8123
       把打印出来的局域网地址交给对方，用命令行装：
         视频工具箱_在线安装_v1.15.0.exe --set-temp-repository http://192.168.1.10:8123/

2) 有代理软件 → 打开「系统代理」再装
     安装器默认使用 Windows 系统代理：先在 FlClash / Clash 里打开系统代理
     （端口一般 127.0.0.1:7890），再重新运行安装器即可。
     不想动系统代理，也可以临时指定别的源：
       视频工具箱_在线安装_v1.15.0.exe --set-temp-repository <可用的镜像地址>

3) 网络实在不稳 → 直接用离线安装包
     视频工具箱_Setup_v1.15.0.exe（约 0.55GB）一次下载、装完不再联网拉组件。
     注意：离线包同样放在 GitHub 上；若 GitHub 本身就慢，只有方案 1 是快路。

安装器「设置」页会列出全部可用仓库源：取消勾选慢的、勾选快的即可切换，
顺序即优先级（IFW 取第一个可用的源）。

二、视频下载（支持并行任务）
------------------------------
1. 粘贴视频链接（支持 YouTube / B 站等 yt-dlp 支持的站点）
2. 选择保存位置：点「浏览…」选文件夹，或直接把文件夹拖进输入框
   · 默认首次为 downloads 文件夹
   · 选定后会长期记住：写入 config.json，下次启动自动填回，不用每次重选
   · 改过一次就一直沿用，直到你再次修改
   · 若该目录当前不存在（如外接硬盘没插），记忆也不会丢，插回后继续可用
3. 点「检测画质」：自动列出 ≥720p 的档位
   规则：同分辨率只保留最大文件；有 60fps 就只留 60fps
4. 点「加入并行下载」：任务会进入「并行下载任务」列表
   勾选「同时下载字幕」（默认开启）会一并下载该视频的字幕：
   包括博主上传的字幕和自动生成字幕，自动转换为 .srt 格式
   （支持中/英/日/韩/西/法/德等多语言）
   · 字幕在视频下载完成后单独拉取，即使字幕接口被风控或没有字幕，
     也只提示一句，不影响视频、封面和信息文件的正常下载
5. 下载期间可以继续粘贴下一个链接、检测画质并加入下载
   每个任务都有独立进度和状态；点击任务可查看对应进度
6. 遇到 B 站等站点的下载风控（HTTP 412）会自动等待重试，
   下载时直接复用「检测画质」的结果，不再重复请求站点，成功率大幅提高
7. 所有后台调用都会隐藏控制台窗口，不会再弹出黑色 yt-dlp / ffmpeg 窗口

三、每个视频自动打包成独立文件夹（v1.3 新增）
------------------------------
下载完成后，每个视频都会在保存位置下单独生成一个文件夹，
文件夹名取自视频标题，里面固定包含：

  某视频标题\
    ├─ 某视频标题.mp4      视频本体（音频始终取最高质量）
    ├─ 封面.jpg            封面图，统一转为 1280x720
    ├─ 视频信息.txt        标题 / 简介 / 视频链接 / 博主主页链接 / 画质 / 下载时间
    └─ *.srt               字幕（若勾选了下载字幕）

说明：
· 封面不论原图是竖版还是超宽，都等比缩放 + 黑边补齐到精确 1280x720，不会拉伸变形
· 多张封面候选时自动取分辨率最高的那张，原始封面图会被清理，只留 封面.jpg
· 视频没有封面时自动跳过，不影响视频下载结果
· 视频信息.txt 使用 UTF-8 with BOM 编码，Windows 记事本直接打开不乱码
· B 站视频若站点未提供博主主页链接，会自动用博主 UID 拼出 space.bilibili.com 链接
· 标题里的非法字符（\ / : * ? " < > | %）会被替换为空格，超长标题截断到 80 字
· 同名视频不会覆盖：已有同名且非空的文件夹时，自动改名为「标题 (2)」「标题 (3)」
· 下载完成后自动打开该视频的独立文件夹

四、视频库（缩略图卡片 + 手动刷新）
------------------------------
1. 默认指向下载页记住的保存位置，可点「浏览…」选择其他文件夹，
   或点「同步下载目录」跟随下载页的保存位置
2. 点「刷新」扫描视频并生成缩略图卡片（打开软件不会自动刷新，避免误扫大目录）
3. 会递归扫描子文件夹，因此每个视频独立文件夹里的视频都能直接看到；
   卡片名显示「文件夹名 \ 文件名」，便于区分不同视频
4. 视频以「缩略图卡片」展示，自动显示视频时长和文件大小
5. 缩略图自动生成并缓存在 data\thumb_cache 文件夹
   缓存名包含完整路径指纹，不同文件夹下的同名视频不会串图
6. 单击卡片直接播放视频；右键卡片打开所在文件夹
7. 视频库刷新只扫描本地文件并用 ffmpeg 抽帧，全程隐藏控制台窗口

五、音画合并（v1.13.0 并入「视频下载」页）
------------------------------
1. 在「视频下载」页顶部分段切到「音画合并」
2. 选择输入文件夹（里面放 mp4 + m4a/weba + 可选 srt/ass 字幕）
3. 点「扫描配对」：自动按文件名和时长配对
   m4a 直接封装不转码；weba 自动转 AAC
   SRT 作为软字幕；ASS 可选烧录 / 封装 MKV / 忽略
4. 点「开始合成」，结果输出到「合成结果」文件夹

六、字幕处理（引擎内嵌，v1.10.2 起；v1.13.0 起含「字幕翻译 / 字幕校准」工作台分段）
------------------------------
0. 速度（v1.11.0）：进入本页不再有数秒卡顿——引擎在程序启动后即后台预热，
   实测界面构建 0.7 秒级；若确实遇到卡顿，可查看 logs\startup.log 里各阶段
   耗时（预热 / 引擎界面构造）留痕，便于定位
1. 语音转录 / 字幕优化 / 翻译 / 配音 / 合成，由内嵌的字幕引擎承担，
   直接在「字幕处理」页内使用，不弹独立窗口、无需联网下载任何模型
2. 用法：切到「字幕处理」页，拖入视频或粘贴链接即可；生成的字幕文件
   可直接用于本页「字幕校准」分段（工作台顶部分段切换）
3. 语音转录引擎可选：必剪、剪映（免费，联网即用）等；
   v1.11.0 起还可在「设置 → ASR 语音识别」把转录指向**自有 ASR 服务**
   （任何 OpenAI 兼容接口）或**本地独立模型**，保存后本页转录模型自动切换
4. 字幕翻译：默认用「LLM 大模型翻译」（走设置里的接口 B，质量最好、不依赖
   被墙/已下线的免费端点）；也可选 必应 / 谷歌 / DeepLx（免费）。
   注意：微软翻译的取 token 端点官方已下线（404）、谷歌翻译在国内网络通常
   不可达——这三个免费服务的调用已按官方新版实现照抄（端点 / 参数 / 语言
   映射一致），选了它们若失败，程序会自动改用 LLM 翻译并把原因记在
   logs\vc_fallback.log，不会再整链报「优化失败」
5. 字幕优化与配音依赖大语言模型，首次使用请到「设置 → 全局 AI（LLM）」
   （或点本页「打开设置」）填好并保存；不配置只影响优化与配音，转录与翻译照常可用
6. 配置、日志、模型缓存与工作目录统一在软件文件夹 data\VideoCaptioner\ 下，
   不再写 %LOCALAPPDATA%（C 盘）
7. 页面右下「许可与来源…」查看内置第三方组件的许可与来源声明文件

七、设置（导航底部唯一全局入口，v1.10.8 起不再分段）
------------------------------
左侧导航底部的「设置」是全程序唯一的设置入口，一页纵向排开：
1. 目录
   · 下载目录：视频下载的默认保存位置（与下载页联动）
   · 数据根目录：全部运行期文件的根，默认在软件文件夹，可整体改到别处
   · 引擎工作目录：字幕引擎任务产物位置，只读、固定在软件文件夹（不落 C 盘）
2. 全局 AI：一套 OpenAI 兼容配置（密钥 / 接口地址 / 文本模型 / 视觉模型）
   全程序共用，可点「测试接口」验证；保存后立即写入字幕引擎
3. ASR 语音识别（转录配置）：转录模型来源——自有 ASR 服务（OpenAI 兼容接口）
   或本地独立模型（模型名 + 模型目录），保存后自动写入引擎「转录配置」
4. AI 校准（Agent 级）：每块最多条数、每块字符预算、单次最大输出 token、
   校准风格（术语级 / 整句重写）——决定 AI 校准一次处理多少内容、改到什么程度；
   用哪套 AI 由上面的「全局 AI」统一决定，不再单独选通道
5. 字幕引擎：转录 / 翻译 / 合成等运行参数（LLM 与保存位置已上收全局，不在此重复）
6. 校准知识同步：自动同步开关与「立即更新」（上传在退出时后台完成，无按钮）
7. 界面：主题 / 界面缩放 / 云母特效
8. 关于：版本号，以及第三方组件许可全文与来源声明的打开入口
注：v1.10.8 起取消「工具设置 / 字幕引擎」分段与独立引擎设置对话框，
全部收敛到这一个全局设置页。

八、字幕校准（v1.9.3 新增；v1.11.0 起支持 Agent 级 AI 校准；v1.13.0 起并入「字幕处理」页工作台分段）
------------------------------
1. 在「字幕处理」页的工作台顶部分段切到「字幕校准」
   （v1.13.0 起「字幕处理」页不再有一级概览分段；「字幕校准」与
   「任务创建 / 语音转录 / 字幕翻译 / 字幕视频合成」并列在工作台分段里）
2. 调用统一校准脚本 subtitle_calib_merged.py（随安装包分发到程序目录顶层），
   做名词级术语原位校准：序号/时间轴/空行/换行/BOM 一字不动
3. 选 .srt 文件 → 选片源模式 → 点「开始校准」
   片源模式（v1.10.5 起与脚本实际支持的全部模式对齐，共 12 项）：
     中英双语（默认） / 日语原声·鸣潮 / 日语原声·终末地 / 韩语原声·鸣潮 /
     明日方舟 / 明日方舟·韩语 / 终末地 / 中文行专属 /
     战双帕弥什 / 战双英文原声 / 综合手游OST / 音乐点评
4. 可选项：修正英文/参考行（--fix-en，仅双语模式）、
   生成改动对照报告（同名 .md）、
   仅统计命中（不写输出文件，先看会改哪些词）
5. 输出默认为同目录「原名.calib.srt」，重名自动加序号，绝不覆盖原字幕
6. 注：v1.10.4 及更早版本有「长句拆两行（--layout）」开关，v1.10.5 起该功能
   已由脚本侧移除，界面同步去掉该开关（实测无效选项，留着只会误导）

【AI 校准（Agent 级，v1.11.0 新增）】
开启「AI 校准」开关后，点「开始校准」就不再只是跑一遍机械术语表，而是等于
向一个 Agent 下达这样的要求：「基于脚本 subtitle_calib_merged 校准字幕，
不允许改变时间轴和格式，仅调整文字内容，如果一次无法读取完整，就自行拆分，
最后合并」。它会依次完成：

  ① 术语脚本基线：先跑一遍脚本，官方术语表命中的部分必定正确（兜底）；
  ② 抽取 cue 表：把 SRT 抽成「序号 / 中文行 / 参考行」，剥离时间轴等结构；
  ③ 载入知识库：调脚本 kb-export 取出全部对象级实体，展开成
     「错形 → 官方名」规则与负向排除规则；
  ④ 自行分块：按「每块条数 / 字符预算」切块，返回被截断或超时自动拆半重试；
  ⑤ 逐块复校：用你配置的 AI（通道见「设置 → AI 校准」，可选接口 A 或 B）
     逐块判定，只允许名词级替换；
  ⑥ 证据校验：每处改动必须能被知识库解释（或替换目标命中官方名），无法解释
     的提议会被拒绝并写进报告，绝不让模型自由改写句子；行数变化一律拒绝；
  ⑦ 合并回填：按 cue 边界重建 SRT——只替换中文行，序号 / 时间轴 / 参考行 /
     换行 / BOM 一字不动；
  ⑧ 独立校验：再调脚本 verify 做第三方断言（cue 数、序号、时间轴、参考行、
     CRLF、BOM 全一致），不通过即判失败并保留日志。

  · 报告：勾选「生成改动对照报告」会写同名 .md，内含每处改动的
    序号 / 原文 / 校准后 / 依据，以及被拒绝的模型提议与原因（便于人工复核；
    标 ⚠ 的是知识库尚未收录的疑似新错形，可后续用 learn 沉淀）
  · 「再次校准」：以上一轮的输出为输入再跑一轮，专挑残留错形，输出
    `原名.calib.r2.srt`、`原名.calib.r3.srt`…… 可连续点，直到满意为止
  · AI 校准开启时「仅统计术语命中」会自动关闭（AI 校准需要产出文件）
  · 未配置 AI（或接口不可用）时请关闭本开关，用原来的纯脚本校准即可

八之二、字幕编辑（打轴，新增）
------------------------------
在程序里直接播放视频、看着画面把字幕的起止时间对齐，不必再在播放器和文本
编辑器之间来回切。结构参照 Nosub / Subtitle Composer 的做法：画面 + 字幕表
+ 波形时间轴，每一步改动都可撤销。

注意：本页是 v1.12.2 之后新增的功能，v1.12.2 及更早的安装包中没有这一页。

【首次使用：装一次播放组件】
本页画面由 libmpv 提供（**LGPL 构建**、动态链接）。出于许可与体积考虑，它
不随安装包分发，需要时拉取一次（约 40MB）——在程序目录执行：
    python tools\download_open_source_deps.py --only mpv
或到发布页手动下载 libmpv-2.zip，解压到 tools\mpv\。
未安装时本页只提示一句、不会报错崩溃，字幕表的查看与编辑不受影响。

【界面】
  · 工具条：打开视频 / 打开字幕 / 保存 / 另存为 · 播放（暂停）· ◀ 帧 / 帧 ▶ ·
    倍速下拉 · 右侧时间码
  · 编辑条：切分 / 合并 / 删除 / 插入 / 取起点 [ / 取终点 ] / 前移 0.1s /
    后移 0.1s · 撤销 / 重做（每个按钮都有悬停提示，写着对应快捷键）
  · 上半区（左右可拖分隔）：左侧画面，右侧字幕表（序号 / 起点 / 终点 / 时长 / 文本）
  · 下半区：波形时间轴——灰波形上叠着字幕块，直接拖块就能改时间
  · 底部状态栏：视频名 / 字幕名 / 条数与字数 / 重叠与过短条数 / 编码与换行 /
    当前缩放 / 「● 未保存」

【基本流程】
1. 「打开视频」→ 画面加载，同时后台解析音频波形（首次显示进度条，之后走缓存）
2. 「打开字幕」→ 载入 .srt；提示会写明条数、源编码（UTF-8 / GBK…）与换行（CRLF / LF）
3. 边看边对：拖波形上的字幕块改时间；在波形上双击可在该处切分；表格里双击可改
   起点 / 终点 / 文本（时间按 时:分:秒.毫秒 填，如 00:01:23.456；文本中的换行
   在表格里显示为 " / "）
4. 「保存」写回原文件；「另存为」另存一份

【快捷键】（焦点在本页时生效，表格里正在打字时方向键照常给文本框）
  空格                    播放 / 暂停
  , .                     后退 / 前进一帧（← → 同效）
  Shift+← / →             选中字幕整体前移 / 后移 100ms
  Alt+← / →               前移 / 后移 1s
  ↑ / ↓                   上一条 / 下一条，并把播放头跳过去
  [ / ]                   把选中条目的起点 / 终点设为播放头当前位置
  Ctrl+K                  在播放头处切分（等于在波形上双击）
  Del                     删除选中条目（表格可多选，一并删除）
  Ctrl+Z                  撤销      Ctrl+Y / Ctrl+Shift+Z 重做
  Ctrl+S                  保存      Ctrl+Shift+S 另存为
  Ctrl+O                  打开视频  Ctrl+Shift+O 打开字幕
  Ctrl+= / Ctrl+- / Ctrl+0   时间轴放大 / 缩小 / 缩放到整轨
  Ctrl+Shift+F            缩放到选中条目所在区间

【安全设计】
  · 撤销 100 步；拖动改时间也算一步（拖之前先存快照，撤销可精确回到拖动前）
  · 保存时若目标文件已存在且没有同名 .bak，先自动备份一份，改错能回退
  · 打开新视频 / 新字幕前若有未保存改动，会先问一句「放弃改动？」
  · 切分或取边界若会让某条短于一帧（40ms），操作被拒绝并提示，不会写出坏数据
  · 时间一律按整数毫秒处理；序号、时间轴格式、换行（CRLF/LF）与 BOM 全部原样保留
  · 切到别的页面自动暂停播放；退出程序时释放播放组件，不留临时目录残留

九、校准知识同步（v1.12.2：界面只有「立即更新」，上传全自动藏在后台）
------------------------------
不同用户使用中会沉淀出不一样的校准内容（术语表、实体、上下文规则、
学习库候选）。程序把它们收集起来在用户之间共享，最终收敛到全体内容的
并集。用户侧只有一个动作：

  · 更新：启动时后台自动执行，设置页可点「立即更新」。从共享仓库拉取
    全体使用者沉淀，与本地做条目级三方合并（本地缺失直接采用远程；
    双方各自新增都能并入；同一处双方改不同内容→保留本地并记冲突日志），
    合并是确定性幂等的，多用户互不覆盖。

上传对你完全无感、不在界面出现任何按钮：
  · 校准 learn 实时将本次确认的候选写进本机学习库；
  · 退出程序时自动派生隐藏子进程，把「校准脚本 + 学习库」先拉远程合并
    再推回共享仓库（不阻塞退出、不弹窗），下次启动即出现在其他用户的
    「更新」里；
  · GitHub 连接参数（owner/repo/branch/同步文件清单/token）由维护者本机的
    github_proxy.yaml vt-github 段提供（该文件属维护者本机配置，不随包分发）。

可选增强（局域网共享盘环境）：管理员用 kb_admin.exe init 建好更新库
（baseline.json + inbox/）后，把机器指过去（VT_SYNC_ROOT），工具箱会
在原有 GitHub 通道之外叠加条目级增量通道：learn 实时把本次新增上传到
自己的收件箱（只新建文件、绝不改写他人内容；本机台账保证只传没传过的），
启动更新同时合并基线与全部增量。未配置时该通道自动停用，不影响 GitHub。

关闭同步：设置页关掉「启用自动同步」（持久生效），或环境变量
VT_NO_CALIB_SYNC=1（临时）。日志统一写 logs\calib_sync.log。

9.1 管理员侧（完全独立程序 kb_admin.exe）
------------------------------
更新库的服务器侧管理全部在根目录的独立程序 kb_admin.exe（源码
kb_admin.py，不 import 工具箱任何模块；exe 与 github_proxy.yaml、
subtitle_calib_merged.py 同级摆放即自动读取内置连接配置）：

  · init            由脚本内置知识生成首版基线 baseline.json（AST 静态读表）
  · status          盘点更新库：基线/各客户端增量/全局生效/冲突/可回收预览
  · collect         收编收集渠道：从 GitHub 收集分支（工具箱退出自动上传处）
                    拉回学习库，confirmed 候选转成条目写进更新库收件箱
                    （幂等去重，重复跑不产生重复）
  · compact         折叠全部增量进新基线（淘汰失效条目，归档只移不删）
  · prune           回收超龄且已无贡献的收件箱文件（leave-one-out 无损判定，
                    默认 dry-run，执行也只 move 到 archive、不物理删除）
  · publish / pull  更新库 ⇄ GitHub 专用分支（供各机器 pull 镜像）
  · cycle           collect → compact → prune → publish 一条链（定期维护）
  · serve           把更新库起成局域网 HTTP 只读镜像
  · selftest        隔离环境端到端断言（init→上传→compact→prune 全链）

详见 docs\校准知识增量同步_管理员手册.md。

十一、数据目录（v1.10.6 新增：运行期文件不写系统盘）
------------------------------
程序运行中产生的全部文件——配置、下载、缩略图缓存、日志、临时文件，以及
字幕引擎的配置与缓存——统一存放在「数据根目录」下，默认就是程序所在目录
（即整个程序绿色便携，拷走文件夹即带走全部数据），不会写入系统盘（C 盘）。

想改到别处（例如数据想放 D 盘、程序放 C 盘只读目录）：
  设置 → 目录 → 数据根目录，填入或选择目标文件夹后点「应用」。
  程序会把现有 data\ 与 logs\ 的内容迁移过去（同名文件保留新位置的值），
  并在程序目录生成 data_dir.txt 记录新位置；重启后完全生效。
  「还原默认」可切回程序目录。

优先级：环境变量 VT_DATA_ROOT > data_dir.txt > 程序目录默认值。

v1.10.8 起：全程序只有「设置」这一个全局设置入口，不再有字幕引擎的独立
设置；字幕引擎的工作目录（任务产物）也被强制固定在数据根下的
data\VideoCaptioner\work-dir，历史上写到 C 盘（C:\Users\…\VideoCaptioner）
的默认位置会在启动时自动改回软件文件夹，无需手动处理。

说明：若检测到旧版曾在系统盘存放的字幕引擎数据，程序会在启动时自动迁移
到数据目录（兼容旧版多套一层同名子目录的布局，迁移后会把残留的空目录
一并回收）。只有当旧位置确实还存在数据目录里没有的文件时，设置页才会
提示残留位置，确认无用后自行删除即可。

程序自身的数据根目录同样不写系统盘；安装/打包过程使用的构建环境与
打包工具放在程序目录之外的独立位置，不影响运行期。


自检方式（不联网、不下载视频，仅在临时目录验证，在 src 目录执行）：

  python _selftest_vc.py

  python _selftest_calib_ai.py     # AI 校准 Agent：解析/回填、规则展开、
                                   # 改动校验与端到端流水线（用假模型，不联网）
