视频工具箱 v2.6.0 使用说明
==============================

这是一份快速速查。完整说明见 docs\程序说明书(用户版).md。

零、安装与首次启动
------------------
· 离线包 VideoToolbox_Setup_v2.6.0.exe，约 1.0GB；在线安装器只下载缺失文件。
· 默认安装到 D:\VideoToolbox，可以改；不需要管理员权限。
· v2.6.0 起为 onedir 形态：安装目录含 视频工具箱.exe 和 _internal\，
  不要只复制 exe。
· 首次启动会按需下载 FFmpeg、yt-dlp、Deno、ASR 模型、libmpv 等。
· 运行日志在 logs\；用户数据在 data\。

一、全局 AI（可选）
------------------
设置 → 全局 AI：
  · 启用 AI      总开关
  · 密钥         API Key（保存在 data\credentials.json，只读）
  · 接口地址     OpenAI 兼容地址
  · 文本模型     文本理解/校准/标题
  · 视觉模型     截图识别、B 站分区/话题
  · 测试接口     验证连通性
  · 保存并应用   立即生效

没有密钥也能用：下载、合并、语音转录、机器翻译、脚本校准、字幕合成、
字幕编辑、流水线（不开 AI 校准）。
需要 AI：AI 校准、AI 托管、B 站分区/话题自动识别。

二、视频处理：下载与合并
------------------------
下载：
  · 粘贴链接，选清晰度（只列 720p 及以上，第一项「最高，推荐」）。
  · 可同时下载字幕并转 SRT；支持并行与取消。
  · 默认保存到 data\downloads。
  · Cookie 在 设置 → 下载 Cookie（反风控）：自动/浏览器读取/
    cookies.txt/游客，支持 8 种浏览器。
  · 代理由后台兜底，界面无开关。

音画合并：
  · 自动配对支持 mp4/mkv/webm/mov + m4a/weba + srt/ass。
  · 默认输入 D:\剪辑，输出留空→输入目录\合成结果。
  · ASS 字幕默认烧录为硬字幕，可改 MKV 封装或忽略。
  · 手动合并：视频必填、音频必填、字幕可选。

三、视频库
----------
· 启动后自动扫描下载目录，缩略图取第 5 秒。
· 单击：打开所在文件夹并用系统播放器播放；右键：只开文件夹。
· 缓存 data\thumb_cache，可删，程序会重建。

四、语音转录
------------
字幕处理 → 语音转录：
  · 选择音视频；模型来源用设置里的 ASR 配置，或临时选 ASR。
  · 识别语言默认自动；已知语言时手动指定更稳。
  · 需要区分说话人时勾选「说话人分离」。
  · 语音分离当前只有入口，不内置分离模型。
  · 说话人分轨在字幕编辑导出时选择「按说话人拆分」。

五、字幕翻译
------------
· 服务：微软（默认）、谷歌、DeepLx；当前不提供 LLM 翻译。
· 排布：译文在上（默认）、原文在上、仅译文、仅原文。
· 双语片源的中英顺序不影响校准：校准按字符集识别中文行。
· 翻译后可做声纹筛选。

六、术语校准
------------
为什么：机翻最容易错专有名词，校准只改文字，把名字统一回官方写法。

两种方式：
  · 脚本校准：术语表 + 上下文正则，先跑，快且可重复。
  · AI 校准：脚本跑完后，让 AI 逐块复核；要消耗你的 AI 额度。

界面片源类型（命令行旗标）：
  中英双语（--bi，默认）        日语原声·鸣潮（--ja）
  日语原声·终末地（--jpe）      韩语原声·鸣潮（--ko）
  明日方舟（--ak）              明日方舟·韩语（--akko）
  终末地（--endo）              终末地·中英双语（--endobi）
  终末地·韩语原声（--endoko）   中文行专属（--zho）
  战双帕弥什（--pgr）           战双英文原声（--pgren）
  综合手游 OST（--wwoc）        音乐点评（--react）

命令行另有：塞尔达 --zel、崩坏星穹铁道 --hsr、宝可梦 --pkm。

保证：
  · 序号、时间轴、空行、换行符、BOM 原样。
  · 只改中文行；参考行默认不动（仅 --fix-en 可修）。
  · 校准后请抽查；片源模式选错会误伤。

知识同步：
  设置 → 校准知识同步：启用自动同步（启动更新、退出上传）或立即更新。
  只同步规则文本，不上传视频/字幕。

七、字幕编辑
------------
· 支持 SRT/VTT/ASS/SSA 读取，导出 SRT/ASS。
· 快捷键：
    空格 播放/暂停
    , . ← → 逐帧
    Shift+←/→ 0.1 秒
    Alt+←/→ 1 秒
    ↑↓ 上/下一条
    [ ] 取起点/终点
    Ctrl+K 切分
    Ctrl+A 全选；Del 删除
    Ctrl+Z 撤销；Ctrl+Y/Ctrl+Shift+Z 重做
    Ctrl+S 保存；Ctrl+Shift+S 另存
    Ctrl+O 打开视频；Ctrl+Shift+O 打开字幕
    Ctrl+= / - / 0 缩放
    Ctrl+Shift+F 适配选中
· 撤销 100 步；最小边界 40ms；状态栏提示重叠/过短。
· 内嵌字幕=软封装；烧录=重编码。

八、流水线
----------
· 链接链：下载 → 翻译 → 校准 → 二次校准 → 成品。
· 下载目录监控：盯住下载目录的新视频，自动走同一条链。
· 自动默认开；并发 1–8，默认 3。
· 进度保存 data\pipeline_state.json；重启后 DONE 跳过、RUNNING 转 READY。
· 有「立即扫描/重试失败项/清空任务进度」。

九、自动化：B 站投稿
--------------------
前提：浏览器已登录 B 站；已配置全局 AI；先采集模板。
· 13 张模板＝10 必需＋3 可选（参与话题、第一张候选封面、
  创作声明「自制」）。
· 采集：选窗口 → 抓帧 → 框选 → 存为该模板；页面显示 ✓/✗。
· 表单：视频、标题、简介、标签、分区、话题；
  「从 视频信息.txt 读取」会在当前目录和上一级查找。
· 默认演练；关闭演练才真正提交。
· 后台线程执行；失败截图在 data\bili_upload\shots。
· v2.6.0 新增 CLI 后台投稿（仅源码方式，安装包不含）：
    tools\python\python.exe src\bili_auto_submit.py "<素材目录>" --dry-run
    tools\python\python.exe src\bili_auto_submit.py "<素材目录>" --visibility self
    tools\python\python.exe src\bili_auto_submit.py --probe

十、AI 托管
-----------
· 条件出现的页面；需要本机部署托管引擎（约 2.2GB，不随安装包）。
· 状态/任务/运行输出三卡片；工作区=程序根；数据在 data\harness-home。
· 未就绪时显示部署引导，不影响其他功能。

十一、设置页顺序
----------------
目录 → 下载 Cookie → 全局 AI → ASR 语音识别 → AI 校准 →
字幕引擎 → 校准知识同步 → 程序更新 → 界面美化 → 界面 → 关于。

十二、文件、备份、更新、卸载
----------------------------
安装目录：默认 D:\VideoToolbox，含 视频工具箱.exe、_internal\、
  tools\、docs\、src\。
data\：ai_config.json、credentials.json、config.json、
  subtitle_style.json、ui_custom.json、videocaptioner\settings.json、
  downloads\、thumb_cache\、tmp\、pipeline_state.json、
  bili_upload\shots\、harness-home\。
logs\：运行日志。

建议备份：
  data\ai_config.json、data\credentials.json、
  data\subtitle_style.json、data\ui_custom.json、
  subtitle_learned_kb.json、data\calib_sync*（如用同步）。

更新：设置 → 程序更新 → 检查更新；增量下载，按 sha256 校验。
  同版本可「修复安装」；失败时用离线包覆盖安装。
卸载：Windows 应用列表或开始菜单卸载。卸载不删 data\、logs\ 和下载文件；
  彻底清理需手动删除安装目录。

十三、命令行（源码方式）
------------------------
统一 CLI：
  tools\python\python.exe src\agent_cli.py status --json
  tools\python\python.exe src\agent_cli.py info "<视频>"
  tools\python\python.exe src\agent_cli.py download "<链接>" --height 1080
  tools\python\python.exe src\agent_cli.py transcribe "<视频>" --lang ja
  tools\python\python.exe src\agent_cli.py translate "<字幕>" --engine bing
  tools\python\python.exe src\agent_cli.py calibrate "<字幕>" --endobi
  tools\python\python.exe src\agent_cli.py stabilize "<字幕>"
  tools\python\python.exe src\agent_cli.py audit "<字幕>"
  tools\python\python.exe src\agent_cli.py compose "<视频>" "<字幕>" --mode burn
  tools\python\python.exe src\agent_cli.py bili-submit "<素材目录>" --dry-run

校准脚本：
  tools\python\python.exe subtitle_calib_merged.py "<字幕>" --out "<输出>" --endobi
  tools\python\python.exe subtitle_calib_merged.py verify "<源>" "<成品>"
  tools\python\python.exe subtitle_calib_merged.py length "<成品>"
  tools\python\python.exe subtitle_calib_merged.py --help

源码运行：需要 Python 3.12，必须在仓库根运行：
  pip install -r requirements.txt
  python src/video_toolbox_qt.py

十四、常见问题
--------------
Q 下载慢/失败？
A 换网络或代理；检查 Cookie 是否过期；GitHub 国际链路慢不是程序故障。

Q 视频没声音？
A 音视频可能分开下载，用「视频处理 → 音画合并」自动配对或手动合并。

Q 语音识别报错？
A 检查 ASR 地址/密钥/模型名/协议，先点「测试 ASR 配置」；本地模型查目录。

Q 谷歌翻译不可用？
A 谷歌免费端点在本机网络常不可用，优先微软翻译。

Q 校准没有改动？
A 可能片源模式选错或术语表已覆盖；看报告，不要为「有改动」反复加词。

Q 校准改坏了正常词？
A 换正确片源模式；命令行用 verify 查结构，用 subfix 回退单条。

Q 字幕对不上画面？
A 到字幕编辑逐帧/0.1 秒微调；不要用整体平移解决中间错位。

Q 烧录很慢？
A 硬字幕要重编码；急用先做软字幕或 MKV 封装。

Q 投稿找不到控件？
A 重新采集缺失模板，检查浏览器缩放/改版/登录态；
  失败截图在 data\bili_upload\shots。

Q 更新失败？
A 用离线安装包覆盖安装，data\ 会保留。

Q AI 托管页不出现？
A 托管引擎未部署或适配层未就绪，不影响其他功能。
