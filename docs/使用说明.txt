视频工具箱 v3.3.2 使用说明
==============================

这是一份快速速查。完整说明见 docs\程序说明书(用户版).md。

零、安装与首次启动
------------------
· 在线安装器 VideoToolbox_OnlineSetup_v3.3.1.exe —— 体积小（约 12MB 级），
  新用户首选；装完首次启动按需下载组件。
· 离线安装包 视频工具箱_Setup_v3.3.1.exe —— 供无网/弱网机器完整部署，
  体积以发布页为准，装完不依赖网络下载主程序。
· 已装旧版不必重装：设置 → 程序更新 → 检查更新，按文件差异增量下载；
  同一版本可选「修复安装」。
· 默认安装到 D:\VideoToolbox，可以改；不需要管理员权限。
· onedir 形态：安装目录含 视频工具箱.exe 和 _internal\，不要只复制 exe。
· 首次启动会按需下载 FFmpeg、yt-dlp、Deno、ASR 模型、libmpv 等。
· 运行日志在 logs\；用户数据在 data\。

一、界面导航
------------------
· 左侧常驻 9 页：首页、视频处理、视频库、实时字幕、字幕处理、
  字幕编辑、流水线、自动化、设置；「AI 托管」是条件页，缺席不影响其他功能。
· 每次启动落在首页；左上角返回箭头固定回首页。
· 拖放：链接→下载；音视频→转录；双语字幕→校准；单语字幕→翻译；
  文件夹→视频库；纯文本→AI 托管（就绪时）。

二、最短任务链
------------------
视频处理下载 → 字幕处理语音转录 → 翻译 → 选片源跑校准 → 字幕编辑对轴导出
→ 合成（字幕编辑「内嵌字幕」软字幕；或音画合并烧录硬字幕/封装 MKV）。
这条链也可以在「流水线」里一次跑完。

三、视频下载
------------------------
· 粘贴链接 → 检测画质；只列 720p 及以上，同分辨率取文件更大的版本，
  并优先 60fps 的源；第一项标「最高，推荐」。
· 「同时下载字幕」默认勾选，可用字幕自动转成 SRT。
· 下载中可暂停/继续，已下载分片保留，不用从头来；并发任务数可按带宽调整。
· 每个视频默认自动建立独立文件夹，标题、字幕、封面集中存放；
  默认保存 data\downloads，可在设置里改下载目录。
· Cookie 在 设置 → 下载 Cookie（反风控）：自动/浏览器读取（8 种）/
  cookies.txt/游客；需要登录的视频先在浏览器登录再「从浏览器读取」。
· 代理由后台兜底，界面无开关。

四、音画合并与视频库
------------------------
· 自动配对：mp4/mkv/webm/mov + m4a/weba + srt/ass；默认输入 D:\剪辑，
  输出留空→输入目录\合成结果；字幕默认烧录为硬字幕，可改封装 MKV 或忽略。
· 手动合并：视频必填、音频必填、字幕可选；音频非 AAC 会转码。
· 视频库：启动后自动扫描下载目录，缩略图取第 5 秒；单击打开所在文件夹并
  用系统播放器播放，右键只开文件夹；缓存 data\thumb_cache 可删，程序会重建。

五、语音转录
------------
字幕处理 → 语音转录：
  · 模型来源在命令栏二选一：「本地」「云端」。点哪项就真正切到哪套后端
    （本地=faster-whisper，云端=设置里的 Whisper 接口），切换后当场体检：
    缺模型权重或缺密钥立刻提示，不会等到转录一半才失败。
  · 识别语言与输出格式在命令栏选；语言默认自动，已知语言手动指定更稳。
  · 需要区分说话人时勾选「说话人分离」。

主播声纹筛选（可选，默认关闭）：
  · 只保留某位说话人（如只要主播、不要路人）在转录阶段就能筛：先在
    转录页「主播声纹」录入卡录一段清晰音频建立声纹，再在转录设置弹窗
    勾选要保留的说话人，并打开命令栏的声纹筛选开关。
  · 缺省「精准优先」：拿不准的台词不混进成品，另存 xxx_待复核.srt 等
    人工确认；误筛时可改「召回优先」或调低阈值重跑、从待复核文件拷回、
    或重录更干净更长的样本。
  · 声纹模型约 27MB，首次使用按需下载；选择保存在 data\voiceprint\。

· 语音分离当前只有入口，不内置分离模型；说话人分轨在字幕编辑导出时
  选「按说话人拆分」。

六、字幕翻译
------------
· 服务：微软翻译（必应，默认）、谷歌翻译、DeepLx；不提供 LLM 翻译，
  需要大模型润色走 AI 校准。
· 谷歌走程序内置代理的专用端点，可用性视当前网络节点而定；失败时
  直接换回必应，必应最稳。
· 排布：译文在上（默认）、原文在上、仅译文、仅原文。
· 双语片源的中英顺序不影响校准：校准按字符集识别中文行。

七、术语校准
------------
为什么：机翻最容易错专有名词，校准只改文字，把名字统一回官方写法。

两种方式（推荐顺序：先脚本，后 AI）：
  · 脚本校准：术语表 + 上下文正则批量替换，每次先跑，快且可重复。
  · AI 校准：脚本跑完后让 AI 逐块复核疑似错形；消耗 AI 额度，需人工复核。

界面 16 种常用片源类型（括号内是命令行旗标；2026-11-22 子键化后细类走 --mode）：
  中英双语（默认，不传旗标）    日语原声·鸣潮（--mode wuwa-ja）
  日语原声·终末地（--mode endo-ja）  日语原声·战双（--mode pgr-ja）
  韩语原声·鸣潮（--mode wuwa-ko）    明日方舟（--ak）
  明日方舟·韩语（--mode ak-ko）      终末地（--endo）
  终末地·中英双语（--mode endo-bi）  终末地·韩语原声（--mode endo-ko）
  中文行专属（--zho）                战双帕弥什（--pgr）
  战双英文原声（--mode pgr-en）      综合手游 OST（--wwoc）
  音乐点评（--react）                边狱巴士（--limbus）
旁有「修正英文/参考行（--fix-en）」开关，仅双语模式生效。
命令行另有：--ff14 / --ffrs / --ssv / --tga26 / --zel / --hsr / --pkm /
--gfl2；界面还有明日方舟日语（--mode ak-ja）/ Arcaea（--mode ak-arcaea）、
影之刃零（--pbz）、鸣潮 4.0 一键重跑（--wuwa40ko / --wuwa40ign /
--wuwa40pv / --wuwa40reveal）等扩展项，按片源选。

保证：序号、时间轴、空行、换行符、BOM 原样，只改文字；参考行默认不动
（仅 --fix-en 可修）；校准后请抽查，片源模式选错会误伤。

知识同步：设置 → 校准知识同步，自动同步（启动更新、退出上传）或立即
更新；只同步规则文本，不上传视频/字幕。学习库 subtitle_learned_kb.json
建议备份。

八、字幕编辑
------------
· 支持 SRT/VTT/ASS/SSA 读取，导出 SRT/ASS（ASS 带当前样式）；
  多人字幕可按说话人拆分导出；「内嵌字幕」= 软封装，不重编码。
· 快捷键：
    空格 播放/暂停；, . ← → 逐帧
    Shift+←/→ 0.1 秒；Alt+←/→ 1 秒；↑↓ 上/下一条；[ ] 取起点/终点
    Ctrl+K 切分；Ctrl+A 全选；Del 删除
    Ctrl+Z 撤销（最多 100 步）；Ctrl+Y / Ctrl+Shift+Z 重做
    Ctrl+S 保存；Ctrl+Shift+S 另存；Ctrl+O 打开视频；Ctrl+Shift+O 打开字幕
    Ctrl+= / - / 0 缩放；Ctrl+Shift+F 适配选中
· 最小边界 40ms；状态栏提示重叠/过短条数。

九、流水线
----------
· 链接链：下载 →（无字幕时自动语音转录）→ 翻译 → 校准 → 二次校准 →
  发布素材 → 成品。
· 发布素材（2026-11-25）：校准链完成后自动生成 10 段时间轴 + 10 tag +
  中文标题，写 投稿信息.txt / 发布素材.md；AI 未开或无字幕时跳过。
· 无字幕会调设置页的 ASR；ASR 不可达时显示「失败：语音转录」，
  修好后点重试。
· 流水线翻译优先必应，必应不可用才回退谷歌。
· 下载目录监控：盯住当前下载目录的新视频自动走同一条链；要换目录先改
  设置里的下载目录（没有单独的监控文件夹选择器）。
· 「自动」默认开；并发 1–8，默认 3；进度存 data\pipeline_state.json，
  重启后已完成跳过、运行中转待执行；有「立即扫描/重试失败项/清空任务进度」。

十、自动化：B 站投稿
--------------------
前提：浏览器已登录 B 站；分区/话题自动识别需全局 AI（手工填不受影响）；
先在自动化页采集模板。
· 13 张模板＝10 必需＋3 可选（参与话题、第一张候选封面、创作声明「自制」）；
  缺必需模板任务无法执行；模板存 data\auto_vision\bili，B 站改版或浏览器
  缩放变化后需重采。
· 采集：选窗口 → 抓帧 → 框选 → 存为该模板；页面显示 ✓/✗。
· 表单字段：视频、标题、简介、标签、分区、话题；「从 视频信息.txt 读取」
  会在当前目录和上一级查找。
· 默认演练模式：只走流程不真正提交；确认无误后手动关闭演练才真跑。
· 后台线程执行；失败截图在 data\bili_upload\shots。
· 程序只看屏幕 + 模拟键鼠驱动你自己已登录的浏览器，不碰浏览器进程，
  不需要你的 B 站密码。

十一、AI 托管
-----------
· 条件页；需要本机部署托管引擎（约 2.2GB，不随安装包）。
· 状态/任务/运行输出三卡片；工作区=程序根；数据在 data\harness-home；
  未就绪时显示部署引导，不影响其他功能。

十二、设置要点
----------------
设置是唯一入口，共 11 张卡片，按界面顺序：
目录 → 下载 Cookie → 全局 AI → ASR 语音识别 → AI 校准 → 字幕引擎 →
校准知识同步 → 程序更新 → 界面美化 → 界面 → 关于。

· 全局 AI 卡内「决策模型（Jev · 预览）」子区默认全部关闭：
    总闸默认关，不开就零请求、零改动，可一键回退纯本地规则。
    决策模式：影子（默认，只把复核证据追加到报告，不改一个字字幕）/
    辅助 / 自动（需门禁验证，当前版本选择后不激活）。
    可选独立凭据：界面不回填、不显示明文，留空用全局 AI 密钥；
    区域端点白名单（默认/百炼北京/新加坡）；「测试决策模型」只报成败，
    任何环节不显示密钥。
    第二音色影子（前瞻）默认关：只记证据、不改字幕。
· ASR 卡：本地独立模型（faster-whisper）或自有 Whisper 兼容接口；
  语音分离为占位开关默认关（当前不附带分离模型）；识别语言已移到
  转录页命令栏，不在设置里。
· 旧「网络代理」卡片已移除：内置代理纯后台兜底，不提供界面配置。
· 界面美化：每个板块可单独设背景图，未设置的用全局；遮罩跟随主题
  （深色压暗、浅色雾白）配合可选模糊，保证文字可读。
· 界面：主题（深色/浅色/跟随系统）、缩放（立即生效）、云母特效、主题色。
· v3.2.5 默认全影子：所有新 AI 开关默认关；一个都不开时行为与旧版
  完全一致，想用哪个新能力再开哪个。

十三、实时字幕
--------------
入口：左侧「实时字幕」（2026-11-25 并入；长生命周期服务，无命令行子命令）。

· 音源：系统内录（WASAPI loopback，默认）/ 麦克风 / WAV 回归；设备可刷新。
· ASR：端点、模型、协议自动复用「设置 → ASR 语音识别」的 ai_config.json；
  密钥只读 credentials.json 的 asr_api_key，本功能不单独存密钥、不回显。
· 术语校准：选片源模式（18 种）；ASR 原文与译文都过同一张 calib_core 术语表。
· 输出：data\live_out\live_<时间>.srt（双语两行：译文在上、原文在下），
  同时写 sub_en.txt / sub_zh.txt 供 OBS 文本源；cues.jsonl 为调试事件流。
· 悬浮层：置顶透明、可拖动、滚轮调字号；右键可开/关点击穿透、回底部、隐藏。
· 本地兜底：可选 Index-Echo（tools\live_engine + tools\live_model，约 2.5GB，
  不随安装包）；未安装时云端失败会直接报错，不会假装降级。
· 首次用内录/麦克风需 soundcard 与 numpy；安装包已内置，源码方式见 requirements。

十四、文件、更新、卸载
--------------------
安装目录：默认 D:\VideoToolbox，含 视频工具箱.exe、_internal\、tools\、
  docs\、src\。
data\ 关键路径：
  ai_config.json（AI/ASR 配置，不含明文密钥）/ credentials.json（密钥，
  独立只读）/ config.json / subtitle_style.json / ui_custom.json /
  videocaptioner\settings.json（字幕引擎设置）
  downloads\（默认下载目录）/ thumb_cache\（缩略图缓存）/ tmp\ /
  pipeline_state.json（流水线进度）/ voiceprint\（声纹样本与筛选）/
  auto_vision\bili（投稿模板）/ bili_upload\shots（失败截图）/
  live_out\（实时字幕 SRT / sub_en.txt / sub_zh.txt / cues.jsonl）/
  harness-home\（AI 托管数据）/ last_update_result.txt（更新结果）
logs\：运行日志。
建议备份：data\ai_config.json、credentials.json、subtitle_style.json、
  ui_custom.json、subtitle_learned_kb.json、data\calib_sync*（如用同步）。

更新：
  · 启动时自动检查一次，只有真正的新版本才提示，平时不打扰。
  · 手动：设置 → 程序更新 → 检查更新；增量下载，按 sha256 校验；
    支持任意版本间升降级；同一版本可选「修复安装」。
  · 被占用的文件走延迟交换：程序退出后由收尾批处理完成替换再重启，
    不留半新半旧的目录。
  · 结果写 data\last_update_result.txt，排障先看它。
卸载：Windows 应用列表或开始菜单；卸载不删 data\、logs\ 和下载文件，
  彻底清理需手动删除安装目录。

十五、命令行（源码方式）
------------------------
统一 CLI（所有子命令支持 --json，失败看 error 字段）：
  tools\python\python.exe src\agent_cli.py status --json
  tools\python\python.exe src\agent_cli.py info "<视频>"
  tools\python\python.exe src\agent_cli.py download "<链接>" --height 1080
  tools\python\python.exe src\agent_cli.py transcribe "<视频>" --lang ja
  tools\python\python.exe src\agent_cli.py translate "<字幕>" --engine bing
  tools\python\python.exe src\agent_cli.py calibrate "<字幕>" --mode endo-bi
  tools\python\python.exe src\agent_cli.py stabilize "<字幕>"
  tools\python\python.exe src\agent_cli.py audit "<字幕>"
  tools\python\python.exe src\agent_cli.py compose "<视频>" "<字幕>" --mode burn
  tools\python\python.exe src\agent_cli.py split "<视频>" --points "00:01:00,00:05:00"
  tools\python\python.exe src\agent_cli.py bili-submit "<素材目录>" --dry-run

校准脚本：
  tools\python\python.exe subtitle_calib_merged.py "<字幕>" --out "<输出>" --mode endo-bi
  tools\python\python.exe subtitle_calib_merged.py verify "<源>" "<成品>"

源码运行：需要 Python 3.12，必须在仓库根运行：
  pip install -r requirements.txt
  python src/video_toolbox_qt.py

十六、常见问题
--------------
Q 下载慢/失败？
A 换网络或代理；检查 Cookie 是否过期；GitHub 国际链路慢不是程序故障。
Q 下载的视频没声音？
A 音视频可能分开下载，用「音画合并」自动配对或手动合并。
Q 转录页切换「本地/云端」后立刻报错？
A 切换真实生效并当场体检：本地缺权重、云端缺密钥都会立刻提示，
  按提示补齐即可；不会出现「以为在用云端，其实跑的是本地」。
Q 谷歌翻译不可用？
A 谷歌走内置代理专用端点，可用性视节点而定；默认必应最稳，失败换回必应。
Q 声纹筛选把想要的台词分进了待复核？
A 「精准优先」在起作用：拿不准就不进成品。可改「召回优先」或调低阈值
  重跑；从 xxx_待复核.srt 拷回需要的行；或重录更干净更长的样本。
Q 校准没有改动或改坏了正常词？
A 没改动可能片源模式选错或术语表已覆盖；改坏了换正确片源模式，
  命令行用 verify 查结构、subfix 回退单条。不要为「有改动」反复加词。
Q 字幕对不上画面？
A 到字幕编辑逐帧/0.1 秒微调；不要用整体平移解决中间错位。
Q 烧录很慢？
A 硬字幕要重编码；急用先做软字幕或 MKV 封装。
Q 投稿找不到控件？
A 重新采集缺失模板，检查浏览器缩放/改版/登录态；失败截图在
  data\bili_upload\shots。
Q 更新失败？
A 看 data\last_update_result.txt 确认失败环节；改用离线安装包覆盖安装，
  data\ 会保留。
Q AI 托管页不出现？
A 托管引擎未部署或适配层未就绪，不影响其他功能。
