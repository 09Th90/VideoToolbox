视频工具箱 —— 第三方组件来源与许可声明
====================================================================
本文件列出随「视频工具箱」安装包分发的第三方组件，以及运行时按需获取的
开源依赖。凡标注 GPL 的组件，其完整许可全文随包提供于本目录
`开源许可_GPL-3.0.txt`（标准 GPL-3.0 原文）；源码来源见下。

--------------------------------------------------------------------
1. NewPipe Extractor（YouTube 第二解析引擎，v1.17.0 起随包分发）
--------------------------------------------------------------------
组件名称 ：NewPipe Extractor
用途     ：yt-dlp 全部源失败时的兜底解析引擎（本工具箱仅调用其 Java 侧
           解析接口取得流地址，实际下载仍由 FFmpeg 完成）
版本     ：随 tools\newpipe-cli\build.py 锁定的依赖版本构建
作者     ：TeamNewPipe 及 NewPipe 贡献者
许可     ：GNU General Public License v3.0（GPL-3.0）
许可全文 ：本目录 开源许可_GPL-3.0.txt（标准 GPL-3.0 原文）
项目主页 ：https://github.com/TeamNewPipe/NewPipeExtractor
源码     ：https://github.com/TeamNewPipe/NewPipeExtractor
源码压缩包：https://github.com/TeamNewPipe/NewPipeExtractor/archive/refs/heads/dev.zip
发行包   ：tools\newpipe-cli\dist\npe-cli.jar（本工具箱自建 fat jar，
           构建脚本与 Java 侧封装源码随仓库分发于 tools\newpipe-cli\）

  GPL-3.0 义务提示：本组件为 GPL-3.0，分发二进制时须随包提供许可全文与对应
  源码获取途径——本安装包已附许可全文，上表给出上游官方源码地址。本工具箱
  通过子进程调用（java -jar）与之交互，未修改其源码；本工具箱自身的授权方式
  由作者决定，与本组件许可不互相传染。
