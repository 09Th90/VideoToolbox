## 1. 认识它

### 1.1 这个软件是做什么的

**视频工具箱**是一个 Windows 桌面程序，把「做一份带中文字幕的视频」这件事的全流程装进了一个软件里：

下载素材 → 出字幕 → 翻译 → 校正专有名词 → 对着画面调时间轴 → 合成成品

这几步原本要用五六个不同的小工具接力，中间还要来回搬文件、改格式、对时间码。这个软件把它们串起来了，数据不用出你的电脑，配置也只需要填一次。

### 1.2 它能做什么

| 你想做的事 | 对应的功能 |
| --- | --- |
| 从视频网站下载视频，带封面和字幕 | 视频处理 → 视频下载 |
| 把分开的视频和音频合成一个文件 | 视频处理 → 音画合并 |
| 把视频里的说话转成字幕文件 | 字幕处理 → 语音转录 |
| 给外语视频加中文字幕 | 字幕处理 → 翻译 |
| 修正机翻把游戏/动漫专有名词翻错的地方 | 字幕处理 → 字幕校准 |
| 字幕时间轴对不上，要一条条调 | 字幕编辑 |
| 把字幕压进视频，或者挂成可开关的轨道 | 字幕编辑 → 内嵌字幕 |
| 一条链接丢进去，全程自动跑完 | 流水线 |
| 一批视频排队处理 | 流水线（监视目录） |
| 只保留主播说的话，剪掉其他人的 | 声纹筛选 |
| 自动把做好的视频投到 B 站 | 自动化 |
| 让 AI 助手替你操作这个软件 | AI 托管 |

### 1.3 它不能做什么

说清楚边界，省得你白折腾：

- **不能破解版权保护**。它只能下载公开可访问的内容，付费或加密内容下不了。
- **不能保证 100% 准确的语音识别**。背景音乐大、多人抢话、口音重、专业术语多的素材，识别错误率会明显上升——这也是为什么需要第 7 章的「校准」。
- **不能自动做出完美翻译**。机器翻译对专有名词的处理天生不准，必须靠校准修正。
- **不能在 macOS 或 Linux 上运行**。它是 Windows 专用程序，且依赖 Windows 的窗口与输入接口。
- **不能无人值守地无限跑**。批量处理需要你先把任务排好，它不会自己找素材。

### 1.4 系统要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10（1809 及以上）或 Windows 11 |
| 磁盘空间 | 程序本体约 500MB；每处理一小时视频另需 1–3GB 工作空间 |
| 内存 | 建议 8GB 以上；使用声纹筛选或本地语音识别建议 16GB |
| 网络 | 下载、翻译、AI 校准、在线更新需要联网 |
| 附加组件 | 自动投稿需要浏览器已登录 B 站；第二解析引擎需要电脑装有 Java 17 以上（可选） |

### 1.5 关于「要不要花钱」

- **下载、出字幕、翻译、校准、编辑、合成**：全部免费，用的是内置或公开的免费通道。
- **AI 校准（第 7 章）**：需要你自己准备一个大模型接口（比如 DeepSeek、通义千问、智谱等），按各家价格计费。这个功能是**可选的**——不开也能用脚本校准，只是漏网的错形会多一些。
- **语音识别**：可以用本机模型（免费但慢），也可以接自己的识别服务（按量计费）。

## 2. 安装与首次启动

### 2.1 选哪个安装包

| 安装包 | 体积 | 适合谁 | 说明 |
| --- | --- | --- | --- |
| **离线安装包**（`VideoToolbox_Setup_v2.5.2.exe`） | 约 1.0GB | 大多数人 | 一次装完，之后不依赖网络 |

不确定就选离线包。它体积大，但装完就能用，不会卡在下载环节。

> **已经装了旧版本？** 不用重下整个安装包：打开程序 → 设置 → 检查更新，内置更新器会按文件差异增量下载（通常只有几十 MB）。

### 2.2 安装步骤

1. 双击安装包。
2. 选择安装位置。默认是 `D:\VideoToolbox`，可以改，但**不要装在中文路径或很深的目录里**（程序内部有些组件对中文路径敏感）。
3. 一路下一步，等待完成。
4. 桌面会出现「视频工具箱」快捷方式。

安装过程中如果提示「程序正在运行」，说明你之前开着一个实例，点确定让它自动关掉即可。

### 2.3 第一次启动会看到什么

第一次启动比之后慢一些（要初始化配置和缓存），通常十几秒到半分钟。启动后会看到：

- **左侧导航栏**：首页、视频处理、视频库、字幕处理、字幕编辑、流水线，最下面是设置。
- **中间主区域**：默认停在「首页」。
- **首页正中的任务框**：一个输入框加一个按钮——这是全软件最常用的入口。

如果启动时弹出「是否检查更新」，按需选择即可，不影响使用。

### 2.4 第一次必须做的事：填 AI 配置

这一步只做一次，之后不用再管。但**不做的话，翻译和 AI 校准用不了**。

1. 点左下角「设置」。
2. 找到「全局 AI」分组。
3. 填入三项：
   - **接口地址**：你的模型服务商给的地址，通常形如 `https://api.xxx.com/v1`
   - **密钥**：服务商给你的那串以 `sk-` 开头的字符
   - **模型名**：比如 `deepseek-chat`、`qwen-plus` 之类
4. 点旁边的「测试」或「检查连接」，看到成功提示即可。

> 密钥保存在 `data\credentials.json`（只读，独立于配置文件），设置页不会回显明文；留空保存表示沿用原密钥，不会清空。

如果你不确定填什么，可以先跳过——下载、出字幕、编辑字幕这些功能不依赖它。

> **小提示**：填完 AI 配置后，点一下「设置自动匹配」。它会检查你填的地址和模型名是否对得上，避免出现「地址是 A 家的、模型是 B 家的」这种常见错误。

### 2.5 语音识别要不要单独配

看你用哪种方式出字幕：

| 方式 | 需要配置吗 | 特点 |
| --- | --- | --- |
| 本机模型识别 | 不需要，但首次要下载模型 | 免费、隐私好、慢、吃内存 |
| 自己的识别服务 | 需要填地址和密钥 | 快、准、按量计费 |

在「设置 → ASR 语音识别」里选。选完可以点「测试连接」确认能通。

## 3. 一分钟上手：贴个链接，出字幕

这一章是「最短路径」，让你先跑通一遍，建立信心。细节在第 4–9 章。

### 3.1 五步跑通

1. **复制链接**：在浏览器里复制一个视频页面的地址。
2. **贴进首页任务框**：回到软件首页，粘贴，点右边的按钮（图标会从文件夹变成播放键）。
3. **等下载完成**：进度条走完，会自动跳到「视频处理」页，你能看到下载好的文件。
4. **出字幕**：切到「字幕处理」页，选中刚下载的视频，点「开始转录」。等进度条走完，你会得到一份字幕文件。
5. **翻译（如果是外语）**：在同一个页面选「翻译」，等它跑完，字幕就变成中英双语了。

到这里，一份可用的双语字幕就有了。如果专有名词翻错了，继续第 7 章。

### 3.2 更省事的做法：用流水线

如果你不想一步步点，用第 10 章的「流水线」：把链接丢进去，它会自动完成下载、翻译、校准、出成品，全程不用管。

## 4. 下载视频与音频

### 4.1 下载视频

**入口**：视频处理页 → 视频下载。

**能贴什么**：

- 视频页面链接（YouTube、B 站等主流站点）
- 分享文案（那种带一堆文字和链接的，直接整段粘贴也行）
- 含链接的 txt 文件（拖进窗口即可）

**下载后会得到什么**：一个以视频标题命名的文件夹，里面通常有：

```
视频文件（.mp4）
封面.jpg（1280×720，用于投稿）
视频信息.txt（标题、简介、标签等元信息）
字幕文件（如果原视频有字幕轨）
```

这个文件夹结构是刻意设计的——后面做成品、投稿都会从这里读信息，别随手改名或删文件。

### 4.2 选清晰度

默认下载最高画质。想省空间或省时间，可以在下载前限制高度（比如只下 1080p）。

### 4.3 需要登录才能看的视频

有些视频（会员内容、需要登录的、年龄限制的）不登录下不了。软件提供了三种拿登录态的方式，按顺序尝试：

1. **自动**：软件自己找可用的登录态。
2. **从浏览器读**：指定你常用的浏览器，让软件去读它的登录信息。⚠ 新版 Chrome / Edge 的加密方式变了，这条路经常失效。
3. **导出 Cookie 文件**：最可靠。用浏览器插件导出登录信息，存成文件，在设置里指过去。

**重要**：拿不到登录态**不会**让下载任务失败，软件会自动降级去试匿名下载。所以如果你看到「已降级」之类的提示，先让它继续跑，别急着当成错误。

### 4.4 下载中断或很慢

- **中断**：重新点一次下载，已下载的部分通常会被复用，不会从头再来。
- **很慢**：检查是不是开了代理。软件内置了代理支持，但节点不好时速度会掉。切换节点后再试。
- **报「SSL」或「EOF」错误**：通常是下载过程中代理节点被切换了，导致已经拿到的下载地址失效。重试一次，软件会重新取地址。

### 4.5 音画合并

有时候你会拿到分开的两个文件：一个只有画面，一个只有声音（常见于高画质下载）。用「视频处理 → 音画合并」把它们合起来。

**自动配对**：把视频和音频放在同一个文件夹里，文件名相同（比如 `xxx.mp4` + `xxx.m4a`），点自动配对，它会自己认出成对的文件。

**手动合并**：文件名不一样也没关系，把文件拖进「手动合并」，逐个指定视频、音频、可选字幕，点开始合成。

合并默认**不重新编码**，所以很快，画质也不会损失。如果格式不兼容（比如某些 WebM 视频），软件会自动转码一次。

## 5. 出字幕（语音转文字）

### 5.1 基本流程

**入口**：字幕处理页 → 语音转录。

1. 选择视频或音频文件（也可以直接拖进去）。
2. 选识别语言。**能选就选**——不选让软件自己猜，遇到中英混杂、日语、韩语的素材容易猜错。
3. 点「开始转录」。
4. 等待完成，字幕会自动关联到当前任务。

### 5.2 长视频怎么办

软件会自动把长音频切成小段分别识别，再拼起来，所以不需要你手动分段。一小时以上的视频耐心等一下即可。

如果中途失败并提示「音频太长」，通常是识别服务那边有限制——软件会自动压缩码率或对半切分重试，多数情况下能自己解决。

### 5.3 只出中文还是出双语

这是两件事：

- **转录**：只负责把说的话变成**原文**字幕（外语就是外语）。
- **翻译**：负责把原文变成**中文**，并排成双语。

所以外语视频的正确顺序是：先转录 → 再翻译。想要纯中文字幕，翻译后把原文行删掉即可。

### 5.4 多人说话的内容

有些识别服务会给每句话标上「说话人 1 / 说话人 2」。这类字幕后面可以用第 11 章的声纹功能筛选，只保留你要的那个人。

### 5.5 识别不准怎么办

先别急着逐条改。按这个顺序处理：

1. **换识别语言再试一次**——语言猜错会导致整篇错得离谱。
2. **换识别模型**——大模型通常比小模型准。
3. **做校准**（第 7 章）——专有名词类的错误，校准比重新识别有效得多。

## 6. 翻译字幕

### 6.1 两种翻译方式

| 方式 | 特点 | 什么时候用 |
| --- | --- | --- |
| **机翻**（默认） | 免费、快、专有名词容易错 | 大多数情况，之后靠校准修正 |
| **大模型翻译** | 更通顺、更懂语境、要花钱 | 对译文质量要求高时 |

机翻不需要任何配置，直接用。大模型翻译要用你在第 2 章填的 AI 配置。

### 6.2 翻译引擎怎么选

软件内置三种免费机翻通道。默认那个通常就够用；如果某一个不好使（比如某段时间连不上），换另一个。

### 6.3 双语是怎么排的

默认**原文在上、译文在下**。这个顺序可以在字幕排布设置里改。

### 6.4 翻译完发现内容还是原文

这是一个已知的坑：如果翻译通道整批失败，有些工具会把译文悄悄换成原文，产出「名字叫翻译版、内容其实是原文」的假翻译。

本软件对这种情况做了处理：**译文缺失会直接报错，不会落盘**。所以如果你看到翻译报错，说明它宁可失败也没给你假货——换个引擎重试即可。

### 6.5 翻译质量不满意

按这个顺序改进：

1. **换引擎**再翻一次。
2. **用大模型翻译**（质量明显更好）。
3. **做校准**（第 7 章）——专有名词的问题，翻译本身解决不了。

## 7. 校准字幕：让专有名词说人话

这是这个软件最有价值的功能，也是最需要理解原理的功能。

### 7.1 为什么需要校准

机器翻译不认识游戏、动漫里的专有名词。它会按字面硬翻：

| 原文 | 机翻结果 | 官方译名 |
| --- | --- | --- |
| Endfield | 恩德菲尔德 | 终末地 |
| Wuthering Waves | 呼啸浪潮 | 鸣潮 |
| Kal'tsit | 卡尔特西特 | 凯尔希 |

校准就是把这些错的地方**按官方译名改回来**，而且只改文字、**不动时间轴**。

### 7.2 两种校准方式

| 方式 | 原理 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **脚本校准**（基础） | 查内置术语表，逐条替换 | 免费、快、结果稳定可预期 | 只能改表里有的，表外的错形改不到 |
| **AI 校准**（增强） | 让大模型通读字幕，找出脚本漏掉的错形 | 能发现新错形，还会联网查证 | 要花钱、慢、结果需要抽查 |

建议流程：**先跑脚本校准，再跑 AI 校准**。脚本负责大头，AI 负责漏网的。

### 7.3 怎么选对「片源类型」

脚本校准需要你告诉它这是什么游戏/作品的字幕，因为它有 17 套不同的术语表。

选错的后果很严重——比如把日语片当成中英双语片，术语表整个用错，校准等于白做。

**如果不确定**：可以先让软件自动判断。但要注意，**日语片必须手动指定「日语」**，自动判断会把它当成中英双语，导致校准全部失效。

### 7.4 校准结果怎么看

校准完成后会生成一份报告，告诉你：

- 改了多少处
- 每一处改了什么（原文 → 改后）
- 哪些地方拿不准（需要你人工确认）

**一定要看「拿不准」那部分**。软件宁可标出来让你判断，也不乱改。

### 7.5 AI 校准怎么用

1. 确认第 2 章的 AI 配置已经填好并测试通过。
2. 在字幕处理页选「AI 校准」。
3. 选好片源类型，点开始。
4. 等待——它会分块处理，长视频可能要十几分钟。
5. 完成后看报告，重点看「被拒绝的改动」——那通常是模型想乱改但被拦下来的地方。

**AI 校准的安全机制**：模型提出的每一处修改都要有依据（术语表命中、联网查证、音频佐证）。没有依据的改动会被**拒绝**，所以不会出现「模型把整篇重写一遍」的情况。

### 7.6 校准会改坏吗

有三层保护：

1. **只改文字，不动时间轴**——序号、时间码、空行全部保持原样。
2. **无依据不改**——AI 校准的每处改动都要有证据。
3. **有报告**——改了什么一目了然，可以对照检查。

如果你还是不放心，校准前先把原字幕复制一份备份。

### 7.7 校准知识会同步吗

会。软件启动时会把校准知识拉下来，退出时把你在本机积累的修正推上去（需要开启同步）。这样多台电脑之间的校准成果是共享的。

如果你不想参与同步，在「设置 → 校准知识同步」里关掉即可，不影响本地校准功能。

## 8. 编辑字幕：看着画面对轴

### 8.1 什么时候需要手动编辑

- 字幕比画面早或晚了一点（整体偏移）
- 某句话跨了两句，需要拆开
- 两句话时间重叠，播放时闪来闪去
- 想把某几句删掉或合并

### 8.2 界面长什么样

**入口**：左侧「字幕编辑」。

从上到下三块：

1. **视频画面**：播放预览。
2. **波形时间轴**：声音的波形图，字幕块画在上面，能直观看到字幕和声音对不对得上。
3. **字幕表格**：每行一条字幕，有开始时间、结束时间、内容。

右侧通常还有属性面板，用来改当前选中字幕的样式。

### 8.3 基本操作流程

1. 打开视频（也可以直接把视频拖进窗口）。
2. 打开字幕文件。
3. 点播放，看字幕和声音对不对得上。
4. 在波形上拖动字幕块调整时间，或者在表格里直接改数值。
5. 改完保存。

### 8.4 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| `Ctrl + K` | 在当前位置把一条字幕切成两条 |
| `Ctrl + A` | 全选 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 另存为 |
| `Ctrl + O` | 打开字幕 |
| `Ctrl + Shift + O` | 打开视频 |
| `Ctrl + Shift + F` | 查找替换 |

### 8.5 几个防手滑的设计

- **撤销**：可以撤销很多步，改错了按 `Ctrl+Z` 就行。
- **拖动前自动存快照**：拖字幕块之前会先记一份，拖坏了能退回去。
- **输入框里按空格不会触发播放**：在表格里打字时，空格就是空格。

### 8.6 内嵌字幕与字幕层

**内嵌字幕**：把当前字幕挂成视频里的一条独立轨道。好处是**不重新编码**，几秒钟就完成，画质完全不变。播放时可以在播放器里开关字幕。

**字幕层**：在画面上实时预览字幕效果，所见即所得地调样式。它不是最终产物，只是预览。

### 8.7 想烧进画面怎么办

「烧进画面」（硬字幕）需要重新编码整个视频，很慢。这个操作在编辑页没有提供——请用第 9 章的方法，或者在命令行里做。

## 9. 做成品：合成与压制

### 9.1 三种成品形态

| 形态 | 体积 | 能否开关字幕 | 速度 | 适用 |
| --- | --- | --- | --- | --- |
| **软字幕**（挂轨道） | 几乎不增加 | 能 | 几秒 | 自己看、要留原文 |
| **MKV 封装** | 略增 | 能 | 快 | 要打包多条字幕/音轨 |
| **硬字幕**（烧进画面） | 与视频同 | 不能 | 慢（重编码） | 投稿、发给不会开字幕的人 |

大多数人需要的是**软字幕**——快、无损、随时能关。

### 9.2 做软字幕

用第 8 章的「内嵌字幕」，或者在命令行里用合成功能选软封装模式。全程不重新编码，画质零损失。

### 9.3 做硬字幕

需要重新编码，速度取决于你的电脑。建议：

- 一次只跑一个任务，别同时开多个。
- 长视频耐心等，中途别关程序。

### 9.4 字幕样式怎么调

在字幕编辑页的属性面板里调字体、大小、颜色、描边、位置。调好的样式会保存下来，下次做同类视频可以直接用。

## 10. 批量与流水线

### 10.1 流水线能做什么

**入口**：左侧「流水线」。

它把「下载 → 翻译 → 校准 → 出成品」串成一条自动流水线。你只要给它输入，它自己跑完全程。

### 10.2 两种用法

| 用法 | 怎么用 | 适合 |
| --- | --- | --- |
| **链接任务** | 把链接贴进流水线，点开始 | 手头有几个明确的视频要处理 |
| **目录任务** | 指定一个文件夹，让软件盯着 | 素材已经在本地，或者下载器在往那个目录里丢文件 |

目录任务的工作方式：软件监视你指定的文件夹，发现「下载完成了」的文件就自动接上后面的流程。判断「下载完成」的依据是文件大小不再变化、没有临时文件残留。

### 10.3 断点续跑

这是流水线最实用的特性：

- 跑到一半关了软件，下次打开会**接着跑**，不会从头再来。
- 已经完成的阶段会跳过。
- 正在跑的阶段会重新跑（因为不知道跑完了没有）。

所以放心关，不用守着。

### 10.4 失败了怎么办

流水线**不会自动无限重试**。某个任务失败后，它会停下来等你处理——这是刻意的，因为反复重试通常只会反复失败。

处理方式：

1. 看失败原因（通常在任务卡片上或日志里）。
2. 修好问题（比如换网络、改配置、删掉坏文件）。
3. 点「重试」从失败的阶段继续。

**失败只影响当前任务**，其他任务照常跑。

### 10.5 并发数怎么设

设置里有「并发任务数」，默认 3。建议：

- 网络好、电脑强：可以调到 4–6。
- 网络一般或同时在做别的事：保持 2–3，或者调到 1 慢慢跑。

调太高不会更快——瓶颈通常在网络或 API 限流。

## 11. 声纹认人：只出主播的字幕

### 11.1 这个功能解决什么问题

看游戏实况、多人访谈、联动直播时，你可能只想保留主播说的话，把其他人的都剪掉。

但识别服务只告诉你「说话人 1 / 说话人 2」，它不知道哪个是主播。这个功能就是解决这件事：**你告诉它主播的声音是什么样的，它帮你筛**。

### 11.2 怎么用

1. **录入主播声纹**：找一段只有主播说话、没有背景音乐和杂音的音频（15–30 秒即可），让软件提取声纹。
2. **给它起个名字**（比如主播的 ID），保存。
3. **跑筛选**：选字幕文件，选要保留的声纹，点开始。

### 11.3 结果有哪几种

每条字幕会被判成三种之一：

| 判定 | 含义 | 处理 |
| --- | --- | --- |
| **保留** | 很像主播 | 留下 |
| **存疑** | 有点像但不够像 | **默认保留**，等你人工判断 |
| **剔除** | 明显不是主播 | 删掉 |

存疑的默认保留，是刻意的——宁可多留几句，也不误杀主播的话。

### 11.4 筛完发现误杀了怎么办

软件在筛选前会自动备份一份未筛选的字幕（文件名带「未筛选」字样）。找到那份，重新来一遍，或者直接把被误删的句子复制回来。

### 11.5 提高准确率的几个要点

- **录入素材要干净**：只有主播一个人说话，没有背景音乐、没有其他人插话、没有回声。
- **录长一点**：15 秒是下限，30 秒以上更稳。
- **可以录多个模板**：同一个人不同设备/不同状态下的声音，录两三个模板，命中率会提高（多个模板是「任一像就算」的关系）。
- **换素材**：如果主播这期戴了耳机、换了麦克风，声音差别大，最好重新录一份。

### 11.6 声纹能跨电脑用吗

能。声纹模板支持同步（和校准知识是分开的两套通道）。开了同步后，你在另一台电脑上也能用同样的模板。

## 12. 视频库

### 12.1 它是什么

**入口**：左侧「视频库」。

把你下载或存放视频的文件夹变成一个有缩略图的浏览界面。适合素材多、记不清文件名的时候。

### 12.2 怎么用

2. 软件会扫描并生成缩略图。
3. 点卡片可以播放，也可以直接跳去处理它。

### 12.3 找不到刚下载的视频

点一下刷新。如果还是没有，检查「设置 → 目录」里的下载目录是不是你实际存放的位置。

## 13. 自动化与 AI 托管

### 13.1 自动投稿（自动化页）

**入口**：左侧「自动化」。

它能驱动你**已经登录 B 站的浏览器**，自动完成投稿：填标题、简介、标签、选分区、上传封面、提交。

**使用前提**：

- 浏览器已登录 B 站；
- 视频所在文件夹里有 `视频信息.txt`（下载功能会自动生成）和封面图；
- 采集过投稿页面的界面模板（软件里有向导，跟着框选即可）。

**第一次用建议先「演练」**：演练模式只识别不点击，能看到它打算点哪里，确认无误再真跑。

### 13.2 AI 托管（AI 托管页）

**入口**：左侧「AI 托管」。

这是给高级用户的功能：让一个 AI 助手（运行在你电脑上的命令行程序）来操作这个软件——读状态、发起任务、收结果。

对普通用户来说，它的实际用法是：**在首页任务框里输入一段自然语言描述**，比如「帮我把这个链接的视频下载下来并加上中文字幕」，如果 AI 托管已经配置好，它会接手处理。

不配置也不影响其他功能。

## 14. 设置逐项说明

设置页项目较多，这里按「你想解决什么问题」来索引，不按界面顺序。

### 14.1 我想改下载位置

**设置 → 目录**。改完新下载的文件会存到新位置，已有的不会自动搬。

### 14.2 我想让翻译/校准能用

**设置 → 全局 AI**。填接口地址、密钥、模型名，点测试。

### 14.3 我想换语音识别方式

**设置 → ASR 语音识别**。可以选本机模型或自己的识别服务。

### 14.4 我想调 AI 校准的力度

**设置 → AI 校准**。这里能调：

| 项 | 作用 | 建议 |
| --- | --- | --- |
| 每块字幕条数 | 一次让模型看多少条 | 保持默认；太大容易超长，太小会漏上下文 |
| 上下文预算 | 模型能看多少参考信息 | 越大越准，但更贵更慢 |
| 思考强度 | 模型思考的深度 | 专有名词多的素材可以调高 |
| 并发数 | 同时处理几块 | 默认串行最稳；服务商不限流可以调高 |
| 联网查证 | 允许模型上网查证 | 建议开，能显著减少瞎猜 |
| 音画佐证 | 允许模型听音频、看画面 | 素材听不清时开 |
| Agent 集群 | 多个模型互相评审 | 追求质量时开，成本翻倍 |

### 14.5 我想改字幕样式

**设置 → 字幕引擎运行参数**，或者直接在字幕编辑页的属性面板里调。

### 14.6 我想关掉知识同步

**设置 → 校准知识同步**。关掉后本地校准照常工作，只是不再和云端交换。

### 14.7 我想改界面外观

**设置 → 界面**（深色/浅色/跟随系统、主题色、缩放）和 **设置 → 界面美化**（背景图、模糊、透明度）。

### 14.8 我想检查更新

**设置 → 程序更新**。

## 15. 文件都在哪

### 15.1 主要目录

| 内容 | 位置 |
| --- | --- |
| 程序本体 | 你安装时选的位置，默认 `D:\VideoToolbox` |
| 下载的视频 | 默认在 `data\downloads`，可在设置里改 |
| 配置（AI 密钥等） | `data\` 目录下的配置文件；密钥单独存 `data\credentials.json` |
| 日志 | `logs\` 目录 |
| 缓存 | `data\cache`、`data\thumb_cache`、`data\waveforms` |
| 校准知识 | `data\` 下的同步相关目录 |

### 15.2 想把数据放到别的盘

**设置 → 目录** 里可以指定新的数据位置。软件会把已有的数据搬过去（同名文件不覆盖），**需要重启生效**。

换电脑时，把整个 `data` 目录复制过去即可——配置、声纹模板、校准知识都在里面。

### 15.3 哪些文件不要删

| 文件/目录 | 为什么不能删 |
| --- | --- |
| `data\` 下所有内容 | 你的配置、模板、校准积累都在这里 |
| `tools\` 目录 | 程序运行依赖的组件（ffmpeg 等） |
| `data\calib_sync_base.*` | 校准同步的基线，看着像备份但**不能删** |

### 15.4 哪些可以放心删

| 内容 | 说明 |
| --- | --- |
| `data\thumb_cache` | 缩略图缓存，删了会重新生成 |
| `data\waveforms` | 波形缓存，删了会重新生成 |
| `data\tmp` | 临时文件 |
| `logs` 里的旧日志 | 只用于排障，占空间可以清 |

## 16. 更新、备份与卸载

### 16.1 怎么更新

**设置 → 程序更新 → 检查更新**。有新版本会提示，按引导下载安装。

更新**不会**删除你的配置、下载的视频、声纹模板和校准知识——这些都在 `data` 目录里，与程序本体分开。

### 16.2 更新后想退回旧版

如果新版有问题，可以重新安装旧版安装包。但注意：**新版可能已经升级过配置文件格式**，退回旧版后部分设置可能需要重填。

### 16.3 怎么备份

只需要备份 `data` 目录（配置、模板、校准积累）和你自己下载的视频。程序本体重装即可。

建议在**大版本更新前**备份一次 `data`。

### 16.4 怎么卸载

用 Windows 的「应用和功能」卸载，或运行安装目录里的卸载程序。

卸载**不会**自动删除 `data` 目录（这是刻意的，防止误删你的积累）。想彻底清理，卸载后手动删除安装目录残留。

## 17. 出问题了

按症状查。每条给出「可能原因」和「怎么处理」。

### 17.1 打不开 / 启动就闪退

| 可能原因 | 处理 |
| --- | --- |
| 装在中文路径或很深目录 | 重装到 `D:\VideoToolbox` 这类简单路径 |
| 杀毒软件拦截 | 把程序目录加入白名单 |
| 上次没正常退出，锁文件残留 | 删除 `data` 下以 `.lock` 结尾的文件 |
| 系统缺少运行库 | 安装 Windows 更新，或重装程序 |

### 17.2 界面白屏 / 一片空白

通常是界面资源加载失败。先关掉重开；仍然白屏就重装一次（不会影响 `data` 里的数据）。

### 17.3 按钮点了没反应

多数是界面卡住了。等一下（可能在处理长任务），或者切到别的页面再切回来。持续无响应就重启程序。

### 17.4 下载失败

| 提示 | 处理 |
| --- | --- |
| 需要登录 | 见 4.3，换一种方式拿登录态 |
| SSL / EOF 错误 | 代理节点不稳，重试或换节点 |
| 解析失败 | 换一个链接试试；有些站点不支持 |
| 速度极慢 | 关掉代理或换节点 |

### 17.5 转录失败

| 提示 | 处理 |
| --- | --- |
| 密钥无效 / 401 / 403 | 检查 ASR 配置里的密钥是否正确、是否有权限 |
| 音频太长 | 软件会自动切分重试；若反复失败，先手动把音频切成两半 |
| 没有声音 | 确认视频本身有音轨 |
| 语言识别错乱 | 手动指定识别语言，别用自动 |

### 17.6 翻译失败

| 提示 | 处理 |
| --- | --- |
| 连接失败 | 换一个翻译引擎 |
| 译文缺失报错 | 这是保护机制（见 6.4），换引擎重试 |
| 翻译出来还是原文 | 引擎异常，换引擎 |

### 17.7 校准没效果

| 可能原因 | 处理 |
| --- | --- |
| 片源类型选错 | 这是最常见的原因，重新选对 |
| 日语片没指定「日语」 | 必须手动指定，自动判断会错 |
| 术语表里确实没有 | 改用 AI 校准，它能发现表外的错形 |
| 改完又变回去了 | 同步机制覆盖了本地修改，检查同步设置 |

### 17.8 AI 校准失败

| 提示 | 处理 |
| --- | --- |
| 连接超时 | 检查网络和接口地址；国内服务别挂代理 |
| 返回内容被截断 | 调小「每块字幕条数」，减少单次输入 |
| 全部块失败 | 通常是密钥或额度问题，先手动测试一次连接 |
| 改了但没写入 | 看报告里的「被拒绝的改动」，可能全被证据校验拦下了 |

### 17.9 声纹筛选没反应

进度条一闪就结束、什么也没变——这是线程被提前回收的已知问题，重启程序重试。若仍不行，把素材换短一点、干净一点。

### 17.10 自动投稿点不中按钮

| 可能原因 | 处理 |
| --- | --- |
| 浏览器窗口大小或缩放变了 | 保持窗口大小和缩放不变，或重新采集模板 |
| B 站页面改版 | 重新采集模板 |
| 模板缺失 | 按提示补采 |

### 17.11 需要给开发者看日志

`logs` 目录里：

| 文件 | 内容 |
| --- | --- |
| `startup.log` | 启动过程分步记录 |
| `crash.log` | 崩溃信息 |
| `ai_client.log` | AI 请求记录 |
| `calib_sync.log` | 校准同步记录 |
| `mihomo.log` | 代理相关 |

反馈问题时附上对应日志，能大幅加快定位。

### 18.3 小词典

| 词 | 意思 |
| --- | --- |
| **转录** | 把说的话变成文字字幕 |

| **校准** | 按官方译名修正专有名词，不改时间轴 |
| **对轴** | 调整字幕的出现和消失时间 |
| **软字幕** | 可以开关的字幕轨道，不烧进画面 |
| **硬字幕** | 烧进画面的字幕，不能关 |
| **声纹** | 用来识别「这是谁在说话」的声音特征 |
| **流水线** | 把多个步骤串起来自动执行 |
| **片源类型** | 这段字幕来自哪个游戏/作品，决定用哪套术语表 |
