## 1. 认识视频工具箱

### 1.1 它解决什么问题

一条视频从「找到」到「能看」通常要经过很多步：下载、分离音视频、语音转写、
翻译、校对专有名词、调时间轴、合成。视频工具箱把这些步骤放进同一个窗口，
每一步都能单独用，也能串成流水线一次跑完。

### 1.2 它能做什么

| 页面 | 主要用途 |
| --- | --- |
| 首页 | 创建任务、查看状态与日志 |
| 视频处理 | 从网站下载视频/字幕，或把分开的画面与声音合并 |
| 视频库 | 扫描本地视频，缩略图浏览与播放 |
| 字幕处理 | 语音转写、字幕翻译、术语校准、字幕合成 |
| 字幕编辑 | 边看画面边调字幕时间轴，导出 SRT/ASS |
| 流水线 | 粘贴链接或盯住下载目录，自动跑完整条链 |
| 自动化 | B 站投稿：采集页面模板、填表、后台执行 |
| 设置 | 全软件唯一的设置入口 |
| AI 托管 | 条件出现：把程序目录交给内置 AI 托管助手 |

左侧导航通常显示 8 个常驻页面。「自动化」和「AI 托管」会在启动后按需加载，
所以刚打开时可能稍晚出现；AI 托管还需要本机具备托管运行环境。

### 1.3 它不能做什么

- **不提供视频源**：只处理你提供的链接、文件或本地目录。
- **不绕过付费/权限**：需要登录或付费的内容，取决于你自己的账号与网站规则。
- **不保证机翻质量**：机器翻译只负责「先看懂」，专有名词必须走校准。
- **不是视频剪辑软件**：不做多轨剪辑、特效、调色。
- **语音分离不是内置模型**：界面有入口，但当前版本不附带分离模型。
- **安装包不含 AI 托管引擎**：托管环境体积较大，需要按需部署。

### 1.4 系统要求

- Windows 10 / 11，64 位。
- 安装与更新不需要管理员权限；默认装到 `D:\VideoToolbox`，可以改。
- 建议预留 6GB 以上磁盘空间（离线安装包约 1.0GB，安装后还会按需下载
  FFmpeg、yt-dlp、ASR 模型、播放组件等）。
- 需要 AI 的功能要自备 OpenAI 兼容接口的密钥；其余功能开箱即用。

### 1.5 关于费用

软件本身免费。以下费用由你自己承担：

- 你选择的 AI 服务商（用于 AI 校准、AI 托管、B 站分区/话题识别等）；
- 你自己的语音识别服务（如果使用在线 ASR）；
- 网络流量。

不填 AI 密钥也能完成：下载、音画合并、本地/在线语音转写、机器翻译、
脚本术语校准、字幕合成、字幕编辑、流水线（不启用 AI 校准）等。

## 2. 安装与首次启动

### 2.1 选哪个安装包

| 形态 | 适合谁 | 说明 |
| --- | --- | --- |
| 离线安装包 `VideoToolbox_Setup_v2.6.0.exe` | 新用户、需要完整离线部署 | 约 1.0GB，装完不依赖网络下载主程序 |
| 在线安装器 `VideoToolbox_OnlineSetup_v2.6.0.exe` | 已经装过旧版、网络较好 | 只下载缺失文件，通常几十 MB 起 |
| 源码方式 | 想直接跑最新代码 | 需要 Python 3.12，见第 15 章 |

已经装了旧版：打开程序 → 设置 → 程序更新 → 检查更新。内置更新器按文件差异
增量下载；同一版本也可以选「修复安装」。

### 2.2 安装步骤

1. 双击安装包，向导为简体中文，不会弹语言选择框。
2. 默认目录 `D:\VideoToolbox`，可以改；安装不需要管理员权限。
3. 安装完成后从开始菜单或桌面快捷方式启动。
4. 安装目录里的 `docs\` 会附带本说明书、使用说明、界面预览、GPL 全文和
   第三方组件声明。

v2.6.0 起主程序采用 onedir 形态：安装目录会有 `视频工具箱.exe` 和
`_internal\` 依赖目录。**不要只复制 exe**，否则会缺少运行库。

### 2.3 第一次启动会看到什么

- 出现启动画面，随后进入首页。
- 程序会检查运行组件；缺失的 FFmpeg、yt-dlp、Deno、ASR 模型、libmpv 等
  会按需下载。
- 首次运行会在程序目录下创建 `data\` 和 `logs\`。
- 如果杀毒软件拦截，请把安装目录加入信任；本程序没有购买代码签名证书。

### 2.4 AI 配置（可选，但强烈建议）

打开「设置 → 全局 AI」：

| 项 | 说明 |
| --- | --- |
| 启用 AI | 总开关 |
| 密钥 | 你的 API Key |
| 接口地址 | OpenAI 兼容地址，可填到域名或版本段 |
| 文本模型 | 用于文本理解、校准、标题等 |
| 视觉模型 | 用于截图识别、B 站投稿页识别 |
| 测试接口 | 验证地址、密钥、模型是否可用 |
| 保存并应用 | 立即写入并生效 |

密钥保存在独立的 `data\credentials.json`，只读、不随程序分发、不上传。
`data\ai_config.json` 不再保存明文密钥。

**没有密钥也能用**：只有 AI 校准、AI 托管、B 站分区/话题自动识别等能力会停用。

### 2.5 语音识别配置（可选）

「设置 → ASR 语音识别」有两种来源：

- **自有 ASR 服务**：兼容 Whisper 的接口，需要填地址、密钥、模型名和协议。
- **本地独立模型**：使用 faster-whisper，在本机跑，需要模型目录。

不认识这些参数时，保持默认并先点「测试 ASR 配置」。在线服务与本地模型
各有取舍：在线通常更快，本地不消耗 API 费用。

## 3. 界面总览与任务流

### 3.1 导航与页面职责

- **首页**：任务框、运行状态、查看日志。
- **视频处理**：下载、清晰度选择、字幕、音画合并。
- **视频库**：扫描下载目录，缩略图浏览。
- **字幕处理**：语音转录、字幕翻译、字幕校准、字幕合成。
- **字幕编辑**：播放器 + 字幕轨，手动对轴。
- **流水线**：链接全自动、下载目录监控。
- **自动化**：B 站投稿模板与任务。
- **设置**：目录、Cookie、AI、ASR、校准、引擎、同步、更新、外观。
- **AI 托管**：条件出现，用于自然语言托管。

### 3.2 拖放与打开方式

- 把**链接**拖进窗口 → 视频处理页并填入链接。
- 把**纯文本**拖进窗口且 AI 托管就绪 → 交给托管；否则会提示不可用。
- 把**视频/音频**拖进窗口 → 字幕处理页（语音转录）。
- 把**双语字幕**拖进窗口 → 字幕处理页（校准）。
- 把**单语字幕**拖进窗口 → 字幕处理页（翻译）。
- 把**文件夹**拖进窗口 → 视频库。
- 把**字幕或音视频**拖到字幕编辑页 → 直接载入编辑。
- 把文件拖到程序图标上，分派规则与拖进窗口一致。

### 3.3 最短的一条路

1. 视频处理：粘贴链接，选清晰度，下载。
2. 字幕处理：语音转录，得到 SRT。
3. 字幕处理：翻译成中文双语。
4. 字幕处理：选择片源类型，跑术语校准；需要时开 AI 校准。
5. 字幕编辑：检查时间轴，导出成品。
6. 视频处理/字幕合成：把字幕烧进画面或封装进视频。

这条链也可以在「流水线」里一次跑完。

## 4. 视频处理：下载与音画合并

### 4.1 下载视频

1. 打开「视频处理」，粘贴链接。
2. 选择清晰度。列表只显示 720p 及以上，每个分辨率一档；优先 30fps 以上，
   同档取文件更大的版本。第一项标「最高，推荐」。
3. 需要字幕时勾选「同时下载字幕」，程序会把可用字幕转成 SRT。
4. 点开始。可以并行多个任务，也可以取消。
5. 默认保存到 `data\downloads`，可在设置里改下载目录。

### 4.2 登录、Cookie 与代理

- 下载页没有单独的 Cookie 输入框。打开「设置 → 下载 Cookie（反风控）」：
  - 自动；
  - 从 8 种常见浏览器读取；
  - 使用你导出的 `cookies.txt`；
  - 只用游客 Cookie。
- 需要登录的视频，先在浏览器登录，再用「从浏览器读取」。
- 程序内置代理兜底，界面不提供代理开关；网络问题时优先检查本机网络与
  Cookie 是否过期。

### 4.3 音画合并

**自动配对**：

- 支持 mp4/mkv/webm/mov 等视频与 m4a/weba 等音频，也支持 srt/ass 字幕。
- 默认输入目录 `D:\剪辑`；输出留空时写到「输入目录\合成结果」。
- 字幕默认「烧录为硬字幕」，也可改为「封装为 MKV」或「忽略」。
- 可以强制配对不同时长的同名文件。

**手动合并**：

- 视频槽必填，音频槽必填，字幕槽可选。
- 音频不是 AAC 时会转码；视频装不进 mp4 时会用 H.264 重编。
- 适合文件名不成对、或只想临时拼一个文件的情况。

## 5. 视频库

- 启动后会自动扫描保存的下载目录，递归查找视频。
- 缩略图默认取第 5 秒画面；短视频取开头。
- 缓存放在 `data\thumb_cache`，可以随时删除，程序会重建。
- **单击**卡片：打开文件所在文件夹，并用系统默认播放器播放。
- **右键**：只打开文件夹。

视频库是浏览工具，不负责转码或剪辑。

## 6. 字幕处理：转录、翻译、合成

「字幕处理」页分三段：语音转录、字幕翻译、字幕校准。

### 6.1 语音转录

1. 选择音视频文件。
2. 选择模型来源：默认使用设置里的 ASR 配置；也可以临时选「ASR」。
3. 命令栏选择识别语言与输出格式；识别语言默认自动检测，已知语言时手动指定通常更稳。
4. 需要区分说话人时勾选「说话人分离」。
5. 开始转录，得到 SRT。

**语音分离**目前只有入口，没有内置分离模型；说话人分轨在字幕编辑导出时
选择「按说话人拆分」。

### 6.2 字幕翻译

- 支持的服务：微软翻译（默认）、谷歌翻译、DeepLx。
- 当前版本不提供「LLM 大模型翻译」；需要大模型润色时走 AI 校准。
- 字幕排布：译文在上（默认）、原文在上、仅译文、仅原文。
- 双语字幕的常见形态是「原文在上、译文在下」；校准会按字符集识别哪一行
  是中文，因此中英顺序不影响校准。
- 翻译完成后可以按声纹筛选特定说话人的字幕。

### 6.3 字幕合成

有三种常见成品形态：

| 形态 | 怎么做 | 特点 |
| --- | --- | --- |
| 软字幕 | 字幕编辑 → 内嵌字幕 | 不重编码，播放器可开关字幕 |
| 硬字幕 | 音画合并时 ASS 选「烧录为硬字幕」 | 字幕进画面，兼容性最好 |
| MKV 封装 | 音画合并时选「封装为 MKV」 | 保留字幕轨，不重编码 |

命令行 `compose` 也支持 soft / burn / mkv 三种模式，详见第 15 章。

### 6.4 字幕样式

- 字幕样式在「设置 → 字幕引擎」和字幕编辑页调整。
- ASS 导出会带当前样式；SRT 不保存样式。
- 烧录前建议在字幕编辑里预览一遍，确认没有超出画面。

## 7. 术语校准详解

### 7.1 为什么必须校准

机器翻译最容易错的不是语法，而是**专有名词**：人名、地名、角色名、技能名、
道具名。同一个名字在一部片里出现三种写法，观众会立刻出戏。校准就是把这些
词统一回官方写法。

程序内置多套游戏术语表，覆盖鸣潮、明日方舟、终末地、战双等作品，并带有
日语、韩语、塞尔达等专用表；术语条目以千计。术语表不是万能的，校准脚本
还会处理常见的音译残留、英文断词和上下文歧义。

### 7.2 两种校准方式

| 方式 | 做什么 | 什么时候用 |
| --- | --- | --- |
| 脚本校准 | 按术语表、上下文正则批量替换 | 每次都要先跑，速度快、可重复 |
| AI 校准 | 让 AI 逐块复核脚本没覆盖的疑似错形 | 术语表跑完后仍有明显错名时 |

推荐顺序：**先脚本校准，再按需开 AI 校准**。AI 校准要消耗你的 AI 额度，
而且需要人工复核，不是「一键完美」。

### 7.3 片源类型怎么选

界面提供以下片源类型（括号内是命令行旗标，开发版有完整说明）：

- 中英双语（默认，`--bi`）
- 日语原声 · 鸣潮（`--ja`）
- 日语原声 · 终末地（`--jpe`）
- 韩语原声 · 鸣潮（`--ko`）
- 明日方舟（`--ak`）
- 明日方舟 · 韩语（`--akko`）
- 终末地（`--endo`）
- 终末地 · 中英双语（`--endobi`）
- 终末地 · 韩语原声（`--endoko`）
- 中文行专属（`--zho`）
- 战双帕弥什（`--pgr`）
- 战双英文原声（`--pgren`）
- 综合手游 OST（`--wwoc`）
- 音乐点评（`--react`）
- 边狱巴士（`--limbus`）
- 最终幻想：共鸣（`--ffrs`）

命令行还支持塞尔达（`--zel`）、崩坏：星穹铁道（`--hsr`）和宝可梦（`--pkm`），
界面暂未列出，需要时用命令行。

**选错模式会误伤**。例如把鸣潮片选成终末地，术语表会把不相干的词改掉。
不确定时先用默认双语模式，再根据片源语言和游戏选择。

### 7.4 校准结果怎么看

- 校准只改文字，不改序号、时间轴、空行、换行符和 BOM。
- 报告会列出改动的 cue 数与 diff；建议先抽查前 20 条和改动密集段。
- 校准后仍然读不通的句子，多半是机翻跨 cue 断句，需要到字幕编辑里
  对着画面改写，而不是继续加术语。
- 如果校准后中文行反而更怪，先检查片源模式是否选错，再检查学习库里
  是否有误学规则。

### 7.5 AI 校准怎么用

「字幕校准」分段里有「AI 校准（Agent 级，接入你自己的 AI 辅助校准）」开关。
打开后可设置：

- 每块最多条数、每块字符预算；
- 思考模式与思考强度；
- 输入上下文预算、单次输出上限；
- 校准风格、是否联网查证、是否使用音画证据；
- 思考轮次上限、Agent 集群与协作轮数。

不理解这些参数时保持默认。AI 校准会分块读取字幕和参考行，输出建议改动；
它不会动时间轴。用量与耗时取决于你的 AI 服务。

### 7.6 校准会改坏吗

正常情况下不会改结构。脚本在写入前会做结构校验；命令行还有 `verify`
断言序号、时间轴、参考行、CRLF 和 BOM 不变。真正需要担心的是**语义误伤**：

- 通用词被当成专名（例如把普通名词「罪」改成角色名）；
- 短词命中长词（例如「德娜」出现在「米德娜」里）；
- 片源模式选错。

因此每次校准后都要抽查；发现误伤时优先修规则，而不是手工改几十条。

### 7.7 校准知识会同步吗

会。设置里有「校准知识同步」：

- 启用自动同步：启动时更新，退出后台上传；
- 立即更新：手动拉取一次。

学习库会记录确认过的规则与反例。同步用于多台设备共享，不会把你的视频
或字幕上传到云端，只同步规则文本。学习库本身在程序目录的
`subtitle_learned_kb.json`，建议定期备份。

## 8. 字幕编辑

### 8.1 能做什么

- 打开视频 + 字幕，边看边调时间轴。
- 支持 SRT、VTT、ASS、SSA 读取；导出 SRT 或 ASS。
- ASS 导出会带当前样式。
- 多人字幕可以按说话人拆分导出。

### 8.2 基本操作

1. 打开视频（`Ctrl+O`）。
2. 打开字幕（`Ctrl+Shift+O`），或把字幕拖进页面。
3. 选中一条字幕，用逐帧/0.1 秒/1 秒按钮微调起止点。
4. `[` 取当前时间为起点，`]` 取终点。
5. 需要把一条拆成两条时，把播放头放到切点，按 `Ctrl+K`。
6. 完成后保存（`Ctrl+S`）或另存（`Ctrl+Shift+S`）。

### 8.3 快捷键

| 快捷键 | 功能 |
| --- | --- |
| 空格 | 播放/暂停 |
| `,` `.` `←` `→` | 逐帧后退/前进 |
| `Shift+←` / `Shift+→` | 0.1 秒微调 |
| `Alt+←` / `Alt+→` | 1 秒调整 |
| `↑` / `↓` | 上一条/下一条 |
| `[` / `]` | 取起点/终点 |
| `Ctrl+K` | 在播放头处切分 |
| `Ctrl+A` | 全选 |
| `Del` | 删除选中 |
| `Ctrl+Z` | 撤销（最多 100 步） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存/另存 |
| `Ctrl+O` / `Ctrl+Shift+O` | 打开视频/字幕 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大/缩小/复位 |
| `Ctrl+Shift+F` | 适配选中字幕 |

### 8.4 防手滑设计

- 每条字幕的最小边界有 40ms 保护，避免拖成零长度。
- 状态栏会提示重叠条数与过短条数，并提供修正入口。
- 内嵌字幕时如果字幕超出片长，会先提示。
- 撤销栈保留 100 步。

当前版本没有「磁吸吸附」开关；对轴以逐帧和 0.1 秒微调为主。

## 9. 流水线

### 9.1 链接流水线

粘贴一个链接后，自动执行：

**下载 →（无字幕时自动语音转录）→ 翻译 → 校准 → 二次校准 → 成品**

适合批量处理同一类 reaction 片、直播切片或官方节目。

### 9.2 下载目录监控

打开监控后，程序会盯住**当前下载目录**里新出现的视频，自动走同一条链。
当前版本不提供单独的「监控文件夹」选择器；要换目录，先改设置里的下载目录。

### 9.3 状态与断点

- 「自动」默认开启；并发数 1–8，默认 3。
- 有「立即扫描」「重试失败项」「清空任务进度」。
- 进度保存在 `data\pipeline_state.json`。
- 重启后：已完成的跳过，运行中的转回待执行；产物需要指纹一致才复用。
- 状态文案包括：等待文件、待执行、进行中、下载中 N%、失败、已完成。
- 无字幕的链接任务会自动调用设置页的 ASR 转录配置；ASR 未配置或不可达时显示
  「失败：语音转录」，修好后点「重试」即可。
- 流水线翻译优先走必应；必应不可用时才回退谷歌。

### 9.4 什么时候不适合用流水线

- 需要逐句人工润色的长片；
- 片源语言混杂、需要中途换校准模式；
- 下载链接需要人工登录/验证。

这些情况建议分步走：先下载，再手动转录/翻译/校准。

## 10. 自动化：B 站投稿

### 10.1 使用前提

- 本机浏览器已登录 B 站；
- 已配置全局 AI（分区/话题识别需要视觉与文本模型）；
- 先在「自动化」页完成模板采集。

### 10.2 模板采集

需要采集 **13 张模板**：10 张必需，3 张可选。

- 必需模板覆盖投稿页的关键控件（标题、简介、标签、分区、上传、封面等）。
- 3 张可选：参与话题、第一张候选封面、创作声明「自制」。
- 每张模板的流程：选窗口 → 抓帧 → 框选目标 → 存为该模板。
- 页面会显示 ✓/✗ 和采集要点；缺必需模板时不能执行任务。

### 10.3 填写投稿表单

支持字段：视频、标题、简介、标签、分区、话题。

- 点「从 视频信息.txt 读取」，程序会在当前目录和上一级目录查找并解析
  标题、简介、标签、分区、话题。
- 也可以手工填写。
- 默认「演练」：只走一遍流程，不真正提交。确认无误后再关闭演练。

### 10.4 执行与失败处理

- 任务在后台线程执行，不阻塞主界面。
- 失败会保存整屏截图到 `data\bili_upload\shots`。
- 结果包含失败步骤、缺失控件和截图路径，按提示补采模板或检查登录态。
- 执行期间不要手动抢占鼠标/键盘；自动化会尽量不移动你的光标。

### 10.5 命令行投稿（源码方式）

v2.6.0 新增 `src\bili_auto_submit.py`，通过 Windows UI Automation +
PostMessage 操作投稿页，不移动真实鼠标、不切前台。它只被 `agent_cli`
的 `bili-submit` 调用，**GUI 不直接使用，安装包也不收录**；需要源码方式运行。

```bash
tools\python\python.exe src\bili_auto_submit.py "<素材目录>" --dry-run
tools\python\python.exe src\bili_auto_submit.py "<素材目录>" --visibility self
tools\python\python.exe src\bili_auto_submit.py --probe
```

素材目录约定放视频、封面、字幕和 `投稿信息.txt`（也接受 `视频信息.txt`）。
首次使用先跑 `--probe` 检查控件，再用 `--dry-run` 演练。

## 11. AI 托管

AI 托管是可选页面，只有本机具备托管运行环境时才会出现。

- **状态卡片**：显示托管引擎是否就绪、当前工作区。
- **任务卡片**：与首页任务框共用入口。
- **运行输出**：查看托管过程与结果。
- 未就绪时会显示部署引导。
- 工作区就是程序根目录；运行期数据在 `data\harness-home`。
- 按钮：打开/停止交互控制台、重新检测、交给 AI 托管。

托管引擎体积较大（约 2.2GB），**不随安装包分发**。没有部署时，页面可能
不出现或显示未就绪，这不影响其他功能。

## 12. 设置页逐项说明

设置是唯一入口，按界面顺序：

### 12.1 目录

- 下载目录；
- 数据根目录；
- 引擎工作目录。

改数据根目录会把配置、缓存和任务状态迁到新位置；迁移前建议先退出程序。

### 12.2 下载 Cookie（反风控）

自动、从浏览器读取、使用 `cookies.txt`、只用游客 Cookie。支持 8 种常见浏览器。
登录态过期时重新读取一次即可。

### 12.3 全局 AI

启用 AI、密钥、接口地址、文本模型、视觉模型、测试接口、自动匹配、
保存并应用。详见 2.4。

### 12.4 ASR 语音识别

- 转录模型来源：自有 ASR 服务 / 本地独立模型；
- 接口地址、密钥、模型名、识别提示词、接口协议
  （识别语言在「语音转录」页命令栏选择）；
- 说话人分离、语音分离（占位）；
- 本地模型名与模型目录；
- 测试 ASR 配置、保存并应用、调用示例。

### 12.5 AI 校准

每块最多条数、每块字符预算、思考模式、思考强度、输入上下文预算、
单次输出上限、校准风格、联网查证、音画证据、思考轮次上限、
Agent 集群、协作轮数。默认值适合大多数片源。

### 12.6 字幕引擎

转录、翻译、合成参数。翻译引擎的选择在字幕处理页，不在这里。

### 12.7 校准知识同步

启用自动同步（启动自动更新 + 退出后台上传）、立即更新。

### 12.8 程序更新

显示当前版本，提供「检查更新」。增量更新只下载变化的文件；
同一版本可选择「修复安装」。

### 12.9 界面美化与界面

背景图、主题（浅色/深色/跟随系统）、界面缩放、云母特效、主题色。
背景图过大或格式不支持时，程序会回退到默认背景。

### 12.10 关于

版本号、许可全文入口、第三方组件来源。

## 14. 更新与卸载

### 14.1 检查更新

打开「设置 → 程序更新 → 检查更新」。更新器会：

1. 读取当前版本；
2. 从 GitHub Releases 的固定更新通道读取文件清单；
3. 只下载 sha256 变化的文件；
4. 校验后替换，并重启程序。

同一版本也提供「修复安装」。如果更新失败，优先改用离线安装包覆盖安装。

### 14.2 手动更新

下载新的离线安装包，直接运行覆盖安装。安装器会关闭旧进程，保留 `data\`。

### 14.3 卸载

- Windows「设置 → 应用 → 已安装的应用」；
- 或开始菜单里的「卸载 视频工具箱」。

卸载**不会删除** `data\`、`logs\` 和你的下载文件。要彻底清理，
卸载后手动删除安装目录即可。

## 16. 常见问题

**下载很慢或失败**
先换网络/代理，再检查 Cookie 是否过期。GitHub 国际链路慢是常见原因，
不是程序故障。

**下载的视频没有声音**
音视频可能分开下载。用「视频处理 → 音画合并」自动配对，或手动合并。

**语音识别报错**
检查 ASR 地址、密钥、模型名和协议；本地模型检查模型目录。先用「测试 ASR 配置」。

**翻译后用不了谷歌**
谷歌免费端点在本机网络下经常不可用，优先用微软翻译。

**校准没有改动**
可能片源模式选错，或术语表已覆盖。看校准报告；不要为了「有改动」而
反复加词。

**校准把正常词改坏了**
记录 cue 号和原词，换正确的片源模式；在命令行用 `verify` 检查结构，
用 `subfix` 回退单条，避免直接改成品。

**字幕和画面对不上**
到字幕编辑页对轴；先用逐帧，再用 0.1 秒微调。不要用整体平移解决
中间段落错位。

**烧录很慢**
硬字幕需要重编码，时长越长越慢；急用时先做软字幕或 MKV 封装。

**B 站投稿找不到控件**
重新采集缺失模板，确认浏览器窗口没有缩放/改版，登录态有效；
失败截图在 `data\bili_upload\shots`。

**更新失败**
改用离线安装包覆盖安装；`data\` 会保留。

**AI 托管页不出现**
托管引擎未部署或适配层未就绪；不影响其他功能。
