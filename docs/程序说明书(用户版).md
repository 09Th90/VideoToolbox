## 一、这个软件能帮你做什么

**视频工具箱**是一个 Windows 桌面软件，把「找视频 → 下下来 → 弄出字幕 → 修好字幕 → 装回视频」这一整条流程装进一个窗口，不用在好几个软件之间来回倒腾。

六个功能页，从左边的导航栏切换：

| 页面 | 干什么用 |
| --- | --- |
| **视频处理** | 从 YouTube、B 站等网站下载视频（含字幕、封面、信息），也能把分开下载的画面和声音合成一个文件 |
| **视频库** | 把某个文件夹里的视频扫出来，用缩略图卡片浏览、点开就播 |
| **字幕处理** | 给视频生成字幕、翻译字幕、校准专有名词、把字幕烧进画面或封装进视频 |
| **字幕编辑** | 在软件里一边放视频一边拖字幕的时间轴，把字幕和画面对齐 |
| **流水线** | 粘贴一个链接，下载→翻译→校准→打包全自动跑完；也可以盯住一个文件夹自动处理 |
| **设置** | 填 AI 密钥、语音识别服务、下载目录、界面主题等（全软件唯一的设置入口） |

**你不需要懂技术**：不用装 Python，不用配环境变量，双击图标就能用。需要用 AI 的功能（字幕润色、AI 校准）要先填一次自己的 AI 密钥，其余功能开箱即用。

## 二、安装与启动

### 2.1 选哪种安装包

| 安装包 | 体积 | 适合谁 |
| --- | --- | --- |
| **离线安装包** `视频工具箱_Setup_v1.15.7.exe` | 约 548 MB | 大多数人。一次下载，装的时候不用联网拉组件 |
| **在线安装器** `视频工具箱_在线安装_v1.15.7.exe` | 约 32 MB | 下载体积小，但安装时要从网上拉约 104 MB 组件 |

> 在线安装器从 GitHub Pages（海外）下载组件，国内直连常常只有几十 KB/s。**慢的是这条国际链路，不是软件本身有问题**。遇到这种情况直接换离线安装包最省事。
>
> 如果你在局域网里有分发源，或者装了代理软件，在线安装也能很快——具体办法见《使用说明.txt》的「在线安装太慢怎么办」一节。

### 2.2 安装与打开

1. 双击安装包，安装向导全程简体中文（不会弹语言选择框）；
2. 默认装到 `D:\VideoToolbox`，可以改；**安装不需要管理员权限**，不会弹 UAC 窗口；
3. 装完从开始菜单或桌面快捷方式打开，也可以直接双击安装目录里的 `视频工具箱.exe`。

### 2.3 几个方便的打开方式

- **把链接拖到图标上**：直接打开「视频处理」页并把链接填进去，省掉复制粘贴；
- **把文件夹拖到图标上**：直接打开合并页并填好路径；
- **把文件拖进已打开的窗口**：视频和字幕会进「字幕编辑」页，链接文字会进下载页，文件夹会进视频库。

### 2.4 如果打不开

`视频工具箱.exe` 没有做代码签名（签名证书要花钱买）。少数开启了 Device Guard 或应用控制策略的电脑会拦住它。这种情况改用脚本方式启动：双击安装目录里的 `src\视频工具箱.bat`（需要电脑装有 Python 3）。

另外，软件带**单实例保护**——已经开着的时候再双击图标不会开第二个窗口，也不会把配置写乱。

## 三、第一次使用：先填一次 AI 配置

**不用 AI 也能正常下载视频、看视频库、编辑字幕时间轴。** 只有「字幕润色」「AI 翻译」「AI 校准」这几项需要 AI。要用就去 **设置 → 全局 AI** 填一次，全软件共用这一套配置，不用到处重复填。

需要填四项：

| 填什么 | 举例 |
| --- | --- |
| 密钥（API Key） | 你的服务商发给你的那串字符 |
| 接口地址 | `https://open.bigmodel.cn/api/paas/v4` |
| 文本模型 | `glm-4.7-flash` |
| 视觉模型 | `glm-4.6v-flash`（截图识别类功能才用到） |

**接口地址不用填得很精确**——只填域名、填到 `/v1`、填完整的 `/chat/completions` 都能认，软件会自动补全。用 Azure 的话填到 `deployments/<部署名>` 就行。

兼容的服务：OpenAI、DeepSeek、智谱、Gemini 兼容层、Ollama（本地模型）、Azure OpenAI 等，只要是 OpenAI 兼容接口都能用。

填完点 **「测试接口」** 验证连通，再点 **「保存并应用」**——保存后立刻生效，同时自动写入字幕引擎，不用再进引擎设置里改一遍。

> **关于你的密钥**：密钥只存在本机的 `data\ai_config.json` 里，不随软件分发、不上传到任何地方。软件自带的源代码里不含任何真实密钥。

### 3.1 语音识别（ASR）要不要配

字幕处理页要把视频里的说话声转成文字，这一步叫「语音识别」。软件内置了几个免费在线转录引擎（必剪、剪映等），**不配 ASR 也能用**。

配了 ASR 的好处是可以选择更准的服务或本地模型。在 **设置 → ASR 语音识别（转录配置）** 里选一种来源：

- **自有 ASR 服务**（推荐）：填接口地址、密钥、模型名。任何 OpenAI 兼容的语音识别接口都行，比如 `FunAudioLLM/SenseVoiceSmall`、`whisper-1`，以及阿里云百炼的 ASR 服务。**不用下载模型文件**。
- **本地独立模型**：填模型名（如 `large-v3`、`large-v3-turbo`）和模型目录。需要机器上有 faster-whisper 运行环境和对应的模型文件。

接口协议那一栏**留「自动识别」就好**——软件会按你填的地址和模型名自己判断该用哪种协议。目前支持 11 种协议：自动识别、OpenAI Whisper 兼容、Azure OpenAI、Chat 音频转写（百炼 / MiMo）、Deepgram、ElevenLabs Scribe、Google Gemini、火山引擎（豆包）、AssemblyAI、百炼实时（WebSocket）、百炼原生（ASR 专用端点）。

填完点「测试 ASR 配置」检查一遍。

> **v1.15.7 修了一个网络问题**：用国内服务（比如阿里云百炼）时，如果你开着代理软件，请求可能被代理送到海外节点导致连不上。现在软件对国内端点强制直连，不用你手动关代理了。

## 四、视频处理：下载与音画合并

这一页顶部有两个分段标签：**视频下载** 和 **音画合并**。

### 4.1 视频下载

1. **粘贴链接**——支持 YouTube、B 站等 yt-dlp 支持的站点；
2. **选保存位置**——点「浏览…」选文件夹，或直接把文件夹拖进输入框。选一次就长期记住，下次打开自动填回，不用每次重选。就算那个文件夹现在不在（比如外接硬盘没插），记忆也不会丢，插回来照样能用；
3. **点「检测画质」**——自动列出 720p 及以上的档位。同一分辨率只保留文件最大的那个，有 60fps 就只留 60fps，省得你在十几个选项里纠结；
4. **点「加入并行下载」**——任务进入列表，可以同时挂好几个。勾选「同时下载字幕」（默认开着）会一并把博主上传的字幕和自动生成字幕都下下来，转成 `.srt` 格式，支持中英日韩西法德等多语言。

**每个视频会自动打包成独立文件夹**，文件夹名就是视频标题：

```
某视频标题\
  ├─ 某视频标题.mp4    视频本体（音频始终取最高质量）
  ├─ 封面.jpg          封面图，统一转成 1280x720
  ├─ 视频信息.txt      标题 / 简介 / 视频链接 / 博主主页 / 画质 / 下载时间
  └─ *.srt             字幕（如果勾了下载字幕）
```

几个贴心的细节：

- 封面不管原图是竖的还是超宽的，都等比缩放加黑边补到精确 1280x720，**不会拉伸变形**；多张候选时自动取分辨率最高的；
- `视频信息.txt` 用 UTF-8 with BOM 编码，**Windows 记事本打开不乱码**；
- 标题里的非法字符（`\ / : * ? " < > |`）自动换成空格，超长截断到 80 字；
- **同名视频不会覆盖**——已有同名文件夹时自动改叫「标题 (2)」「标题 (3)」；
- 下载完成后自动打开那个文件夹给你看。

下载过程中可以继续粘贴下一个链接，互不干扰，每个任务有独立进度。遇到 B 站之类的风控（HTTP 412）会自动等待重试。所有后台调用都隐藏了黑色命令行窗口，不会在屏幕上闪来闪去。

> **字幕下不下来不影响视频**：字幕是在视频下完之后单独拉的，就算字幕接口被风控或者这个视频压根没字幕，也只提示一句，视频、封面、信息文件照常给你。

### 4.2 音画合并

有些站点会把画面和声音分成两个文件下（比如 `.mp4` 画面 + `.m4a` 声音），需要合成一个才能正常看。

1. 切到「音画合并」分段，选择输入文件夹；
2. 点 **「扫描配对」**——自动按文件名和时长把画面和声音配成一对；
3. 点 **「开始合成」**，结果输出到「合成结果」文件夹。

处理方式：`.m4a` 直接封装不转码（不损失音质）；`.weba` 自动转成 AAC；`.srt` 字幕作为软字幕挂进去（播放器里可以开关）；`.ass` 特效字幕可以选烧录进画面、封装成 MKV、或者忽略。

## 五、视频库：本地视频浏览

1. 默认显示下载页记住的那个保存位置，也可以点「浏览…」换别的文件夹，或点「同步下载目录」跟随下载页；
2. 点 **「刷新」** 开始扫描——**打开软件时不会自动扫描**，免得误扫一个几万文件的大目录卡住；
3. 会递归扫描子文件夹，所以每个视频的独立文件夹里的视频都能直接看到。卡片名显示「文件夹名 \ 文件名」，方便区分；
4. 卡片上自动显示视频时长和文件大小；
5. **单击卡片直接播放，右键打开所在文件夹**。

缩略图会自动生成并缓存在 `data\thumb_cache`，第二次刷新就快了。缓存名里含完整路径指纹，**不同文件夹下的同名视频不会串图**。

## 六、字幕处理：转录、翻译、校准、合成

这一页内嵌了一个开源字幕引擎（VideoCaptioner），在页内直接用，不弹独立窗口。顶部有几个分段标签：**任务创建 / 语音转录 / 字幕翻译 / 字幕校准 / 字幕视频合成**。

进入这一页不会有卡顿——引擎在软件启动后就在后台预热好了，实测界面构建 0.7 秒级。

### 6.1 基本用法

把视频拖进来或者粘贴链接，然后按需走这几步：

- **语音转录**：把视频里的说话声转成字幕文字；
- **字幕翻译**：翻成中文（或别的语言），输出双语字幕；
- **字幕校准**：把机器翻译错的专有名词改对（下面单独讲，这是本软件的招牌功能）；
- **字幕视频合成**：把字幕烧进画面，或封装成可开关的软字幕。

字幕优化和配音这两项依赖大语言模型，**要先在设置里填好 AI 配置**。不填的话只是这两项用不了，转录和翻译照常能用。

配置、日志、模型缓存、任务产物统一放在软件文件夹的 `data\VideoCaptioner\` 下，**不会往 C 盘写东西**。

### 6.2 关于翻译服务的一个说明

字幕翻译可以选大模型翻译（质量最好）或者必应、谷歌、DeepLx 这几个免费服务。

需要知道的是：**免费翻译服务的公开端点这几年陆续失效了**——微软翻译的取 token 端点官方已经 404，谷歌翻译在国内网络通常不可达。软件已经按官方新版实现把这些端点、参数、语言映射都更新过了，但端点本身不通就是不通，这不是软件能修的。

所以：

- 选了免费服务如果整批失败，软件会自动改用微软翻译再试一次并提示你；
- **v1.15.1 起，如果译文缺失，软件会明确报错并且不生成文件**，不会再悄悄产出一个「名字叫『-谷歌翻译.srt』、内容其实还是原文」的假翻译骗你；
- 想要稳定的翻译质量，建议直接用大模型翻译。

引擎的翻译兜底行为记录在 `logs\vc_fallback.log`，出问题时可以给维护者看这个文件。

### 6.3 字幕校准（招牌功能）

机器翻译最容易翻错的就是**专有名词**——人名、地名、技能名、道具名。一部动画里主角名字被翻成三种写法，看着非常出戏。字幕校准就是专门解决这个的。

**基本用法**：

1. 切到「字幕校准」分段，选一个 `.srt` 文件；
2. 选**片源模式**（共 12 项）：中英双语（默认）/ 日语原声·鸣潮 / 日语原声·终末地 / 韩语原声·鸣潮 / 明日方舟 / 明日方舟·韩语 / 终末地 / 中文行专属 / 战双帕弥什 / 战双英文原声 / 综合手游OST / 音乐点评；
3. 点 **「开始校准」**。

**它保证不动什么**：序号、时间轴、空行、换行符、BOM **一个字节都不改**，只替换中文行里的术语。也就是说校准完的字幕和原字幕在播放器里的表现完全一致，只有文字变了。

**输出**：默认生成同目录的「原名.calib.srt」，重名自动加序号，**绝不覆盖你的原字幕**。

**可选项**：

- 修正英文/参考行（只在双语模式下有效）；
- 生成改动对照报告（同名 `.md`），里面写清楚每处改了什么、依据是什么；
- 仅统计命中——先看看会改哪些词，不写文件。

**AI 校准（推荐）**：打开「AI 校准」开关后，校准就不只是跑一遍机械术语表，而是让 AI 逐块复核术语表没覆盖到的疑似错形。它的流程是：

① 先跑一遍术语脚本（官方术语表命中的部分必定正确，兜底）→ ② 抽出字幕表、剥掉时间轴 → ③ 载入知识库 → ④ 自行分块 → ⑤ 逐块让 AI 复校 → ⑥ **证据校验**（每处改动必须能被知识库或联网查证解释，解释不了的一律拒绝）→ ⑦ 按边界合并回填 → ⑧ 独立校验（再断言一遍结构完全一致）→ ⑨ **片源档案**（v1.15.1 新增：输出中文标题、标签、官方核对结果、脚本沉淀建议）。

第 ⑥ 步是关键：**AI 不允许自由改写句子**，只能做有依据的名词级替换；行数变化、整句改写、无依据的改动全部拒绝并写进报告。这是为了防止 AI 把你的字幕改得面目全非。

**v1.15.6 起 AI 还能联网查证**：知识库里没收录的疑似错形，AI 可以发起联网搜索、抓取官方资料页面，把查到的内容当作**只读证据**再下结论。查证结果仍然要过第 ⑥ 步的证据校验，AI 不能凭搜索结果自由发挥。网络出问题时会自动降级，不会打断校准。

**「再次校准」**：以上一轮的输出为输入再跑一遍，专挑残留的错形。输出 `原名.calib.r2.srt`、`原名.calib.r3.srt`……可以连续点，直到满意为止。

**报告怎么看**：勾选「生成改动对照报告」会写一个同名 `.md`，里面有每处改动的序号、原文、校准后、依据，以及**被拒绝的 AI 提议和拒绝原因**（方便你人工复核）。标 ⚠ 的是知识库还没收录的疑似新错形，可以后续沉淀进知识库。

> AI 校准开启时「仅统计术语命中」会自动关闭（AI 校准需要产出文件）。没配 AI 或接口不可用时，请把这个开关关掉，用纯脚本校准一样能用。

### 6.4 校准知识同步

不同用户在使用中会沉淀出不同的校准成果（术语表、实体、上下文规则）。软件把它们在用户之间共享，最终收敛成全体内容的并集。

**你这边只需要知道一件事**：更新在启动时后台自动执行，你也可以在设置页点「立即更新」。上传完全无感，界面上没有上传按钮——退出软件时自动在后台完成，不弹窗、不阻塞退出。

合并是**确定性**的：本地缺失的直接采用远程，双方各自新增的都能并进来，同一处双方改成不同内容时保留本地并记冲突日志。**多用户之间不会互相覆盖**。

不想同步的话，在设置页关掉「启用自动同步」即可。日志在 `logs\calib_sync.log`。

## 七、字幕编辑：看着画面对轴

下载来的字幕时间轴常常不准——字幕比画面早半秒或者晚一秒，看着很难受。这一页让你在软件里一边放视频一边把时间轴拖准，不用在播放器和文本编辑器之间来回切。

> **首次使用要装一次播放组件**：画面播放由 libmpv 提供（约 40 MB），出于许可和体积考虑它不随安装包分发。在程序目录执行：
> ```
> python tools\download_open_source_deps.py --only mpv
> ```
> 或到发布页手动下载 `libmpv-2.zip` 解压到 `tools\mpv\`。
>
> **没装也不会崩**，本页只提示一句，字幕表的查看和编辑照常能用。

### 7.1 界面布局

- **工具条**：打开视频 / 打开字幕 / 保存 / 另存为 · 播放（暂停）· ◀ 帧 / 帧 ▶ · 倍速下拉 · 右侧时间码
- **编辑条**：切分 / 合并 / 删除 / 插入 / 取起点 `[` / 取终点 `]` / 前移 0.1s / 后移 0.1s · 撤销 / 重做（每个按钮悬停都有提示，写着对应快捷键）
- **上半区**（左右可拖分隔）：左边画面，右边字幕表（序号 / 起点 / 终点 / 时长 / 文本）
- **下半区**：波形时间轴——灰色波形上叠着字幕块，**直接拖块就能改时间**
- **底部状态栏**：视频名 / 字幕名 / 条数与字数 / 重叠与过短条数 / 编码与换行 / 当前缩放 / 「● 未保存」

### 7.2 基本流程

1. **「打开视频」**——画面加载，同时后台解析音频波形（首次会显示进度条，之后走缓存，秒开）；
2. **「打开字幕」**——载入 `.srt`，提示会写明条数、源编码（UTF-8 / GBK 等）与换行格式（CRLF / LF）；
3. **边看边对**：拖波形上的字幕块改时间；在波形上双击可以在该处切分；表格里双击可以改起点、终点、文本（时间按 `时:分:秒.毫秒` 填，比如 `00:01:23.456`；文本里的换行在表格中显示为 ` / `）；
4. **「保存」** 写回原文件，**「另存为」** 另存一份。

### 7.3 快捷键

焦点在本页时生效（在表格里打字时，方向键照常给文本框用）：

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `,` `.` | 后退 / 前进一帧（`←` `→` 同效） |
| `Shift+←` / `→` | 选中字幕整体前移 / 后移 100ms |
| `Alt+←` / `→` | 前移 / 后移 1 秒 |
| `↑` / `↓` | 上一条 / 下一条，并把播放头跳过去 |
| `[` / `]` | 把选中条目的起点 / 终点设为播放头当前位置 |
| `Ctrl+K` | 在播放头处切分 |
| `Del` | 删除选中条目（表格可多选，一并删除） |
| `Ctrl+Z` | 撤销　　`Ctrl+Y` / `Ctrl+Shift+Z` 重做 |
| `Ctrl+S` | 保存　　`Ctrl+Shift+S` 另存为 |
| `Ctrl+O` | 打开视频　　`Ctrl+Shift+O` 打开字幕 |
| `Ctrl+=` / `-` / `0` | 时间轴放大 / 缩小 / 缩放到整轨 |
| `Ctrl+Shift+F` | 缩放到选中条目所在区间 |

### 7.4 几个防手滑的设计

- **撤销 100 步**，拖动改时间也算一步——拖之前先存快照，所以撤销能精确回到「拖动前」，而不是「拖了一下之后」；
- **保存时自动备份**：如果目标文件已存在且没有同名 `.bak`，先自动备份一份，改错了能回退；
- 打开新视频或新字幕前，如果有未保存改动，会先问你一句「放弃改动？」；
- 切分或取边界如果会让某条字幕短于一帧（40ms），操作会被拒绝并提示，**不会写出坏数据**；
- 序号、时间轴格式、换行符、BOM 全部原样保留；
- 切到别的页面自动暂停播放；退出软件时释放播放组件，不留临时文件。

### 7.5 内嵌字幕与字幕层

- **内嵌字幕**：把当前字幕（**包含还没保存的改动**）作为一条独立的 mov_text 轨道挂进 mp4。用的是流复制、**不重新编码**，所以几秒钟就完成，画质零损失，播放器里可以开关这条软字幕。
- **字幕层**：在视频画面上叠一个透明的字幕预览层，随播放实时渲染当前字幕，**所见即所得**——你在这里调好的样式，就是最终烧录出来的样子。

> 如果你要的是把字幕**硬烧录**进画面（播放器关不掉的那种），请用「字幕处理」页的「字幕视频合成」分段。本页的硬烧录路径已经弃用——实测会让处理进程卡死。

## 八、流水线：一条链接全自动跑完

前面几页都是手动一步步来。如果你有一批视频要走同样的流程，用这一页。

**粘贴链接，剩下全自动**：下载（原片 + 字幕 + 封面 + 信息）→ 翻译 → 字幕校准 → AI 二次校准 → 成品打包。

也可以**盯住一个文件夹**：下载目录里新出现的视频会被自动接管，判断下载完成后走同一条链，中间还能自动做音画合并。

### 8.1 页面上有什么

- **新建任务**：粘贴链接，回车或点「添加任务」；
- **自动流水线**：开关，以及是否启用 AI 二次校准；
- **任务进度**：每个任务的各个阶段状态一目了然——等待中 / 就绪 / 进行中 / 完成 / 失败 / 跳过。

### 8.2 几个值得知道的特性

- **断了能接着跑**：任务状态实时存盘，软件重启后已完成的阶段自动跳过、正在进行的归位重跑，不会从头再来一遍；
- **一个任务失败不拖累别的**：失败被隔离在当前任务，队列里的其他任务照常推进；
- **输入没变就不重跑**：产物带着输入指纹，同样的输入不会重复劳动；
- **任务排队执行**：单并发、先进先出，不会同时开好几个把机器压垮；
- **存量文件不会被自动处理**：只接管新出现的，你之前放在那里的文件不会被莫名改动。

不想用这个功能的话，在「自动流水线」里关掉开关就行。

## 九、设置页逐项说明

左侧导航最底部的 **「设置」** 是全软件唯一的设置入口，一页纵向排开：

### 9.1 目录

- **下载目录**：视频下载的默认保存位置（与下载页联动）
- **数据根目录**：所有运行期文件的根，默认在软件文件夹，可以整体挪到别处
- **引擎工作目录**：字幕引擎任务产物的位置，只读，固定在软件文件夹（不落 C 盘）

> 所有默认位置都落在软件文件夹，**不写系统盘**。想搬家见下面第十节。

### 9.2 全局 AI

一套 OpenAI 兼容配置（密钥 / 接口地址 / 文本模型 / 视觉模型），**全软件共用**——工具箱自己、字幕引擎、AI 校准都用这一套。点「测试接口」验证，「保存并应用」立即生效并同步写入字幕引擎。

### 9.3 ASR 语音识别（转录配置）

转录模型的来源：自有 ASR 服务（OpenAI 兼容接口）或本地独立模型（模型名 + 模型目录）。保存后自动写入引擎的「转录配置」，不用进引擎设置里手改。协议留「自动识别」即可。

### 9.4 AI 校准

决定 AI 校准一次处理多少内容、改到什么程度：

| 选项 | 说明 |
| --- | --- |
| **思考模式** | 开关。关掉更省更快；长片源做整句重写时建议打开 |
| **思考强度** | v1.15.6 新增，思考模式打开时才显示。参考模型厂商的「高级配置」档位 |
| **每块最多条数 / 每块字符预算** | 块越小越稳（读不完会自动折半重试），但块多就更慢 |
| **输入 / 输出预算** | 单次请求的 token 上限，有快捷档位可选。v1.15.6 起输出上限最高 512K |
| **校准风格** | 「术语级（只替换名词，稳妥）」或「整句重写」。**不确定就选术语级** |

用哪套 AI 由上面的「全局 AI」统一决定，这里不再单独选通道。

### 9.5 字幕引擎

转录、翻译、合成等运行参数。LLM 和保存位置已经上收到全局设置，这里不重复。

### 9.6 校准知识同步

自动同步开关，以及「立即更新」按钮。上传在退出软件时后台完成，**没有上传按钮**（这是故意的，免得你操心）。

### 9.7 界面

- **主题**：深色 / 浅色 / 跟随系统三档，另有 8 种预设主题色（默认绿 `#45C877`）
- **界面缩放**：立即生效，100%–200% 都一致
- **云母特效**：Windows 的亚克力/云母材质效果
- **背景**：可以模糊，也可以给每个导航板块单独设背景图（支持直接把图片拖进去，手输路径会做四态校验）

> 主题切换在**重启软件后完全生效**。

## 十、文件都放在哪

软件是**绿色便携**的：运行中产生的全部文件——配置、下载、缩略图缓存、日志、临时文件，以及字幕引擎的配置和缓存——统一放在「数据根目录」下，**默认就是软件所在目录**。把整个文件夹拷走，就等于把全部数据带走了，不会在系统盘留下东西。

### 10.1 想把数据放到别处

比如软件放 C 盘只读目录、数据想放 D 盘：

1. **设置 → 目录 → 数据根目录**，填入或选择目标文件夹，点「应用」；
2. 软件会把现有 `data\` 和 `logs\` 的内容迁移过去（同名文件保留新位置的值）；
3. 在程序目录生成 `data_dir.txt` 记录新位置；
4. **重启后完全生效**。

想切回来点「还原默认」即可。

### 10.2 主要目录一览

```
视频工具箱\
├─ 视频工具箱.exe          主程序（双击这个）
├─ data\                   你的数据（配置、下载、缓存）
│   ├─ config.json         全局设置（下载目录、数据根、同步开关）
│   ├─ ai_config.json      AI 与 ASR 配置（含你的密钥，别外传）
│   ├─ downloads\          默认下载目录
│   ├─ thumb_cache\        视频库缩略图缓存（可删，会自动重建）
│   ├─ waveforms\          字幕编辑页的波形缓存（可删，会自动重建）
│   └─ VideoCaptioner\     字幕引擎的数据（配置 / 缓存 / 模型 / 任务产物）
├─ logs\                   日志（出问题时给维护者看这个）
│   ├─ gui_errors.log      界面异常记录
│   ├─ calib_sync.log      校准知识同步日志
│   ├─ startup.log         启动耗时诊断
│   └─ vc_fallback.log     字幕引擎翻译兜底日志
├─ docs\                   说明文档与第三方许可声明
├─ tools\                  运行时依赖（已内置，无需联网下载）
└─ src\                    源代码（脚本方式启动时用）
```

**可以放心删的**：`data\thumb_cache\`（缩略图缓存）、`data\waveforms\`（波形缓存）、`data\tmp\`（临时文件）、`logs\` 里的日志。删了都会在需要时自动重建，只是第一次会慢一点。

**不要删的**：`data\ai_config.json`（你的 AI 密钥配置）、`data\config.json`（全局设置）、`tools\` 里的任何东西、`docs\VideoCaptioner_GPL-3.0.txt`（开源许可全文，法律要求必须保留）。

### 10.3 卸载

卸载**不会删除 `data\` 目录**——你的配置、下载记录、字幕成果都留着。确认不需要了自己手动删掉即可。

## 十一、常见问题

**Q：打开软件没反应 / 被系统拦住了？**
A：exe 没有代码签名，开启 Device Guard 或应用控制策略的电脑可能拦截。改用脚本方式启动：双击 `src\视频工具箱.bat`。

**Q：字幕翻译总是失败？**
A：免费翻译服务的公开端点这几年陆续失效了（微软 token 端点 404、谷歌国内不可达），这是端点侧的问题。软件会自动改用微软翻译重试一次；仍然失败的话，建议在设置里配好 AI 用大模型翻译。v1.15.1 起翻译不完整会**明确报错且不生成文件**，不会再悄悄给你一个内容还是原文的「假翻译」。

**Q：AI 校准点了没反应或报错？**
A：先检查 **设置 → 全局 AI** 是否填好、点「测试接口」是否通过。没配 AI 时请关闭「AI 校准」开关，用纯脚本校准一样能用。校准页有「刷新」按钮，界面卡住时点一下可以复位（正常运行时不会打断任务）。

**Q：字幕编辑页打开视频只有声音没有画面？**
A：播放组件 libmpv 没装好。执行 `python tools\download_open_source_deps.py --only mpv` 重新拉取一次，然后重启软件。

**Q：用国内 AI 服务（比如百炼）连不上，报代理错误？**
A：v1.15.7 已经修了——对国内端点强制直连，不再被系统代理送到海外节点。如果还在用旧版本，升级即可；临时办法是关掉代理软件。

**Q：在线安装器下载特别慢？**
A：慢的是 GitHub Pages 的国际链路。最省事的办法是换用离线安装包（约 548 MB，一次下完）。有内网源或代理软件的话也可以用那些方式提速，详见《使用说明.txt》。

**Q：下载的视频字幕时间轴不准？**
A：YouTube 等平台有一种「滚动式」字幕，同一条字幕的结束时间被延伸到下一条，表现为字幕长时间叠挂（实测重叠率高达 84.9%）。新下载的字幕软件会自动修正；存量的旧文件可以用「字幕编辑」页手动对轴。

**Q：数据能换个盘放吗？**
A：可以，见第十节「想把数据放到别处」。

**Q：软件会往 C 盘写东西吗？**
A：不会。所有运行期文件都在数据根目录下（默认就是软件所在目录）。历史上字幕引擎曾写到 `C:\Users\…\VideoCaptioner`，现在启动时会自动迁回软件文件夹。
