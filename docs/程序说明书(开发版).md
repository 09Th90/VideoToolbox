## 〇、文档信息与版本纪律

### 0.1 版本号来源

唯一来源是 `src/video_toolbox_qt.py` 的 `VERSION = "2.6.0"`。
`scripts/dev/apply_version.py` 负责把版本号同步到 18 个固定位置，包括：

- `packaging/视频工具箱.spec`
- `packaging/视频工具箱.iss`
- `packaging/installer_src/` 的在线安装器配置
- `packaging/online_release/vt_update_core.py`、`vt_dl.py`
- `src/vt_update_check.py`
- `docs/使用说明.txt`、两份程序说明书、英文说明书
- `README.md` 的 `@version` 标记

改号后还会调用 `stamp_versions.py`：

- 为自研源文件重打首行 `# @version x.y.z`；
- 重新生成 `文件版本清单.md`（SHA-1 清单）。

`stamp_versions.py` 从 **git index（暂存区）** 读取 blob SHA，因此运行前要先
`git add`，并保证工作区与暂存区一致；否则清单会出现假阴性。

## 一、系统概览

### 1.1 产品定位

一个 Windows 桌面工具，把「下载 → 转写 → 翻译 → 校准 → 合成」串成可视流程，
同时提供 CLI 与 Python API 供批处理。核心差异点是**术语校准**：只改文字，
不改字幕结构，并把校准知识沉淀为可同步的规则库。

### 1.2 能力矩阵

| 域 | 能力 | 主要入口 |
| --- | --- | --- |
| 下载 | yt-dlp 主链 + NewPipe 兜底、字幕、Cookie、代理 | GUI 视频处理、`agent_cli download` |
| 转录 | 在线 ASR、本地 faster-whisper、说话人分离 | GUI 字幕处理、`agent_cli transcribe` |
| 翻译 | 微软/谷歌/DeepLx，双语排版 | GUI 字幕处理、`agent_cli translate` |
| 校准 | 17 种模式、术语表、上下文正则、AI 校准、知识同步 | GUI 校准段、`agent_cli calibrate`、校准脚本 |
| 编辑 | SRT/VTT/ASS/SSA，逐帧对轴，撤销/边界保护 | GUI 字幕编辑 |
| 合成 | 软字幕、硬字幕、MKV 封装 | GUI、`agent_cli compose` |
| 流水线 | 链接链、下载目录监控、断点续跑 | GUI 流水线、`src/pipeline.py` |
| 声纹 | 声纹筛选、按说话人拆分 | GUI 字幕/编辑、`speaker_voiceprint*` |
| 自动化 | B 站投稿 GUI 自动化、CLI UIA 自动化 | GUI 自动化、`bili_auto_submit.py` |
| 托管 | 内置 harness 适配层 | GUI AI 托管页、`harness_bridge.py` |
| 视频库 | 本地视频扫描、缩略图、播放 | GUI 视频库、`media_registry.py` |

### 1.3 技术栈

| 层 | 选型 |
| --- | --- |
| 界面 | PySide6 6.12 + PySide6-Fluent-Widgets 1.11.3 |
| 自研主题 | `src/vt_fluent` QSS/控件层 |
| 引擎 | 自研 `src/core` + `engine_*.py` 接缝；字幕引擎组件在 `tools/videocaptioner` |
| 下载 | yt-dlp + NewPipe Extractor |
| 媒体 | FFmpeg / ffprobe / libmpv |
| ASR | OpenAI 兼容接口 / faster-whisper |
| 打包 | PyInstaller onedir + Inno Setup |
| 更新 | 自研在线安装器 + GitHub Releases 平铺资产 |

### 1.4 运行时约束

- Windows 10/11 64 位；安装器 `ArchitecturesAllowed=x64compatible`。
- 安装版免管理员（`PrivilegesRequired=lowest`），默认 `D:\VideoToolbox`。
- 源码态需要 Python 3.12，且必须在仓库根运行（按 cwd 定位 `tools/`、`data/`）。
- 构建机需要 PyInstaller 6.22.3、onnxruntime，以及 ASCII junction 构建根。
- `tools/python` 是内嵌解释器，系统 Python 缺依赖，统一用它跑脚本。

### 1.5 演进与兼容包袱

- v2.1.0 从 PyQt5 迁到 PySide6；旧主题与控件仍有兼容分支。
- 字幕引擎源自第三方 videocaptioner，逐步通过 `engine_*` 接缝自研化；
  `src/vt_engine` 是并行完整包，尚未接入主程序。
- v2.6.0 起安装形态从 onefile 改为 onedir，去掉了每次启动的解包时间。
- 历史版本留下的双入口（GUI/CLI/脚本）需要保持行为一致，改动要有回归。

## 二、总体架构

### 2.1 分层

```
表现层   src/video_toolbox_qt.py、src/vt_fluent、src/vt_engine_ui、各页面模块
接口层   src/agent_cli.py、subtitle_calib_merged.py、src/bili_auto_submit.py
业务域   src/core/{download,asr,translate,calibrate,pipeline}、src/*.py 域模块
接缝层   src/engine_*.py、src/vt_engine（并行）
底座     src/core/shared（路径/日志/进程/配置）、tools/
```

依赖红线：

- `src/core` 不得 import Qt。
- 表现层不得直接 import videocaptioner；必须经 `vt_engine_ui/_seams.py`。
- `src/vt_engine` 不依赖 videocaptioner，但当前未接线。
- 第三方只读目录：`harness/`、`tools/` 的运行时本体。

### 2.2 目录映射

| 目录 | 职责 |
| --- | --- |
| `src/core/shared` | 路径解析、日志、子进程、配置、缓存 |
| `src/core/download` | yt-dlp、Cookie、NewPipe |
| `src/core/asr` | 在线/本地 ASR、协议适配 |
| `src/core/translate` | 微软/谷歌/DeepLx、双语排版 |
| `src/core/calibrate` | 校准规则、学习库、同步 |
| `src/core/pipeline` | 编排、状态机 |
| `src/vt_engine` | 自研完整引擎（26 模块 + 5 线程） |
| `src/vt_engine_ui` | 引擎 UI 适配层，12 文件 |
| `src/vt_fluent` | 自研 Fluent QSS/控件库，12 文件 |
| `src/calib_entity` | 对象级知识层与 CLI，只读 |
| `scripts/dev` | 开发、自检、构建、探针脚本 |
| `packaging` | spec、iss、在线安装/更新链 |
| `docs` | 说明书、许可、提示词与补丁 |

### 2.3 线程与进程

- 长任务走 QThread；翻译/校准另有线程池。
- 子进程统一收口到 `core/shared/proc.py`，便于超时/取消。
- 定时器：mpv 进度 40ms、下载目录轮询 5s。
- GUI 主线程不做阻塞 IO；耗时操作必须放进工作线程或子进程。

### 2.4 启动时序

1. `setswitchinterval(0.001)`；
2. `prepare_runtime_env()`；
3. crash guard；
4. QApplication；
5. StartupScheduler；
6. `applyAppStyleSheet()`（必须在建窗前）；
7. QLockFile 单实例；
8. 主题/字体；
9. MainWindow + `fit_to_screen()` + show；
10. 首帧后 `_defer()` 加载惰性页与同步线程；
11. `exec_()`。

### 2.5 惰性加载与降级开关

- 5 个 `_LazyPageShell`：页面先占位，首帧后替换真实控件。
- 自动化页约 6s、AI 托管页约 4s 后挂载，顺序不保证。
- 校准/声纹同步在首页就绪后 3.5s 启动，两条 daemon 线程。
- 常用降级环境变量：
  - `VT_NO_SYNC`、`VT_NO_CALIB_SYNC`、`VT_NO_VP_SYNC`
  - `VT_NO_PIPELINE`、`VT_NO_SCHED`、`VT_NO_SPLASH`
  - `VT_NO_UPDATE_CHECK`、`VT_CALIB_OPT`、`VT_ENGINE_UI`

## 四、业务域

### 4.1 下载域

- 入口：`src/core/download/*`、`src/video_toolbox.py` 的下载原语。
- 主链 yt-dlp，NewPipe 兜底（`tools/newpipe-cli`）。
- 清晰度只列 ≥720p，每个分辨率一档，优先 >30fps，再取最大文件。
- 默认下载目录 `data/downloads`；可配置。
- Cookie：自动/浏览器读取/cookies.txt/游客，支持 8 种浏览器。
- 代理由后台兜底，GUI 不暴露开关。
- 输出：视频、可选字幕（转 SRT）、元信息。

### 4.2 转录域

- 入口：`src/core/asr/*`、`engine_asr*`、`src/vt_engine_ui/transcription_interface.py`。
- 两种来源：自有 ASR 服务（Whisper 兼容）/ 本地 faster-whisper。
- 识别语言默认自动；可指定。
- 说话人分离：调用方在导出时选择合并或按说话人拆分。
- 语音分离只有占位，不内置模型。

### 4.3 翻译域

- 入口：`src/core/translate/*`、`engine_translate.py`。
- 服务：微软（默认）、谷歌、DeepLx；LLM 翻译已移除。
- 双语排布：译文在上/原文在上/仅译文/仅原文。
- 输出 SRT，保留时间轴；翻译失败时保留原文并可重试。

### 4.4 校准域

- 入口：`subtitle_calib_merged.py`、`src/core/calibrate/*`、`src/calib_ai_agent.py`。
- 机械校准：术语表 + 上下文正则 + 学习库；只改中文行。
- AI 校准：分块、上下文预算、思考强度、联网查证、音画证据、集群/协作。
- 结构契约：序号/时间轴/空行/CRLF-LF/BOM 不变；参考行默认不动，
  仅 `--fix-en` 允许修参考行。
- 学习库：`subtitle_learned_kb.json`，confirmed 规则自动注入；支持同步。
- 模式：17 种（默认 `bi` + 16 个旗标），详见 8.2。

### 4.5 字幕编辑与合成域

- 入口：`src/subtitle_editor*.py`、`src/subtitle_compose.py`。
- 读取 SRT/VTT/ASS/SSA；导出 SRT/ASS。
- 撤销 100 层；边界最小 40ms；重叠/过短提示。
- 合成三种：软字幕（内嵌）、硬字幕（烧录）、MKV 封装。
- ASS 烧录需要重编码；软封装不重编码。

### 4.6 流水线域

- 入口：`src/pipeline.py`。
- 链接链：下载→翻译→校准→二次校准→成品。
- 目录监控：盯下载目录的新视频；没有独立文件夹选择器。
- 自动开关默认开；并发 1–8，默认 3。
- 状态：`data/pipeline_state.json`，原子写；重启时 DONE 跳过、RUNNING 转 READY。
- 产物复用需要 `.src.json` 指纹一致。

### 4.7 声纹域

- 入口：`src/speaker_voiceprint*.py`、`src/voiceprint_sync.py`。
- 声纹筛选、按说话人拆分、同步。
- 模型与模板属于运行期数据；清理 `data/` 后需重新录入/下载。

### 4.8 自动化与投稿域

- 入口：GUI `src/auto_vision_page.py` + `src/bili_upload.py`；
  CLI `src/bili_auto_submit.py` + `agent_cli bili-submit`。
- GUI：13 张模板（10 必需 + 3 可选），后台线程，默认演练，失败整屏截图。
- CLI：UIA 定位 + PostMessage 输入，不移动真实光标；读素材目录的
  `投稿信息.txt`/`视频信息.txt`；支持 `--probe/--dry-run/--edit/--only/--visibility`。
- CLI 模块**不随安装包分发**，GUI 也不 import 它。

### 4.9 AI 托管域

- 入口：`src/harness_bridge.py`、`src/harness_page.py`。
- 页面条件挂载；工作区=程序根；运行期数据 `data/harness-home`。
- 引擎本体在 `harness/`（第三方，只读），约 2.2GB，不随安装包分发。
- 未就绪时任务/控制台禁用，显示部署引导。

### 4.10 视频库与媒体注册

- 入口：`src/media_registry.py`、GUI 视频库页。
- 启动后约 1.5s 扫描下载目录；递归，跳过隐藏与 `thumb_cache`。
- 缩略图取第 5 秒（短片取 0 秒），缓存 `data/thumb_cache`。
- 单击打开文件夹并调用系统播放器；右键只开文件夹。

## 五、表现层

### 5.1 导航与页面注册

- 静态注册 7 页：首页、视频处理、视频库、字幕处理、字幕编辑、流水线、设置。
- 惰性追加 2 页：自动化、AI 托管。
- `NAV_TEXTS` 有 8 个标签（不含 AI 托管）。
- AI 托管只有在适配层导入成功时出现；自动化在预热后出现。
- 页面构造失败时对应页缺席，其余页面不受影响。

### 5.2 首页与任务框

- 任务框先于重页面构造，避免启动卡顿。
- 任务创建通过 `task_creation_interface`，支持链接/文件/文本分派。
- 首页状态与日志入口是排障第一站。

### 5.3 页面信号契约

- 页面之间通过信号/回调解耦，不直接操作对方控件。
- 长任务统一走工作线程，结果回到主线程更新 UI。
- 校准/翻译/下载的取消与超时必须有明确状态，不能只改按钮文案。

### 5.4 `vt_fluent` 主题层

- 自研 QSS/控件层，逐步替换 qfluentwidgets 的外观。
- `applyAppStyleSheet()` 必须在 QApplication 之后、建窗之前。
- QSS 资源缺失会导致 UI 退化；`_selftest_qss_pack.py` 检查打包后的资源路径。

### 5.5 冻结态与源码态差异

- 冻结态 `sys.executable` 是 exe，不是 Python 解释器。
- 资源路径走 `_MEIPASS`/exe 目录；源码态走仓库路径。
- `data/`、`logs/`、`tools/` 的定位必须同时适配两种形态。
- 部分 lambda/子进程调用在冻结态会失效，需用命名函数或显式参数。

## 六、数据契约与运行时状态

### 6.1 字幕文本契约

- 标准 SRT：序号 / 时间轴 / 文本行 / 空行。
- 双语：首中文行 + 末参考行；中文行按字符集识别，不依赖先后顺序。
- 不变量：序号、时间轴、空行、CRLF/LF、BOM 一字不改。
- `--fix-en` 是唯一允许修改参考行的开关。
- `verify <src> <out>` 必须打印 `VERIFY OK`；`length` 检查行宽。

### 6.2 流水线状态

`data/pipeline_state.json`：

```json
{
  "version": 1,
  "saved": "...",
  "auto": true,
  "ai_calib": false,
  "workers": 3,
  "dismissed": [],
  "jobs": {
    "id": {
      "chain": "...",
      "files": {},
      "stages": [
        {"state": "DONE", "error": "", "reason": "", "out": "...", "ts": 0}
      ]
    }
  }
}
```

- 原子写，避免半截文件。
- 重启时 DONE 跳过、RUNNING 转 READY。
- 产物复用需要 `.src.json` 指纹一致。

### 6.3 校准学习库与同步

- `subtitle_learned_kb.json`：候选、confirmed、rejected。
- confirmed 规则在对应模式自动注入；rejected 永不自动应用。
- 同步基线：`data/calib_sync_base.py`、`data/calib_sync_kb_base.json`。
- 同步只传规则文本，不传视频/字幕。
- 学习库被 `.gitignore` 忽略但仍在 git 跟踪中，**不要 `git rm --cached`**，
  否则校准同步提交会缺文件。

### 6.4 缓存

| 路径 | 内容 | 可删除 |
| --- | --- | --- |
| `data/cache/asr_results` | ASR 结果 | 是 |
| `data/videocaptioner/cache` | 翻译/ASR 缓存 | 是 |
| `data/waveforms` | 波形峰值 | 是 |
| `data/thumb_cache` | 视频库缩略图 | 是 |
| `data/tmp` | 临时文件 | 是 |

### 6.5 界面状态

- `data/config.json`：界面与运行偏好（9 键）。
- `data/ui_custom.json`：美化配置（8 键）。
- `data/subtitle_style.json`：字幕样式。

常用：

```bash

tools\python\python.exe subtitle_calib_merged.py src.srt --out out.srt --endobi
# 结构校验
tools\python\python.exe subtitle_calib_merged.py verify src.srt out.srt
```

### 9.7 构建侧已知坑

- 中文路径 → PyInstaller Qt 钩子读成 `?????`，必须用 ASCII junction。
- `PYTHONPATH` 上的 sitecustomize 会被收进 PYZ；必须 `env -u PYTHONPATH`
  并在 spec `excludes` 中剔除 `sitecustomize/usercustomize`。
- `excludes` 优先级高于 `hiddenimports`；漏摘 excludes 会导致模块缺失。
- 顶层自研模块必须同时进 spec hiddenimports 与 iss 的 Source 白名单。
- QSS `datas` 目标目录写错会导致运行时 UI 退化。
- gh-pages 单文件 100MiB 上限；改用 GitHub Releases 平铺资产。
- 冻结态 `sys.executable` 不是解释器；零参 lambda 可能崩。
- Inno 静默安装可能按注册表 `PreviousAppDir` 选目录。
- 递归删除在本机可能触发安全删除钩子；批量清理用 rename 或 Win32 API。
