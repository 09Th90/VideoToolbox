## 四、对象级消歧机制（M3 核心）

**最小触发门**：仅当本 cue ref 存在**多目标** ref mention 才启用对象 scoping；单目标 ref 走与现状完全相同的代码路径（结构化零漂移）。

**三级 tie-break（全部 fail-closed，失败保守回退 R|=T，只可能少改不可能改错）**：
1. 规则1：zh 序次交集恰 1 → 裁决（resolved_tb1）。
2. 规则1.5：`_category_tiebreak` category 首段证据恰一命中 → 裁决（resolved_tb3）；缺 category/同类目不可区分 → 放弃。
3. 规则2：`_parent_tiebreak` parent 链（ENTITIES.parent 实锤数据，单父防环）→ 裁决（resolved_tb2）。
4. 全失败 → R|=T 挂起不盲改（tb_fail）。

**EXCLUDE**：整行倒回 → mention 级预跳过（`exclude_scan` 判 ref 正则 ∩ wrong in zh）。

**关键探测结论**：multi_target 31 条 90% 是 lint 错层结构性误报（wrong 是 ctx 专属错形不在 mention zh_map/ref_map）；真消歧仅 1 parent（心.parent=心月狐）+ 1 aliases（清宵司骑）。子串陷阱（梦枢天罗⊃梦枢不同对象、岁主 vs 心月狐走 category）已规避。
