# 视频工具箱 v2.6.0

> 本版把安装形态切到 onedir，新增 B 站后台投稿 CLI，改进更新器与校准脚本，
> 并全量重写四份说明书。

## 新增

- **B 站后台投稿 CLI**：新增 `src\bili_auto_submit.py` 与
  `agent_cli bili-submit`。使用 Windows UI Automation 定位控件、
  PostMessage 输入，不移动真实光标、不切换前台；支持 `--probe` 预检、
  `--dry-run` 演练、`--edit` 编辑、`--only` 指定步骤、`--visibility` 设置
  可见性。该模块仅源码方式可用，GUI 与安装包不直接使用。
- **启动画面与更快的首屏**：任务框先于重页面创建，自动化/AI 托管页首帧后
  惰性挂载；启动过程增加进程耗时日志，便于定位慢启动。
- **任务栏自动隐藏让位**：Fluent 窗口在最大化/全屏场景下自动隐藏任务栏，
  避免遮挡字幕编辑底部控件。
- **在线发布链升级**：app 包改为 `exe + _internal` 结构，增加版本信任记录，
  为 onedir 安装形态的增量更新打基础。

## 改进

- **安装形态 onefile → onedir**：安装目录新增 `_internal\`，启动不再每次
  解包，冷启动明显更快。升级安装会清理旧 `_internal`。
- **更新器**：
  - 区分源码模式与安装版；
  - 同版本提供「修复安装」；
  - 版本显示与设置页/关于页统一；
  - 校正陈旧的安装记录，避免「当前版本」显示落后。
- **校准脚本**：
  - 按字符集识别中文行/参考行，英文在上时也能正确校准；
  - `--endo` 只改中文行，不再误改英文参考行；
  - `subfix` 拒绝空 new 与纯标记覆盖，支持 `--strict`；
  - 覆盖源文件时自动生成 `.bak`；
  - 沉淀 wuwa_explore_tales 侧车中的 6 条通用上下文规则
    （Midna、remaster、Sentin els、Sentinel→岁主、Res on ator→共鸣者）。
- **AI 校准**：文本行拆分与参考行还原更稳，减少多行 cue 的错位。
- **文档**：用户版、开发版、使用说明、英文版全部从零重写，并校正
  页面数量、校准模式/子命令数量、onedir 安装形态等事实。

## 修复

- 修复源码模式下版本显示与安装版不一致的问题。
- 修复更新完成后重启时「当前版本」仍显示旧值的问题。
- 修复英文参考行在上时校准可能改错行的问题。
- 修复 `subfix` 空覆盖导致的行内容丢失风险。
- 修复部分启动路径重复创建页面的问题。

- `check_syntax`、`check_names`、`check_secrets`、`check_doc_drift` 通过。
- `_smoke_all` 冒烟通过；`_selftest_gui` 在桌面会话下通过。
- 校准 AI 自检、QSS 打包自检、在线安装/更新自检通过。
- 离线安装、启动、卸载实测通过；卸载保留 `data\`。
- 合成用例验证：校准只改中文行，序号/时间轴/参考行/CRLF/BOM 零改动。

## 已知限制

- 无代码签名；少数启用 Device Guard/应用控制策略的电脑会拦截 exe。
- 离线包约 1.0GB，国内直连 GitHub 可能较慢。
- AI 托管引擎（约 2.2GB）不随安装包分发。
- 语音分离只有入口，不内置模型。
- CI 只跑语法、文档一致性、密钥扫描；GUI 自检需本地桌面会话。

## 安装

1. 双击安装包，向导为简体中文。
2. 默认装到 `D:\VideoToolbox`，可以改；不需要管理员权限。
3. 装完从开始菜单或桌面快捷方式启动。

> 发布资产使用 ASCII 文件名，避免 GitHub 截断中文附件名；安装后程序名仍为
> 「视频工具箱」。
