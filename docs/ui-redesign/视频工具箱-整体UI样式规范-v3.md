# 视频工具箱 · 整体 UI 样式规范（v3 后端对齐稿）

- 适用版本：v3.3.1 · PySide6 + qfluentwidgets
- 画板：1440 × 900；预览按 2× 输出（2880 × 1800）
- 配套文件：`视频工具箱-整体UI重设计.html`、`preview-v3/*.png`
- 对齐对象：`src/vt_app/`、`src/features/*/`、`src/vt_engine_ui/`、`src/ui_theme.py`
- 数据说明：页面中的视频名、任务、路径、模型名、进度均为演示数据；字段、列名、选项、数值范围按真实实现。

---

## 1. 这版和 v2 的区别

v2 是目标态概念稿，v3 按后端实现重画。核心变化：

1. 导航补齐 9 项：首页 / 视频处理 / 视频库 / 字幕处理 / 字幕编辑 / 流水线 / AI 托管 / 自动化 / 设置。
2. 视频处理补 `音画合并`、`视频切片` 两个子页；字幕处理补 `字幕翻译`、`字幕校准` 两个子页。
3. 首页只保留 `TaskCreationInterface`：单输入框 + 状态 / 进度 / 日志，不画仪表盘和虚构队列。
4. 下载画质改为“检测后动态列表”，不再预设固定档位。
5. 视频库只保留文件名、大小、时长；删除状态、日期、字幕数、语言、存储占用。
6. 语音转录改为单文件工作台；翻译、校准各自独立页。
7. 流水线改为 7 阶段链，链接任务 6 段、目录任务 5 段。
8. 设置改为“6 个入口块 → 二级页”，不使用左侧分类栏；删除“全部已保存”等不存在的聚合状态。
9. 主色改为后端预设 `#2F8D63`（旧品牌绿）；8 个预设均来自 `ui_theme.py`，默认值为 `#45C877`。

## 2. 画板与壳层

| 项目 | 数值 |
|---|---|
| 画板 | 1440 × 900 |
| 左侧导航 | 200 宽，固定 |
| 顶栏 | 46 高：面包屑 / 搜索 / 通知 / 设置 |
| 状态栏 | 26 高：引擎 / ASR / 配置 / 页内状态 / 版本 |
| 内容区 | 上 16、左右 22、下 14 |
| 页头 | 标题 20px；说明 11px；右侧状态与操作 |
| 卡片间距 | 10～12 |
| 卡片圆角 | 10 |
| 控件圆角 | 6；按钮 7 |
| 控件高度 | 输入 30 / 小按钮 26 / 主按钮 30～34 / 命令栏 46 |

三种骨架：

- **列表页**（视频库、并行任务）：页头 → 路径/命令栏 → 表格或网格 → 日志/页脚。
- **工作台页**（下载、转录、翻译、校准、编辑、流水线、AI 托管、自动化）：页头 → 子页标签/命令栏 → 主区 + 右栏 → 底部日志或媒体条。
- **设置页**（入口/二级）：页头 → 状态行 → 3×2 模块网格；二级页为“主表单 + 右侧状态卡”。

主题色预设（`ui_theme.py`，首项为默认）：

`#45C877 / #2F8D63 / #3B82F6 / #06B6D4 / #8B5CF6 / #EC4899 / #F59E0B / #EF4444`

字幕编辑工作区使用 `--card:#202328`、`--line:#31353B`、`--accent:#4BC08A`。壳层（导航、顶栏、状态栏）保持浅色，不做整程序双主题反转。

## 4. 字体与状态

- 字体：`Microsoft YaHei UI` → `Microsoft YaHei` → `PingFang SC` → `Segoe UI`。
- 字号：页标题 20 / 卡标题 13 / 正文 13 / 表格 11.5 / 辅助 10.5 / 微型 9～9.5。
- 字重：标题 600；按钮与关键数字 500；正文 400。
- 状态不只靠颜色：必须“圆点 + 文字 + 底色”三层。
- 状态词固定：`就绪 / 空闲 / 下载中 / 转录中 / 校准中 / 已完成 / 等待中 / 失败 / 未启动 / 未配置`。
- 失败使用 `danger`，等待使用 `warn`，完成/就绪使用 `ok`；不使用紫色表达状态。

## 5. 组件规则

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | 实底 `accent`、白字、高 30～34 | 每页最多 1 个主动作：开始处理 / 加入下载 / 开始转录 / 开始投稿 |
| 次按钮 | 白底、1px `line` | 暂停 / 取消 / 刷新 / 浏览 |
| 危险按钮 | 透明底、`danger` 文字 | 删除 / 清空 |
| 图标按钮 | 26～30 方框、无文字 | 媒体条、文件夹、设置 |

### 表格

- 表头 9.5px、`faint`、无底色；行高 44～54。
- 选中行 `accent-soft` + 左侧 2px `accent` 竖线。
- 数值右对齐；路径、链接允许省略号，悬停显示完整值。
- 列宽按真实表设置，不平均分配；下载页 8 列：任务 / 链接 / 画质 / 进度 / 速度 / 剩余 / 状态 / 保存位置。

### 表单

- 标签列 96～104；输入起点统一。
- 输入高 30，底色 `input`，聚焦描边 `accent` + 3px 柔光。
- 开关为 36×20 胶囊；开启用 `accent`，关闭用 `#D6DCE1`。
- 设置二级页字段 ≥5 行时自动双列；宽字段（接口、密钥、路径、提示词）跨两列。
- 长说明不铺在字段下，移到右侧“说明”卡。

### 日志

- 等宽 10.5px；时间 `faint`；标签 `accent-ink`；正文 `dim`。
- 高度按页面给足，允许大量留白；空态只显示 3～5 行提示。
- 日志卡右上角固定“清空 / 导出”。

## 6. 页面清单与关键结构

| 页面 | 关键结构 | 后端约束 |
|---|---|---|
| 首页 | 单输入 + 文件夹/播放按钮 + 示例 + 当前任务 + 日志 | `TaskCreationInterface`；不画队列/统计 |
| 视频处理·下载 | 链接 + 检测画质 + 动态画质列表 + 8 列任务表 + 日志 | 仅 ≥720p；同分辨率优先 fps>30，再取最大文件；并发 1–6 |
| 音画合并 | 自动配对表 / 手动合并双轨页（标签切换）+ 规则 + 进度 | 同名视频/音频配对；ASS 格式可选；输出不改源 |
| 视频切片 | 源文件 + 规则 + 9 段预览 + 输出执行 | 自动分段 / 指定点 / 指定时长；逐段校验可播放 |
| 视频库 | 文件夹路径 + 4 个动作 + 文件夹网格 + 计数 | 卡片只有文件名、大小、时长；左键打开并开文件夹 |
| 字幕处理·转录 | 单文件卡 + 命令栏 + 输出空态 + 状态/日志 | 单文件；模型、语言、输出格式、声纹筛选 |
| 字幕翻译 | 命令栏 + 4 列表格 | 表头随“翻译字幕/优化字幕”切换 |
| 字幕校准 | 输入/输出 + 12 组片源模式 + 选项 + 检查 + 日志 | 只改文字；序号/时间轴/空行/换行/BOM 不动 |
| 字幕编辑 | 视频 + 右属性 + 波形 + 收起字幕列表 + 20 图标媒体条 | CueTable 默认隐藏；顶部无文字工具条 |
| 流水线 | 链接输入 + 7 阶段任务链 + 事件日志 | 链接 6 段、目录 5 段；并发默认 3、范围 1–8 |
| AI 托管 | 状态 + 任务 + 输出 + 部署引导 | 控制台未启动时显示引导；模型/密钥取设置 |
| 自动化 | 目标窗口/模板采集 + B 站投稿 + 演练/真跑 | 先抓模板再填任务；默认演练 |
| 设置入口 | 6 块 3×2 + 配置快照 | 3 保存 / 2 即时 / 1 只读；无“全部已保存” |
| 设置二级 | 主表单 + 右侧状态/说明/入口 | 字段与真实控件一一对应 |

| 入口块 | 合并的真实设置卡 | 保存方式 |

| 全局 AI | AI | 保存并应用 + dirty |

## 8. 后端对齐硬规则

1. 下载画质不预设档位；“检测画质”后才出现列表，默认选最高档。
2. 下载表固定 8 列，不合并“速度/剩余”，不隐藏“保存位置”。
3. 视频库不显示转写/校准状态、日期、语言、分辨率、存储占用。
4. 语音转录是单文件，不做批量队列、四阶段进度条。
5. 字幕校准不改变时间轴与文件格式，只替换文字。
6. 字幕编辑底部是图标媒体条（约 20 个）+ 倍速；字幕列表默认收起。
7. 流水线是 7 阶段链，不是 4 段固定进度条；并发默认 3。
8. 设置页无左侧分类栏，无全局“上次保存”时间戳。
9. 字幕引擎设置没有“输出格式”；输出格式在字幕翻译页保存时选择。
10. 配置路径使用真实文件：`data/config.json`、`data/ai_config.json`、`data/ui_custom.json`、`data/credentials.json`、`data/VideoCaptioner/settings.json`。

## 10. 样例稿交互层

样例稿不是静态截图，以下操作已可实际点击并看到界面变化：

| 控件 | 实际行为 |
|---|---|
| 左侧导航 / 页内 `data-goto` | 切换 14 个 screen，更新面包屑与父级高亮 |
| 音画合并“自动配对 / 手动合并” | 切换两套面板，不改变页面其他区域 |
| 主题色 8 个圆点 | 即时改写 `--accent / --accent-ink / --accent-soft / --accent-line`；按钮、链接、开关、选中环、活动记录同步换色 |
| 主题下拉（浅色 / 深色 / 跟随系统） | 浅色/深色即时切换 `.app.dark-demo`；跟随系统读 `prefers-color-scheme` |
| 云母特效开关 | 切换 `.app.mica-demo` 渐变与顶栏模糊 |
| 设置数字项 | 真实 `<input type="number">`，可输入、可上下调，失焦不重置 |
| 背景 / 卡片不透明度 | 改为真实 `input[type=range]` 拉条，0–100%；0 = 全透明/不压暗，100 = 完全压暗/不透明，拖动即时更新百分比、轨道填充和页面/卡片 |
| 设置开关 | 文档级事件委托，动态渲染的开关也可切换 |
| 背景“更改” | 打开本地图片选择，按行铺到全局或对应页面；遮罩滑杆实时叠加 |
| 恢复默认外观 | 清背景、回浅色、回样例主色 `#2F8D63`、关闭云母 |
| 保存并应用 | 弹出“已保存并应用 · 样例演示”提示 |

边界：这是纯前端样例，不读取也不写入 `data/ui_custom.json`；刷新后恢复默认演示状态。界面缩放、检查更新仍为视觉占位。真实程序接入时，主题色/主题/云母应写 `data/ui_custom.json` 并由 `ui_theme.py` 应用。
