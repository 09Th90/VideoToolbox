# 视频工具箱 · 前后端对应全量审查报告

- 审查日期：2026-11-25
- 审查对象：`docs/ui-redesign/视频工具箱-整体UI重设计.html`、6 套设置二级页、9 张预览图
- 对照对象：`src/vt_app/`、`src/features/*/`、`src/vt_engine_ui/`、`src/ui_theme.py` 等现有 PySide6 源码
- 审查性质：只读比对，**未修改 HTML、样式规范与 `src/` 源码**

## 一、总体结论

当前设计稿是一套完成度较高的**目标态概念设计**，但不是现有程序的**状态映射稿**。视觉语言、信息密度、下载页动态画质和设置页“块 → 二级页”方向可以保留；页面清单、首页/视频库/字幕处理/流水线的主体结构、设置字段和一批数值路径必须返工。

已确认的页面覆盖关系：

- 实际功能页共 **13 个**：9 个主导航页（首页、视频处理、视频库、字幕处理、字幕编辑、流水线、AI 托管、自动化、设置）+ 视频处理下的音画合并/视频切片 2 个子页 + 字幕处理下的字幕翻译/字幕校准 2 个子页。
- 设计稿覆盖 **7 个主页面**，缺 **AI 托管、自动化 2 个整页**，也缺 **音画合并、视频切片、字幕翻译、字幕校准 4 个子页**。
- 实际设置页是 **11 张设置卡**；设计稿归并为 6 个逻辑块。卡级映射可以闭合为 `1+1+3+2+2+2=11`，但字段级尚未闭合。

结论分级：

- **P0（阻断验收）12 项**：整页/子页缺失、主体数据模型不成立、关键数值错误、设置保存语义矛盾。
- **P1（重要差异）18 项**：控件缺失、字段缺失、操作入口错位、路径与选项不完整。
- **P2（文案/视觉）8 项**：命名缩写、演示数据未标注、状态措辞不精确。

## 三、P0 阻断项

### P0-1 导航缺两个实际页面

- 实际可见导航 9 项：`首页 / 视频处理 / 视频库 / 字幕处理 / 字幕编辑 / 流水线 / AI 托管 / 自动化 / 设置`。
- 依据：`src/vt_app/main_window.py:234-248`；`src/features/harness/feature.py:16`（`nav="AI 托管"`，底部）；`src/features/automation/feature.py:17`（`nav="自动化"`，底部）。
- 设计稿只有 7 项，完全缺 `AI 托管`、`自动化`。这不是“少画两个按钮”，而是两套独立功能页没有设计。

### P0-2 四个功能子页没有画面

- `视频处理` 页实际由 `下载 / 音画合并 / 视频切片` 三段组成；设计只画了下载，另外两个标签没有内容。
- `字幕处理` 页实际由 `语音转录 / 字幕翻译 / 字幕校准` 三段组成；设计只画了语音转录的队列，翻译与校准没有内容。
- 依据：`src/features/download/feature.py:21`、`src/features/workbench/page.py:392-475`、`src/features/merge/page.py`、`src/features/split/page.py`。
- 设计稿的“全量 UI”目前只覆盖约一半功能面。

### P0-3 首页仪表盘没有后端数据源

- 实际首页只是任务创建入口：`src/vt_app/home_page.py:20-62` 承载 `TaskCreationInterface`；`src/vt_engine_ui/task_creation_interface.py:259-368` 是单输入框 + 文件夹/播放按钮 + 状态/进度/日志/捐助/版本。
- 设计稿的“正在处理、队列 2/3、运行环境、本周处理 42、成功率 96%、最近完成、4 个快捷入口”均无后端接口或数据表。
- 这些可以作为目标态，但必须标注“需新增聚合接口”，不能放在“当前状态”页面里。

### P0-4 视频库卡片元数据与操作不成立

- 实际卡片只有缩略图、文件名、`大小 · 时长`（`src/features/library/page.py:287-312`）；左键打开文件 + 打开所在文件夹，右键打开所在文件夹（`:318-321`）。
- 设计稿的“已下载/已转录/已校准、日期、字幕条数、语言、分辨率”没有数据模型；`排序、导入视频、自动扫描开关、存储占用、清理缓存` 也没有实现。
- 实际“自动扫描”是首次打开自动加载，不是用户开关。

### P0-5 语音转录被画成批量队列，实际是单文件工作台

- 实际转录页是单文件卡 + 命令栏：`src/vt_engine_ui/transcription_interface.py:152-175`，命令栏 `:439-535`。
- 设计稿的 5 文件队列、批量进度、四阶段（提取音频/语音识别/智能断句/输出 SRT）在源码中不存在。
- 设计稿的“断句方式、热词表、输出目录、时间轴偏移、自动标点、保留语气词、自动校准、预计输出、最近输出”也没有对应控件。
- 实际存在但设计缺失的关键控件：转录模型（本地/云端）、识别语言、输出格式、声纹筛选、打开文件夹、开始转录。

### P0-6 字幕编辑的布局与工具条不是当前实现

- 实际布局：视频 + 右侧 `SubtitlePropsPanel`（约 1:4），下方波形时间轴，CueTable 默认隐藏在抽屉；`src/features/subtitle_edit/page.py:280-357`。
- 实际底部是 20 个图标 + 倍速下拉，覆盖打开视频/字幕、保存/另存/关闭、上一帧/播放/下一帧、切分/合并/删除/插入、取起点/终点/前后移、撤销/重做、内嵌字幕、展开列表；`:424-530`。
- 设计稿（v2）顶部是文字工具条，CueTable 常显，缺底部媒体条，也没有画面字幕浮层的直接编辑入口。
- “字幕编辑始终深色，不受主题影响”不成立；媒体条与属性面板是主题感知的（`:532-550`、`subtitle_editor.py:1394-1408`）。

### P0-7 流水线阶段、并发与入口全部错位

- 实际阶段标签 7 个：`下载完成 / 智能合并 / 语音转录 / 字幕翻译 / 字幕校准 / 二次校准 / 成品输出`（`src/features/pipeline/pipeline.py:70-98`）。
- 任务链不是统一的：链接任务 6 段（跳过智能合并），目录监听任务 5 段（跳过语音转录）。设计稿固定“下载 / 转录 / 校准 / 归档”四段无法表达实际链。
- 实际并发默认 3，范围 1–8（`DEFAULT_WORKERS=3`、`MIN_WORKERS=1`、`MAX_WORKERS=8`）；设计写 2，是把下载页的并发误用到了流水线。
- 实际新建任务是卡内“链接输入 + 添加任务”（`src/features/pipeline/page.py:182-217`）；设计改成页头“新建任务”按钮，却没有链接输入。
- 实际配置只有“自动流水线开关 + 并发任务数 + 扫描/重试/打开下载目录/清空任务进度”；设计稿的“自动转录、自动校准、归档+通知、失败自动重试 2 次”均无对应 UI 或行为。

### P0-8 设置页“全部已保存 / 即时保存”与真实保存模型矛盾

- 实际是混合保存模型：AI、ASR、AI 校准需要“保存并应用”，并各自维护 dirty 状态；下载目录/外观等即时生效；数据根目录要“应用/还原默认”。
- 依据：`src/vt_app/settings_page.py:331-343`（11 张卡）、`:669-769`（AI）、`:774-932`（ASR）、`:1401-1605`（校准）。
- 设计稿却写“全部已保存 / 上次保存 2 分钟前 / 所有更改即时保存 · 没有整页应用”，并给下载、外观也加“保存并应用”。这是对保存语义的双向错误。
- 实际没有全局“上次保存”时间戳，也没有“4 项就绪 / 2 项需确认”的聚合状态。

### P0-9 全局 AI 缺少关键控件

- 实际卡内有：启用、密钥、接口地址、文本模型、视觉模型、测试接口、**自动匹配**、**保存并应用**、**未保存标记**、**决策模型启用（Jev 总闸）**、**决策模式（shadow/assist/auto）**、决策密钥、决策端点（默认/北京/新加坡）、**测试决策模型**、**第二声纹影子开关**。
- 依据：`src/vt_app/settings_page.py:669-769`、`:1086-1176`；决策模式定义见 `:55-58`。
- 设计稿缺少自动匹配、dirty、决策模式、测试决策、第二声纹；把“Jev 影子决策”和“决策启用”混成一层，容易让用户以为只有一个总闸。
- “已连接 128ms / 上次保存 2 分钟前”没有持久状态源；测试延迟是一次性结果。

### P0-10 字幕引擎与 AI 校准字段大面积缺失

- 引擎区实际可见两组：
  - 字幕翻译：翻译服务、是否翻译、目标语言、线程数、DeepLX 端点。
  - 字幕合成：字幕样式、字幕布局、输出视频、软字幕、视频质量。
  - 依据：`src/vt_engine_ui/setting_interface.py:58-166`、`:279-313`；宿主的隐藏/搬运逻辑见 `src/vt_app/settings_page.py:1984-2050`。
- 设计稿只保留“引擎版本 / 工作目录 / 翻译引擎 / 输出格式”，其中 **“输出格式”不存在**；“翻译引擎”实际叫“翻译服务”；字幕样式/布局/输出视频/软字幕/视频质量全部缺失。
- AI 校准实际还有：**输入上下文预算 + 128K/256K/512K/1M 预设**、**思考开关**、**思考轮次上限**、**音画证据开关**、**Agent 集群开关 + 成员 + 协作轮数**；输出上限默认 **65,536**，预设 256K/512K/1M。设计只画了“输出上限 256K”，默认值也错。
- 依据：`src/vt_app/settings_page.py:1401-1605`，预算默认见 `:1422-1426`，预设见 `:1456-1461`。

### P0-11 下载/Cookie/外观存在硬性数值与路径错误

- 主题色实际预设为 `#45C877, #2F8D63, #3B82F6, ...`（`src/ui_theme.py:100-101`）；设计用 `#0E8C96, #178A5B` 替代前两项，后六项相同，属于“设计新色”而非现状。

## 四、P1 重要差异

1. **下载任务表少两列**：实际 8 列 `任务/链接/画质/进度/速度/剩余/状态/保存位置`，列宽 `(56,220,66,66,78,70,70,240)`（`download/page.py:210-215`）；设计 7 列，把链接压到副标题、保存位置压到页脚，不符合表格可选中/可核对的要求。
2. **下载操作语义错**：实际是选中行后“暂停/继续”与“取消选中任务”，并带 1–6 并发 SpinBox（`:220-232`）；设计改成行内暂停/取消 + “暂停全部/清除已完成”，没有选中态语义。
3. **下载页多出页面级“打开下载目录”**：下载页实际没有该按钮；该动作在流水线页 `pipeline/page.py:404`。设计在首页和下载页都放了它。
4. **下载“下载设置”摘要卡不存在**：实际没有“画质优先 / 并发 / 保存位置 / 归档”四格摘要；也没有页脚“修改”入口。
5. **下载源码文案仍写“优先 60fps”**：`download/page.py:185` 与 `ytdlp_util.py:452` 的 docstring 仍是 60fps，但 `parse_qualities()` 实际是 `fps > 30`（`:464-466`）。设计改成 `>30fps` 是对的，**源码 UI/注释也需要同步**。
6. **视频库文件夹栏缺操作**：实际有“浏览/同步下载目录/刷新/打开文件夹/扫描计数”（`library/page.py:72-112`）；设计只有“更改文件夹 + 自动扫描开关 + 扫描状态”，缺“同步下载目录/刷新”。
7. **视频库卡片交互丢失**：实际左键打开文件并打开文件夹、右键打开文件夹；设计只画播放徽标，没有说明点击行为。
8. **字幕处理页级动作不存在**：实际没有页面级“添加文件/打开输出目录”；文件卡内才有“打开文件夹 / 开始转录”。设计把这两个动作抬到页头，属于新增。
9. **字幕编辑导出不完整**：实际保存/另存/关闭分离，属性面板可导出 SRT/ASS；设计只有顶部“导出 SRT”，缺另存为、关闭、ASS。
10. **字幕编辑属性面板字段不足**：实际含轨道样式、字体、字重、B/I/U/S、字号、9 宫格对齐、边距、缩放、描边、填充、描边色、背景开关/色、阴影开关/色/距离、导出、上一条/下一条（`subtitle_editor.py:1050-1358`）；设计检查器只覆盖部分。
11. **流水线“重试/清空”文案不符**：实际是“重试失败项 / 清空任务进度”；设计写“重试失败 / 清空已完成”。实际没有“清空已完成”语义。
12. **流水线日志导出不存在**：实际日志是 `LogView("流水线日志")`；设计右上“导出”没有对应动作。
13. **ASR 协议选项严重不全**：实际 12 种协议（自动、OpenAI Whisper 兼容、Azure OpenAI、Chat 音频转写、Deepgram、ElevenLabs Scribe、Google Gemini、火山引擎、AssemblyAI、百炼实时、百炼原生、百炼 Filetrans）；设计只列 3 种（`settings_page.py:655-667`）。
14. **ASR“识别语言”不是设置字段**：实际已迁到语音转录页顶部，设置页只留去向提示（`settings_page.py:789-791`）；设计把它做成一行字段，容易被误解为可在此配置。

## 五、P2 文案与视觉差异

1. 画质首行实际是“`1440p 60fps ~2.8 GB`（最高，推荐）”，设计缩写为“最高·推荐”，可接受但要在规范里注明是视觉缩写。
2. 实际按钮文案“同时下载字幕（博主上传 + 自动生成，自动转 SRT）”，设计简写“同时字幕”，语义够用但不够精确。
3. 设计把流水线末段叫“归档”，实际阶段名是“成品输出”。
4. 设计页脚“并发 1/2”把下载页并发与流水线并发混在一起；实际两处是独立配置。
5. 设置入口的“6 个模块 · 4 项就绪 · 2 项需确认”没有聚合源，建议删除或标注“示意”。
6. “字幕编辑始终深色”应改为“当前预览为深色；实际随主题切换”。
7. 设计顶栏“设置二级页”是样例导航/调试入口，不应作为产品导航项出现。
8. 设置快照“上次保存 2 分钟前”应删除；实际只有每张卡的 dirty 状态，没有全局保存时间。

## 六、设置页 6 块 → 11 张卡映射

| 设计块 | 对应后端卡 | 卡级覆盖 | 字段级结论 |
|---|---|---|---|
| 全局 AI | `_build_ai_card` | 1/1 | 缺自动匹配、dirty、决策模式、测试决策、第二声纹 |
| 语音识别 ASR | `_build_asr_card` | 1/1 | 协议 3/12、识别语言应为提示、缺 dirty/套餐提示 |
| 字幕引擎与校准 | `_build_engine_section` + `_build_calib_ai_card` + `_build_sync_card` | 3/3 | 引擎翻译/合成字段缺一半；校准预算/思考/媒体/集群缺一半；知识计数虚构 |
| 下载与存储 | `_build_dirs_card` + `_build_cookie_card` | 2/2 | 缺 Cookie 文件、数据根目录应用/还原；工作目录路径错；磁盘占用无源 |

## 七、建议处理顺序

1. **先定范围**：AI 托管、自动化、音画合并、视频切片、字幕翻译、字幕校准 6 个页面是补设计，还是明确排除在本次重设计之外。不能继续用“全量 UI”表述却不覆盖。
2. **再定首页/视频库/流水线的产品形态**：保留仪表盘就必须新增聚合接口；否则回归真实的任务创建/文件夹网格/流水线卡。
3. **设置页按 6 块做字段补全**：优先 AI、字幕引擎与校准、下载 Cookie，这三块缺口最大；同时把“即时保存/显式保存”改成每块真实语义。
4. **统一数值与路径**：并发 3（流水线）/2（下载）；主题色映射 `ui_theme.ACCENT_PRESETS`；遮罩 55/0；工作目录 `data/VideoCaptioner/work-dir`；配置文件组 `config.json + ai_config.json + ui_custom.json + credentials.json`。
5. **最后清演示数据**：所有统计、模型名、时间戳、知识条数要么接真实数据，要么统一加“示意数据”标记。
