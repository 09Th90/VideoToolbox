## 0. 本轮两处返工

### 0.1 下载页画质改为后端动态列表

原稿的 `1080P60 / 1080P / 720P / 仅音频` 是固定胶囊，不符合后端 `src/core/download/ytdlp_util.py → parse_qualities()`：

| 原稿写法 | 后端实际 | 处理 |
|---|---|---|
| 固定四档，检测前就展示 | 点击“检测画质”后才返回列表 | 改为“检测后动态画质列表”，面板标题说明“不预设档位” |
| 同时有 1080P60 与 1080P | 按 height 分组，同分辨率只留一档 | 删除重复档；样例只保留 `1080p 60fps` |
| 只有 1080 / 720 | 可能出现 2160p / 1440p / 1080p / 720p 中的 2～4 档 | 样例改为 `1440p 60fps / 1080p 60fps / 720p 30fps` |
| 有“仅音频”入口 | `src/features/download` 无音频-only 实现 | 删除“仅音频”入口与任务行 |
| 文案“优先 60fps” | 代码是 `fps > 30`，不是严格 60fps | 改为“优先 >30fps，再取最大文件” |
| 固定默认档 | `on_detect_done` 默认选中第 0 行（最高档） | 新面板默认选中第一行，并标“最高” |

### 0.2 设置页改为“模块块 → 二级页”

- 删除 168px 左侧分类栏和右侧长滚动表单。
- 入口页改为 3 列 × 2 行共 6 个模块块。
- 点击整块进入 `settings-detail`，用独立二级页显示字段、状态与说明。
- 二级页按 Esc 返回设置；左上角“← 设置”也可返回。

## 1. 设计原则

1. **固定壳层**：左侧 200px 导航、46px 顶栏、26px 状态栏固定，页面只负责内容。
2. **紧凑但不拥挤**：正文 13px；卡片内说明 10.5px；表格辅助信息 9～10px；控件 30px；卡片间距 12px。
3. **一页一个主动作**：主按钮只出现在页头或当前任务卡；其余为次级/幽灵按钮。
4. **状态不只靠颜色**：状态胶囊用“点 + 文字 + 底色”三层表达；失败、等待、完成都有文字。
5. **深色是局部模式**：只有字幕编辑工作区使用深色，壳层保持浅色，避免全程序两套主题割裂。
6. **表单对齐**：标签固定列，输入起点统一；长说明折成单行或放到右侧状态卡，不在表单里铺段落。

## 4. 通用组件

### 按钮

- 主按钮：`accent` 底、白字、高 30、圆角 7、左右 14；只出现一个。

## 7. 画质契约（必须按后端）

`parse_qualities()` 的实际顺序：

1. 只保留 `height >= 720` 且有视频编码的格式。
2. 按 `height` 分组；同一分辨率只保留一条。
3. 每组优先取 `fps > 30` 的格式；若没有，再取全组。
4. 在候选里取 `filesize / filesize_approx` 最大的一条。
5. 按 `height` 降序返回。

UI 映射：

- 列表行文案：`{height}p {fps}fps   ~{size}`；第一行追加“（最高，推荐）”，视觉上用等宽的“最高·推荐”标记。
- 检测完成默认 `setCurrentRow(0)`，即最高档。
- 检测后必须把“可用画质”区从空态切换为列表；不允许在检测前显示固定档位。
- 下载按钮的可用性与选中行绑定；未选中行不能提交。
- 不存在“仅音频”模式；不要新增该入口。
- 并发默认 2，设置范围 1～6；不要出现“分片线程”“代理”。

- 本设计未修改 `src/`；落地需要另做 PySide6/QSS 实现，不能直接把 HTML 当成品。
- 设置入口把后端约 10 张设置卡压成 6 个逻辑模块；若要求“一卡一块”，可拆成 8～10 块，但入口页会从 3×2 变成 4 列或滚动。
