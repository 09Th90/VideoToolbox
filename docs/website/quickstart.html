安装与打开

双击安装包

安装向导全程简体中文，不会弹语言选择框。

选安装位置

默认装到 D:\VideoToolbox，可以改；安装不需要管理员权限，不会弹 UAC 窗口。

打开

从开始菜单或桌面快捷方式启动，也可以直接双击安装目录里的 视频工具箱.exe。

几个方便的打开方式：

  • 把链接拖到图标上：直接打开「视频处理」页并把链接填进去；
  • 把文件夹拖到图标上：直接打开合并页并填好路径；
  • 把文件拖进已打开的窗口：视频和字幕进「字幕编辑」页，链接文字进下载页，文件夹进视频库。
如果打不开：视频工具箱.exe 没有做代码签名（签名证书需付费购买），少数开启 Device Guard 或应用控制策略的电脑会拦住它。改用脚本方式启动：双击安装目录里的 src\视频工具箱.bat（需要电脑装有 Python 3）。软件带单实例保护，已开着时再双击不会开第二个窗口。

第一次使用：填一次 AI 配置

不用 AI 也能正常下载视频、看视频库、编辑字幕时间轴。 只有「字幕润色」「AI 翻译」「AI 校准」需要 AI。要用就去 设置 → 全局 AI 填一次，全软件共用这一套：

填什么举例
密钥（API Key）你的服务商发给你的那串字符
接口地址https://open.bigmodel.cn/api/paas/v4
文本模型glm-4.7-flash
视觉模型glm-4.6v-flash（截图识别类功能才用到）

接口地址不用填得很精确——只填域名、填到 /v1、填完整的 /chat/completions 都能认，软件会自动补全。 兼容的服务：OpenAI、DeepSeek、智谱、Gemini 兼容层、Ollama（本地模型）、Azure OpenAI 等，只要是 OpenAI 兼容接口都能用。 填完点「测试接口」验证连通，再点「保存并应用」——保存后立刻生效，并自动写入字幕引擎。

关于你的密钥：密钥只存在本机的 data\ai_config.json 里，不随软件分发、不上传到任何地方。软件自带的源代码里不含任何真实密钥。

语音识别（ASR）要不要配

软件内置了几个免费在线转录引擎，不配 ASR 也能用。配了的好处是可以选更准的服务或本地模型。 在 设置 → ASR 语音识别 里选一种来源：

  • 自有 ASR 服务（推荐）：填接口地址、密钥、模型名。任何 OpenAI 兼容的语音识别接口都行，比如 FunAudioLLM/SenseVoiceSmall、whisper-1、阿里云百炼 ASR。不用下载模型文件。
  • 本地独立模型：填模型名（如 large-v3、large-v3-turbo）和模型目录，需要 faster-whisper 运行环境与对应模型文件。

接口协议留「自动识别」就好——软件会按地址和模型名自己判断该用哪种协议，目前支持 11 种： 自动识别、OpenAI Whisper 兼容、Azure OpenAI、Chat 音频转写（百炼 / MiMo）、Deepgram、ElevenLabs Scribe、 Google Gemini、火山引擎（豆包）、AssemblyAI、百炼实时（WebSocket）、百炼原生（ASR 专用端点）。

源码方式

完全离线、或想直接用最新源码时（需要 Python 3.12）：

git clone https://github.com/09Th90/VideoToolbox.git
cd VideoToolbox
pip install -r requirements.txt
python -m playwright install chromium   # 可选：Cookie 导出 / B 站投稿才需要
python src/video_toolbox_qt.py
必须在仓库根目录运行：程序按当前工作目录定位 tools/、data/，换目录启动会找不到运行时。首次运行会按需下载 FFmpeg、yt-dlp、ASR 模型、libmpv 等外部依赖；python tools/download_open_source_deps.py --check 可先体检缺什么。

文件都放在哪

软件是绿色便携的：配置、下载、缩略图缓存、日志、临时文件统一放在「数据根目录」下，默认就是软件所在目录， 不写系统盘。把整个文件夹拷走就等于把全部数据带走了。想搬家：设置 → 目录 → 数据根目录。 

视频工具箱\
├─ 视频工具箱.exe          主程序（双击这个）
├─ data\                   你的数据（配置、下载、缓存）
│   ├─ config.json         全局设置（下载目录、数据根、同步开关）
│   ├─ ai_config.json      AI 与 ASR 配置（含你的密钥，别外传）
│   ├─ downloads\          默认下载目录
│   ├─ thumb_cache\        视频库缩略图缓存（可删，会自动重建）
│   └─ waveforms\          字幕编辑页的波形缓存（可删，会自动重建）
├─ logs\                   日志（出问题时给维护者看这个）
├─ docs\                   说明文档与第三方许可声明
├─ tools\                  运行时依赖（已内置，无需联网下载）
└─ src\                    源代码（脚本方式启动时用）

可以放心删的：data\thumb_cache\、data\waveforms\、data\tmp\、logs\ 里的日志。 不要删的：data\ai_config.json、data\config.json、tools\ 里的任何东西、 docs\开源许可_GPL-3.0.txt（法律要求必须保留）。卸载不会删除 data\ 目录。
