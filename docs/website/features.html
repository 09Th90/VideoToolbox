首页 · 工作台

打开软件的第一页。顶部任务框支持三种输入：拖文件、粘链接、直接打字。 打字的内容会交给 AI 托管执行（部署了 AI 引擎时），比如「把 data\downloads 里最新的视频转成字幕」。 下方直达最近的任务进度，一键创建下载 / 转录 / 翻译任务。

视频处理 · 视频下载

粘贴链接

支持 YouTube、B 站等 yt-dlp 支持的站点。

选保存位置

选一次就长期记住，下次打开自动填回；就算文件夹暂时不在（外接硬盘没插），记忆也不会丢。

检测画质

自动列出 720p 及以上档位：同一分辨率只留文件最大的，有 60fps 就只留 60fps，省得在十几个选项里纠结。

加入并行下载

任务进入列表，可同时挂好几个；默认一并下载博主上传字幕与自动生成字幕，转成 .srt，支持中英日韩西法德等多语言。

每个视频自动打包成独立文件夹，文件夹名就是视频标题：

某视频标题\
  ├─ 某视频标题.mp4    视频本体（音频始终取最高质量）
  ├─ 封面.jpg          封面图，统一等比补边到 1280x720，不拉伸
  ├─ 视频信息.txt      标题 / 简介 / 链接 / 博主主页 / 画质 / 下载时间
  └─ *.srt             字幕（如果勾了下载字幕）
几个贴心细节：同名视频不覆盖（自动改叫「标题 (2)」）；视频信息.txt 用 UTF-8 with BOM，记事本打开不乱码；标题非法字符自动替换、超长截断到 80 字；下载完成自动打开文件夹；字幕拉取失败不影响视频本体。

视频处理 · 音画合并

有些站点把画面和声音分成两个文件下（如 .mp4 画面 + .m4a 声音），需要合成一个才能正常看。分两种模式：

自动配对

选输入文件夹 → 「扫描配对」按文件名和时长自动配成一对 → 「开始合成」，结果输出到「合成结果」文件夹。适合成批处理下载下来的文件。

手动合并

把视频和音频从资源管理器直接拖进来（拖到任意槽位或页面空白处都会自动归位），字幕可选 .srt / .ass。结果叫 原视频名_merged.mp4，同名不覆盖。

手动合并更「抗造」：音频先实测编码，AAC 直接封装、其它格式自动转 AAC；视频先直接封装，装不进 mp4（如 vp9 / av1）会自动改 H.264 重编码再试一次。.m4a 直接封装不转码、不损失音质；.srt 作为软字幕挂进去，播放器里可开关。

视频库

  • 默认显示下载页记住的保存位置，可换文件夹或「同步下载目录」跟随下载页；
  • 点「刷新」才扫描——打开软件时不会自动扫，免得误扫几万文件的大目录卡住；
  • 递归扫描子文件夹，卡片名显示「文件夹名 \ 文件名」，并显示时长与文件大小；
  • 单击卡片直接播放，右键打开所在文件夹；
  • 缩略图缓存在 data\thumb_cache，缓存名含完整路径指纹，不同文件夹下的同名视频不会串图。

字幕处理

内置自研字幕处理引擎，页内直接用、不弹独立窗口。顶部分段标签： 任务创建 / 语音转录 / 字幕翻译 / 字幕校准 / 字幕视频合成。 把视频拖进来或粘贴链接，按需走转录 → 翻译 → 校准 → 合成几步。 字幕优化与配音依赖大模型，需先在设置填 AI 配置；不填只是这两项用不了，转录翻译照常。

关于免费翻译服务：微软翻译的取 token 端点官方已 404、谷歌翻译在国内通常不可达，这是端点侧的问题。整批失败时软件会自动改用微软翻译重试一次；译文缺失会明确报错且不生成文件，不会产出内容还是原文的「假翻译」。想要稳定质量，建议直接用大模型翻译。

「字幕视频合成」分段可以把字幕硬烧录进画面，或封装成可开关的软字幕 / MKV。配置、日志、模型缓存、任务产物统一放在软件文件夹 data\ 下，不往 C 盘写东西。

字幕编辑 · 看着画面对轴

下载来的字幕时间轴常常不准。这一页左边放视频、右边字幕表、下半区是波形时间轴—— 直接拖波形上的字幕块就能改时间，不用在播放器和文本编辑器之间来回切。 首次使用需装一次播放组件 libmpv（约 40 MB，出于许可与体积不随安装包分发）；没装也不会崩，字幕表的查看编辑照常。

按键作用
空格播放 / 暂停
, .后退 / 前进一帧（← → 同效）
Shift+←/→选中字幕整体前移 / 后移 100ms
Alt+←/→前移 / 后移 1 秒
[ ]把选中条目的起点 / 终点设为播放头当前位置
Ctrl+K在播放头处切分
Ctrl+Z / Ctrl+Y撤销 / 重做
Ctrl+= - 0时间轴放大 / 缩小 / 缩放到整轨
  • 撤销 100 步，拖动改时间也算一步——拖之前先存快照，撤销能精确回到「拖动前」；
  • 保存时自动备份：目标文件已存在且无同名 .bak 时先备份一份；
  • 切分或取边界若会让某条字幕短于一帧（40ms），操作被拒绝，不写坏数据；
  • 内嵌字幕：把当前字幕（含未保存改动）作为 mov_text 软字幕轨挂进 mp4，流复制不重编码，几秒完成、画质零损失；
  • 字幕层：画面上叠透明预览层随播放实时渲染，所见即所得。

流水线 · 一条链接全自动跑完

粘贴链接，剩下全自动：下载（原片 + 字幕 + 封面 + 信息）→ 翻译 → 字幕校准 → AI 二次校准 → 成品打包。 也可以盯住一个文件夹：新出现的视频自动接管，判断下载完成后走同一条链，中间还能自动做音画合并。 并发任务数 1~8 可调（默认 3），一个在下载时另一个可以同时在校准。

断了能接着跑

任务状态实时存盘，重启后已完成阶段自动跳过、进行中的归位重跑。

失败被隔离

一个任务失败不拖累队列里的其他任务。

输入没变就不重跑

产物带输入指纹，同样的输入不会重复劳动。

存量文件不动

只接管新出现的文件，之前放在那里的不会被莫名改动。

自动化 · B 站投稿

保存投稿模板（标题 / 简介 / 标签 / 分区 / 话题），投稿表单可从视频目录的 视频信息.txt 一键读取； 执行在后台线程跑，失败自动留整屏截图方便排查。

AI 托管 · 让 AI 替你操作整个软件

本节功能只有在部署了 AI 引擎后才会出现。没部署时导航栏里没有「AI 托管」这一项，软件其它一切照旧。
  • 首页输入框直接打字，回车后跳到「AI 托管」页，AI 自己读文件、运行内部工具把事办完；
  • 模型和密钥不用另配——用的就是「设置 → 全局 AI」那一套，改了设置下一次托管自动生效；
  • AI 的工作目录就是程序根目录，能读写文件、执行程序；高危操作（删文件、改配置）会先问你；
  • 每次任务的完整记录存在 data\harness-home\transcripts\，可随时翻看；
  • 想人工指挥：点「打开交互控制台」，在浏览器里打开完整的对话式控制台。
