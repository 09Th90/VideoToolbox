常见问题与已知限制

真实使用中会碰到的问题，以及当前版本明确做不到的事——写在这里，而不是藏在 issue 列表里。

常见问题

打开软件没反应 / 被系统拦住了？

exe 没有代码签名，开启 Device Guard 或应用控制策略的电脑可能拦截。改用脚本方式启动：双击安装目录里的 src\视频工具箱.bat（需要电脑装有 Python 3）。

字幕翻译总是失败？

免费翻译服务的公开端点这几年陆续失效了（微软 token 端点 404、谷歌国内不可达），这是端点侧的问题。软件会自动改用微软翻译重试一次；仍然失败的话，建议在设置里配好 AI 用大模型翻译。

翻译不完整时会明确报错且不生成文件，不会再悄悄给你一个内容还是原文的「假翻译」。

AI 校准点了没反应或报错？

先检查 设置 → 全局 AI 是否填好、点「测试接口」是否通过。没配 AI 时请关闭「AI 校准」开关，用纯脚本校准一样能用。校准页有「刷新」按钮，界面卡住时点一下可以复位（正常运行时不会打断任务）。

字幕编辑页打开视频只有声音没有画面？

播放组件 libmpv 没装好。在程序目录执行 python tools\download_open_source_deps.py --only mpv 重新拉取一次，然后重启软件。没装播放组件时本页只提示一句，字幕表的查看和编辑照常能用。

用国内 AI 服务（比如百炼）连不上，报代理错误？

新版本已经修了——对国内端点强制直连，不再被系统代理送到海外节点。如果还在用旧版本，升级即可；临时办法是关掉代理软件。

在线安装器下载特别慢？

慢的是 GitHub Releases 的国际链路，不是软件本身有问题。有内网分发源或代理软件的话可以用那些方式提速；完全断网的环境请按源码方式运行。

下载的视频字幕时间轴不准？

YouTube 等平台有一种「滚动式」字幕，同一条字幕的结束时间被延伸到下一条，表现为字幕长时间叠挂（实测重叠率高达 84.9%）。新下载的字幕软件会自动修正；存量的旧文件可以用「字幕编辑」页手动对轴。

软件会往 C 盘写东西吗？数据能换盘放吗？

不会。所有运行期文件都在数据根目录下（默认就是软件所在目录）。想把数据放到别处：设置 → 目录 → 数据根目录，填入目标文件夹点「应用」，软件会把现有 data\ 和 logs\ 迁移过去，重启后完全生效。

已知限制

限制现状与影响
无代码签名签名证书需付费购买；少数开启应用控制策略的电脑会拦截 exe
无离线安装包onefile 打包后超过 1 GB；完全断网环境只能用源码方式
无自动化测试只有 scripts/dev/ 下的人工自检脚本；升级前建议先备份 data/
组件走国际链路托管在 GitHub Releases；国内直连速度取决于你的网络
