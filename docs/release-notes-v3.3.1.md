# 视频工具箱 v3.3.1 发布说明

- 发布日期：2026-11-26
- 基线版本：v3.2.5（2026-11-22）
- 说明：本版合并原 3.3.0 开发线（实时字幕、UI v3 重构、校准硬化）并完成发布前收尾，统一以 **v3.3.1** 发布。

## 一、新增：实时字幕

左侧新增「实时字幕」页，长生命周期服务，无命令行子命令。

- 音源：系统内录（WASAPI loopback，默认）/ 麦克风 / WAV 回归；设备可刷新。
- ASR：端点、模型、协议自动复用「设置 → ASR 语音识别」的 `ai_config.json`；密钥只读 `credentials.json` 的 `asr_api_key`，不单独存密钥、不回显。
- 术语校准：18 种片源模式；ASR 原文与译文都过同一张 `calib_core` 术语表。
- 输出：`data\live_out\live_<时间>.srt`（双语两行：译文在上、原文在下），同时写 `sub_en.txt` / `sub_zh.txt` 供 OBS 文本源，`cues.jsonl` 为调试事件流。
- 悬浮层：置顶透明、可拖动、滚轮调字号；右键可开/关点击穿透、回底部、隐藏。
- 本地兜底：可选 Index-Echo（`tools\live_engine` + `tools\live_model`，约 2.5GB，不随安装包）；未安装时云端失败直接报错，不假装降级。
- 首次使用内录/麦克风需要 `soundcard` 与 `numpy`；安装包已内置，源码方式见 `requirements.txt`。

## 二、新增：发布素材（流水线阶段 + 独立命令）

- 流水线在「二次校准」之后、「成品输出」之前新增 `publish` 阶段：从校准字幕生成 10 段时间轴 + 10 个 tag + 中文标题，写 `投稿信息.txt`（严格对齐 B 站投稿读取格式）与 `发布素材.md`。
- 硬约束在代码侧兜底：标题【游戏名】钩子【主播名】≤80 字、10 tag 去标题词补足、10 章节首段 0 起点 / 间隔 ≥5s / 标题 ≤16 字 / 均分兜底。
- CLI：`agent_cli publish <srt> [--video --game --streamer --title-en --out]`。
- AI 未启用或无校准字幕时该阶段自动跳过，不阻塞成品。

## 三、校准系统硬化

- **不动点幂等**：修复术语路径裸 `str.replace` 对「错形 ⊂ 官方名」规则二次命中叠字的问题（`_apply_pair` 哨兵保护）；幂等矩阵 353/353，`p3_a_test.py` 22/22。
- **证据覆盖率守卫**：`_verified_hit` 新增 `_VERIFIED_COVER_MIN=0.6`，佐证片段须覆盖改动区间主体，挡下「半佐证前缀」误放行。
- **不动点门禁重写**：无机械层时 `fixed_point=None` + 显式跳过原因；复跑前保护参考行；单跑不等时补跑区分「渐进精修 / 振荡」，只诊断不放松门禁。
- **audit 交付门禁**：`audit_gate_findings` 机械补校 + 重验 + 回滚保护，无锚点判 inconclusive。
- **跨 cue 一致性**：全片扫书名号断裂 / 相邻重复 / 同源异译，报告-only，不改产物。
- **性能**：`_learn_canonicals()` 从逐条循环提到批外一次 + 日志批量落盘，校准 CLI 每次固定开销 **55s → 9.5s**，不动点 SHA 不变。
- **配置保存**：`ai_save_config` PUT→PATCH，界面未收集的键（`calib_concurrency`、`decision_*`、`max_tokens/timeout/retries` 等 11 个）不再被「保存并应用」重置。
- **校准风格三档**：自动（机翻腔 hot==0 自动整句重写）/ 锁定术语级 / 整句重写；校准页新增「本轮风格 / 不动点」只读标签与结论级摘要日志。
- **会话固化**：安全评审结论为保持 `VT_SESSION_PROMOTE` env-gated 默认关闭，不暴露界面开关。

## 四、AI 校准能力修复（P0 + P1）

针对「AI 校准第二轮采纳 0 处」的实测问题：

- 结构化检索 + 统一来源分级（补 kurobbs，消除同页两级矛盾）。
- 官方/wiki 证据入采纳闸门，联网查到的官方名可直接参与校验。
- 确定性候选改最长匹配唯一结果，拦「西吉兰机甲 → 西格莉卡兰机甲」类污染。
- 规则命中 0 条的双语片自动切整句重写（rewrite）。
- 拒绝整改回路：闸门拒绝后带反馈重问，每块最多 1 次。
- 参考行补全（wuwa-40ko/ign/pv/reveal、ak-arcaea 等）；resume 空 KB 注入官方名全集 + 会话证据。
- `build_meta` 联网佐证：低把握干净中文官方名经 A 级来源佐证升 high 后可采纳。
- 机械冲突闸门：同表长键二次命中 / 孤儿短键切碎官方键为 hard；23 条孤儿污染补长键修复归零（hard 0）。
- `learn` 状态机加固：版式兼容、按源文件去重、撞名审查、单片快路径、`--force`。
- 实测（鸣潮 4.0 新联邦 reaction，251 cue）：242 处改动；「西格莉卡兰 / 西吉兰 / 永明官员」残留 0；复跑 SHA256 与第三方批准终稿逐字节一致（不动点证明）。

## 五、流水线与模式

- 一校改为 AI 精确校准（`style="rewrite"` + 自定义指令），二校 `resume_from` 接续并临时启用会话固化（带撞名审查 / 回滚守卫）。
- 按片源自动选游戏模式：`pgr-en / ak / limbus / gfl2` 补高判别 markers；PGR 片实测命中 `pgr-en`。
- 校准模式子键化：12 个变体旗标降级为「游戏-细类」ASCII 子键（`--mode <键>`），旧旗标继续兼容；界面补齐 8 个缺失入口。

## 六、界面 v3 重构

- 新壳层 `src/vt_app/shell.py`：覆盖式顶栏（品牌 / 面包屑 / 窗口按钮，可拖动、双击最大化）与底部状态栏（本机模式、主题、配置、版本）。
- 设置页改为 3×2 六块入口 + 6 个独立二级页，`SettingsPage.sp.*` 属性全部保留，旧引用不破。
- 统一 `PageHeader` / `ScrollPage` / `TabPage` 内边距与标题层级；视频处理、合并、切片、视频库、字幕处理、字幕编辑、流水线、自动化逐页改版。
- 主题 token 与 QSS 对齐 v3；修复顶栏/导航色块分段、设置底栏遮挡、二级页 `showEvent` 重置等问题。
- 背景遮罩语义纠正：数值即不透明度/压暗强度，0% 真正全透明，滑杆范围 0–100%，「板块遮罩」更名「卡片不透明度」。

## 七、构建与安装

- 新增运行期依赖 `soundcard==0.4.6`（WASAPI 采集），已随离线包与在线包分发；`torch/demucs` 仍为可选分离后端，不进安装包。
- 离线安装包：`视频工具箱_Setup_v3.3.1.exe`（发布页同时提供 ASCII 名 `VideoToolbox_Setup_v3.3.1.exe`）。
- 在线安装包：`VideoToolbox_OnlineSetup_v3.3.1.exe`（约 12MB 引导器，按文件差异拉取 app/code/docs/tools 分层组件）。
- 已装旧版不必重装：设置 → 程序更新 → 检查更新，按文件差异增量下载；同一版本可选「修复安装」。
