## 来源说明

- 归档自 git 提交历史中 `HEAD` 版本的文件内容（逐字节原样）。
- 原文件已在本机清理（移入回收站），git 跟踪中同步移除，以避免仓库体积膨胀。

## 还原方法

如需取回某个文件，直接从本目录复制回原路径即可：

```bash
# 例：取回旧的 Inno Setup 语言文件
cp history/build/Languages/ChineseSimplified.isl build/Languages/
```

## 保留说明

以下目录/文件**未归档也未删除**，因为它们与构建或运行直接相关：

- `tools/` —— 程序运行依赖（内置 Python 运行时、ffmpeg、yt-dlp、deno、
  Playwright 浏览器、mihomo 代理、videocaptioner wheel）
- `build/Languages/ChineseSimplified.isl` —— Inno Setup 中文语言文件，编译 .iss 必需
- `build/ifw_config/` —— 在线安装器配置
- `src/`、`docs/`、`installer_src/` —— 源码、文档、安装器构建源码
- `data/config.json`、`data/uploader_profile/` 等 —— 用户配置与数据
