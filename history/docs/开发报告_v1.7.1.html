1. 项目概览

1.1 项目定位

「视频工具箱」是一款面向个人的本地视频工作台，覆盖从 B站视频下载 → 本地字幕生成（ASR） → 音视频/字幕合并 → 视频库管理 → B站自动投稿 的完整闭环。所有外部依赖（Python 运行时、Chromium 浏览器、Whisper 模型、ffmpeg/yt-dlp）均内嵌在工具目录内，免安装、免联网初始化、可整目录拷贝迁移。

1.2 技术栈

层级技术用途
GUIPython Tkinter（ttk.Notebook 五标签页）下载 / 视频库 / 合并 / 字幕生成 / B站投稿
下载yt-dlp（内嵌 exe）抓取信息 JSON、清晰度解析、并行下载、字幕下载
媒体处理FFmpeg / FFprobe（内嵌 exe）抽帧封面、时长探测、抽音频、音视频/字幕合并、烧录字幕
ASRfaster-whisper（large-v3-turbo）本地字幕生成，GPU float16 优先、CPU int8 回退
投稿自动化Playwright + 内嵌 ChromiumB站投稿页自动填表、文件注入（CDP）、登录态复用
打包发布PyInstaller + Inno Setup单目录 exe + 安装包；模型/浏览器单独外置下载脚本

1.3 版本演进

  • v1.6.x：安装包瘦身（ASR 模型改为外置下载）；视频库；音视频合并。
  • v1.7.0：目录按功能分层（src/docs/data/logs/tools）；投稿分区自动检测为两级级联；视频信息.txt 与投稿表单字段全对齐；ASR 大模型。
  • v1.7.1（本期）：① B站分区改为单级下拉（B站当前无一级/二级），分区/话题检测均改为先上传视频再取列表（修复 areas 检测退出码 1 问题）；② 新增「加入合集」自动检测与选择；③ 同步上传原始字幕（.srt），字幕语言默认英语；④ 简介按「源地址/来源/原简介」格式自动生成。

4. 技术设计

4.1 总体架构设计

  • 三层 + 数据带：GUI 层（Tkinter）只负责交互与装配；引擎层（video_toolbox.py + 投稿引擎子包 + ASR worker）承载全部业务；工具链层为内嵌二进制/运行时。数据与日志独立成带，用户数据可整体迁移。
  • 自包含免安装：Python 运行时、Chromium、Whisper 模型、yt-dlp/ffmpeg 全部内嵌在 tools\，程序不依赖系统环境；模型与浏览器由安装/下载脚本补齐。
  • 子进程隔离：ASR 转写与 B站投稿均为独立子进程，崩溃不影响 GUI；GUI 通过行协议 + 队列回主线程更新界面。
  • 路径锚点与迁移：引擎启动时按「程序目录」计算各路径锚点，并对 v1.6 旧布局（根目录散落 data/logs）自动迁移，保证升级不丢用户数据。

4.2 进程模型与通信协议

通道协议说明
GUI → ASR worker命令行参数（--video/--model/--out/--ffmpeg/--ffprobe/--language）worker 由内嵌 python 以子进程运行
ASR worker → GUIstdout 行协议 @@PROGRESS {"pct":…} / @@LOG / @@DONE / @@ERRORGUI 逐行解析，进度回填任务表
GUI → 投稿引擎任务 JSON（data\uploader_tasks\*.json）+ 子进程参数引擎启动时 load_task_file 装配字段
投稿检测 → GUIstdout 标记行 CATALOG_JSON=… / CATALOG_SAVED=… + 结果文件GUI 解析后回填分区/合集/话题下拉
GUI 内部主线程 queue.Queue + after() 轮询子进程/线程产物安全回到 Tk 主线程

4.3 投稿引擎设计（v1.7.1）

  • 登录态长期复用：Playwright 以 data\uploader_profile 持久化上下文启动，首次扫码后 Cookie 长期有效，后续免登录。
  • 先上传、再取分区：B站上传视频后才进入可填写的投稿区。分区/话题/合集检测流程均先调用 upload_video 完成真实上传，再枚举表单，修复「areas 检测失败（退出码 1）」。检测会上传视频但不投稿。
  • 单级分区：B站当前分区为单级下拉，UI 通道展开下拉直接枚举全部选项（与页面所见一致），接口通道兜底并把两级树自动拍平为叶子；GUI 由两级级联改为单级下拉。
  • 合集自动检测：主通道调用创作中心 member.bilibili.com/x2/creative/web/seasons（页面内 fetch 带 Cookie）获取账号全部合集；失败且已上传视频时回退枚举页面「合集」下拉；GUI 新增「检测合集」按钮与下拉选择。
  • 字幕同步上传：选视频时自动从同目录查找原始 .srt（同名 → .en.srt → 同名前缀 → 任意）；上传流程定位字幕区 → 先选语言（默认英语）→ CDP 注入字幕文件 → 等待完成。
  • 简介格式：选视频时按「源地址（换行）/ 来源：博主主页（同行）/ 原简介（换行）」自动生成，字段取自 视频信息.txt 的视频链接/博主主页/简介。
  • 文本扫描式定位：表单定位不依赖固定 class，而是扫描页面可见文本标签（“标题/简介/分区/合集/字幕…”）与可点击元素，再按名称点击选项——对 B站改版有较强抗性。
  • 文件注入双通道：主通道 Playwright set_input_files（CDP）；非标准上传组件时回退 PyAutoGUI 操控系统文件对话框（剪贴板粘贴路径，支持中文路径）。
  • 字段级容错：逐字段填写独立 try/except，单字段失败记录结果不中断其余字段；预览/提交双模式，提交前 GUI 二次确认。
  • 可观测性：每次失败自动截图到 logs\uploader\screenshots，日志 logs\uploader\run_*.log，便于排障。

4.4 ASR 字幕生成设计

  • 恒定内存：ffprobe 取总时长后按 10 分钟/块（块间 2 秒重叠防切句）用 ffmpeg 抽取 16kHz 单声道 wav，任意时刻内存中只有一块音频。
  • 重叠去重：段时间戳加块偏移回到全局时间轴，丢弃起始落在上一块已覆盖区的段。
  • VAD 过滤：faster-whisper VAD 过滤静音（min_silence 500ms），beam_size=5。
  • 算力回退：GPU float16 优先，加载失败自动回退 CPU int8，界面提示实际引擎。
  • 进度协议：块级/段级进度通过 @@PROGRESS 实时回传，GUI 显示百分比与当前块。

4.5 下载链路设计

URL 输入→ fetch_info_json（重试 4 次）→ parse_qualities 清晰度解析→ yt-dlp 并行下载→ make_cover 1280×720 封面→ write_info_txt 视频信息.txt
  • 每视频独立文件夹（sanitize_folder_name + unique_folder 防重名）；可选下载字幕。
  • 视频信息.txt 字段与投稿表单完全对齐（标题/简介/标签/分区/创作声明/话题/视频链接/博主主页），GUI 选视频即全字段预填，简介按投稿格式自动生成。
  • 多任务并行下载，任务表记录进度/状态，可中途取消。

4.6 合并链路设计

scan_media 扫描→ smart_pair 时长匹配配对→ merge_pair（ffmpeg）→ 封装 / 字幕烧录
  • smart_pair 以 ffprobe 时长差为准则智能配对 mp4/m4a/webm 与 srt/ass 字幕，自动识别音视频/字幕组合。
  • ass_mode=burn 时把字幕烧录进画面；否则仅封装音轨。

4.7 打包与发布

  • PyInstaller（视频工具箱.spec）：把 GUI + 引擎 + 上传器源码打进单目录 exe，内嵌 python 运行时与上传器源码随包携带。
  • Inno Setup（视频工具箱.iss）：生成安装包，写入开始菜单/桌面快捷方式。
  • 大组件外置：Whisper 模型（约 1.5GB）与 Chromium 不入安装包，首次运行或由下载脚本补齐到 tools\，避免安装包臃肿。

5. 关键业务流程

5.1 B站投稿流程（v1.7.1）

1. GUI：选视频 → 自动读取同目录 视频信息.txt 预填（标题/简介按格式/标签/分区/声明/话题）
2. GUI：点「检测/刷新分区列表」（需已选视频）→ 引擎先上传视频 → 枚举单级分区 → 回填下拉
3. GUI：点「检测合集」→ seasons 接口获取账号合集 → 回填下拉（可留空）
4. GUI：原始字幕自动查找（.srt）→ 语言默认「英语」
5. 启动投稿引擎（任务 JSON）：
    goto 投稿页 → 登录态检测/扫码 → 上传视频 → 等待就绪 → 选封面
    → 标题/创作声明 → 分区（单级）→ 加入合集（若有）→ 标签 → 话题
    → 字幕上传（选语言→注入 srt）→ 简介
6. 预览模式（不提交）核对；正式提交前 GUI 二次确认 → 点击「立即投稿」

任一步失败：单字段隔离记录 + 自动截图 + 日志，GUI 报告结果。

5.2 字幕生成流程（ASR）

1. GUI 选视频（可多选）→ 语言/是否双语 → 启动 worker 子进程
2. worker：ffprobe 总时长 → 分块抽 wav → VAD 转写 → 重叠去重 → 写 SRT
3. GUI：@@PROGRESS 实时进度 → @@DONE 后刷新任务表，输出到视频同目录
