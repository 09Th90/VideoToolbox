## 一、本次四项需求与实现

### 1. 按功能划分目录，程序文件夹顶层只留主程序（+日志）

安装后目录：

```
D:\VideoToolbox\（默认，用户可改）
├─ 视频工具箱.exe        顶层唯一可执行主程序
├─ tools\                运行时依赖
│   ├─ ffmpeg.exe / ffprobe.exe / yt-dlp.exe
│   ├─ python\           内嵌 Python 3.12.10（faster-whisper/playwright）
│   ├─ ms-playwright\    内嵌 Chromium
│   ├─ uploader_src\     投稿引擎源码（新增 catalog.py 分区/话题检测）
│   └─ asr_model\        识别模型空壳（模型用户自行下载，不进包）
├─ src\                  源代码 + 脚本启动器（video_toolbox*.py / worker / .bat / 自检）
├─ docs\                 使用说明.txt、界面预览.png
├─ data\                 用户数据（运行时生成，不进包，卸载保留）
│   ├─ config.json  downloads\  thumb_cache\
│   ├─ uploader_profile\（B站登录态） uploader_tasks\  catalog\（分区话题缓存）
└─ logs\                 日志
    └─ uploader\screenshots\（投稿日志与失败截图）
```

- 主程序/引擎路径锚点全部改造：`video_toolbox.py` 新增 APP_DIR/SRC_DIR/DOCS_DIR/DATA_DIR/LOGS_DIR；`uploader_src/config.py` 锚到 `data`、`logs`；并内置 **v1.6 旧布局自动迁移**（旧根目录 config.json、旧 tools 下 profile/tasks/logs 首次运行自动归位，本次已实测把原登录态 profile 完整迁入 data）。
- 所有 Python 入口设置 `sys.dont_write_bytecode=True`，运行时不在程序目录生成 `__pycache__`。

### 2. 默认安装位置改为 D 盘

`.iss`：`DefaultDirName=D:\VideoToolbox`（原为 `{autopf}\VideoToolbox`）；保持用户级安装（lowest，无 UAC）。向导中仍可自行改路径。

### 3. B站投稿分区/话题自动检测 + 级联

- 新增投稿引擎模块 `tools/uploader_src/modules/catalog.py`，运行器新增 `--catalog areas|topics` 子命令。
- **分区树**：主通道在已登录投稿页内 fetch 创作中心分区接口（自动带 Cookie，两个候选地址容错），失败回退 UI 通道——打开分区浮层按左右两列 x 坐标枚举一级/二级；结果缓存到 `data/catalog/areas.json`。
- GUI 分区由手输框改为**一级/二级两级级联下拉** + 「检测/刷新分区列表」按钮，启动自动载入缓存；选定一级后二级自动联动。
- **话题**：选定两级分区且选中视频后，点「检测本分区话题」，引擎上传视频（**不会投稿**）→选中该分区→枚举「参与话题」区全部 chip；结果显示在多选列表，**双击或按钮加入**，仍保留手动输入。
- 检测与投稿互斥（检测时禁用投稿按钮），避免同浏览器 profile 双开冲突。

### 4. 下载「视频信息.txt」与投稿表单完全匹配

- `write_info_txt` 在原标题/简介/链接/博主基础上，新增投稿对齐字段：**标签 / 分区 / 创作声明 / 话题**（键名与 sidecar 词表一致；标签自动取站点 tags）。
- `parse_info_txt` 扩展为解析全部六字段；投稿页选视频后**一次性回填标题/简介/标签/分区（自动选中两级下拉）/创作声明/话题**。
- sidecar 新增独立 `topics`（话题）字段，与 tags（标签）区分；TXT 侧车同样识别两类字段。

## 四、使用注意

1. 分区检测只需登录、无需选视频；**话题检测必须先选视频**（B站要上传视频、选定分区后才渲染该分区话题），过程只上传不提交。
2. 首次使用投稿/检测仍需扫码登录，登录态存 `data\uploader_profile`，仅在本机、不随包分发。
3. 覆盖安装 v1.6 时，旧布局数据首次运行自动迁移到 data/logs，登录态不丢。
4. 识别模型仍需按使用说明自行下载放入 `tools\asr_model`（不随包分发，卸载也不会删除用户模型）。
