## 三、编译错误修复记录（本次）

### 3.1 故障现象

便携版编译器编译 .iss 时报错并中止：

> Compiler Error — Line 37: Couldn't open include file
> "H:\doubao\innosetup\IS\Languages\ChineseSimplified.isl"：系统找不到指定的文件。

### 3.2 根因

`compiler:Languages\ChineseSimplified.isl` 指向编译器自带 Languages 目录，而该便携版只带 29 种官方语言、**缺简体中文语言文件**（6.4 起 ChineseSimplified 虽已转官方，但此便携包被裁剪）。

### 3.3 修复措施（全部落在工作区内，未改动编译器目录）

1. 从 Inno Setup 官方仓库 jrsoftware/issrc 获取 `ChineseSimplified.isl`（标注 Inno Setup 6.5.0+，适用 6.7.3），存于 **`build\Languages\ChineseSimplified.isl`**，随项目走、可移植。
2. `视频工具箱.iss` 第 37 行改为引用项目内相对路径：
   `Name: "chinesesimp"; MessagesFile: "build\Languages\ChineseSimplified.isl"`（english 仍用 `compiler:Default.isl`）。
3. **编码关键点**：经实测编译器自带 29 个 .isl 全部为 **UTF-8 无 BOM**（如韩文"다음"为 UTF-8 字节 EB 8B A4…），故语言文件必须保持 UTF-8 无 BOM；LanguageCodePage=936 仅声明运行时代码页，不能据此把文件转成 GBK，否则向导会乱码。最终文件已通过严格 UTF-8 校验。
4. ISCC 重新编译：成功（约 169 秒，退出码 0）。
